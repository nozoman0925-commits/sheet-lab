# 第三者評価：1万人の仮想利用者（第32版 → 第33版）

- 評価日：2026-11-19
- 方法：
  - A. 1万人の人物像（年代・立場・生活リズム・けが・医師の制限・気分・使える時間・厳しさ・やり抜く力）を作り、本体の計算そのもので14日間の「今日の一太刀」を出させた（`eval/personas10k.js`）
  - B. 実際の画面を4つの幅×3つの文字の大きさ×3つの外観×4つの間（144画面）と、一太刀・ふり返りの画面で機械的に点検した（`eval/ui_audit.js`）
- 注意：
  - 「続く割合」は、達成・失敗の連続・合わない課題・時間超過から決めた**モデルによる推定**で、実際の利用者の数字ではない。前後の比較に使う。
  - 楽しさや見た目の好みは、この方法では測れない。実際の人の試験運用（`docs/試験運用_7日間.md`）が要る。

## 第33版で直したこと

1. 夜間・シフト制の人には、時刻に縛られた課題（起床・就寝・朝食など）を出さない。
2. 入門で答えた「1日に使える時間」の2倍を超える課題を避ける。
3. 見せた候補をその日の記録に残し、7日間はなるべく別の候補を出す。
4. 難度の上限は、当てはまるもの（不調の日・心の不調・始めて3日）のうち低い方にする。
5. 今日の稽古に「今日 +EXP」と「次の段位まで あと○ EXP」を出す。
6. 画面：「？」・月送り・暦の日付を押しやすく（40px。幅320pxの画面の暦だけは36px）、11px未満の文字をなくし、白書の暦の数字のコントラストを上げた。

## まだ残っていること（次の候補）

- **初回の道のりが長い**：序章7幕・入門37画面・入門の儀34手順。以前に「詳しく」と指示されたため削っていない。最初の一太刀までを短くする案（入門の儀を3章に絞り、残りは使いながら案内する）を検討する価値がある。
- **段位の最初の一段が遠い**：14日で足軽に上がるのは7%前後。EXPの計算を変えない決まりのもとでは、最初の数日に小さな達成の印（初めての一太刀・3日続いた等）を見せる方法が考えられる。
- **やり抜く力が低い人が離れやすい**：14日続く割合はおよそ4割（モデル推定）。2日続けて届かなかった時に、もっと軽い一つに絞る今の仕組みの効き目を、実際の人で確かめたい。
- 実際の人による7日間の試験運用と、iPhone での確認はまだ。
