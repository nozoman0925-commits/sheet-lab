# 専門家レビューのお願い

アプリが毎日出す「一太刀」（課題127件）と「今日の言葉」（370件）を、内容の正しさと安全の面から見ていただきたい。

## 1. 課題（`missions.csv`）

**見ていただきたい方**：運動指導の資格者（理学療法士・トレーナー）、睡眠・生活習慣に詳しい方、可能なら心理職（公認心理師・臨床心理士）。

| 列 | 中身 |
|---|---|
| ID | 課題の番号（`分類-連番`、`o-` は16タイプの弱点を鍛える課題） |
| 課題文 | 利用者に見せる命令文（武士の師範の口調） |
| 難度 | 1（易）〜9（難）。段位と調子に合わせて選ばれる |
| 最小版 | 調子の悪い日に出す、軽い版 |
| 実行の手順 | 「もし〜なら、〜する」の形の手順 |

**とくに見ていただきたい点**

1. **体への負担**：けが・持病がある人に出してはいけない課題が混じっていないか。（アプリは入門時に「痛みやけががある所」と「医師から運動を止められているか」を聞き、該当する人には運動の課題を出さない作りになっている）
2. **睡眠・食事**：「カフェインを一滴もとるな」「昼寝も二度寝もするな」などが、夜勤の人や体調の悪い人に害にならないか。
3. **心への負担**：命令口調が、気分の落ち込んでいる人を追い詰めないか。（アプリは気分の落ち込み・強いストレスがある人には、課題の数と難度を下げる作りになっている）
4. **難度の並び**：難度の数字が、実際の大変さと合っているか。
5. **最小版**：本当に「できない日でもできる」軽さになっているか。

各行の「安全面の確認」「表現の確認」「判定（可／要修正／削除）」「コメント」の列に記入してください。

## 2. 今日の言葉（`quotes.csv`）

**見ていただきたい方**：古典・思想史に詳しい方（漢文・日本思想・西洋古典）。

**とくに見ていただきたい点**

1. **人物と出典**：その人の言葉として確かか。出典（書名）は正しいか。俗に言われているだけの言葉（いわゆる誤った引用）が混じっていないか。（出典の不確かな「伝」の言葉はすでに外してある）
2. **原文と訳**：漢文の書き下し・古文が正しいか。「注記」に「訳」とある言葉は現代語訳や翻訳で、原文そのままではない。訳として不自然でないか。
3. **場面との合い方**：場面タグ（例：`fail`＝失敗の翌日、`body`＝体調不良の翌日）に合っているか。
4. **不適切な言葉**：差別的・自傷を促すと受け取られかねない言葉がないか（「死ぬこと」を説く武士道の言葉は、とくに慎重に）。

| タグ | 出る場面 |
|---|---|
| start | 気持ちが乗らず始められなかった翌日 |
| cont | 続けている時 |
| fail | 失敗した翌日 |
| self | 衝動に負けた翌日 |
| adv | 困難が続く時 |
| body | 体調が悪い時 |
| learn | 学び |
| time | 時間がなかった翌日 |
| will | 意志 |
| calm | 心を落ち着けたい時 |
| humble | 慢心を戒める |
| focus | 集中 |
| env | 環境を整える |

## 3. 返していただいた後

- 「削除」の行はアプリから外し、「要修正」の行は直してから、もう一度見ていただく。
- 表は `node tools/export_review.js` でいつでも本体から作り直せる。
