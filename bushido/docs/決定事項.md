# 決定事項（変えるときは、ここを先に書き換えてから）

ここにある決定と違う作りを入れる時は、**黙って変えない**。先に利用者（のぞむさん）に「この決定を変える」と伝えて了承をもらい、この表を書き換えてから作る。

| 項目 | 決定 | 決めた時 |
|---|---|---|
| 本質 | 意志の弱さを、仕組みと物語で補う自己鍛錬の道具。本体は「1日1つの最重要行動（今日の一太刀）＋夜30秒のふり返り」 | 第35版 |
| タグライン | **己に勝て。言い訳を断て。昨日の己を超えろ。** | 第35版（第32〜34版の「毎日の約束で、己を鍛える」は無断の変更だったので戻した） |
| 師範（人物） | **置かない。** アプリ自体が道場。言葉は出典つきの格言として出す。以前に登録された師範のデータは消さずに残す（表示しない） | 第35版 |
| 初回の道のり | 最初の一太刀まで5タップ：序章は最後の一画面（全編は任意）→ 安全の3問（けが・医師の制限・気分）→ 道場。入門の儀は自動で始めない（全編は誓いの間から） | 第35版 |
| 一太刀の選び方 | 単純なルール：安全の判定（けが・医師の制限・痛み・不調の上限）は必ず別に行い、そのうえで「目標の分野 → 最近見せていない → 軽い」の順。点数の重みづけはしない（実際の利用者の記録が集まってから見直す） | 第35版 |
| 画面 | 機能は削らず、普段見せる情報を削る。1画面に主役は一つ。表示の量は最小・標準・詳細 | 第34版 |
| 罰の扱い | 段位は下げない。休んでも「再起」として扱い、責めない。できなかった日を赤で強調しない | 第26版〜 |
| 作る場所 | Claude Code で作る（このリポジトリの `bushido/src`）。claude.ai の公開版は確認用の置き場 | 第28版〜 |
| 数字の扱い | 1万人の仮想利用者の「続く割合」はモデルによる推定で、実際の利用者の数字ではない。続くことの証明は、実際の利用者の試験運用（`docs/試験運用_7日間.md`、14日版も可）で行う | 第35版 |
