# iPhone 実機チェック表

開発環境では iPhone の実機を使えないため、Playwright で画面幅（375・390・430・1280）だけを確かめている。以下は**実機でしか確かめられない**項目。結果を ○／×／△ と気づいたことで埋める。

記入者：＿＿＿＿　機種：＿＿＿＿　iOS：＿＿＿＿　日付：＿＿＿＿

## A. claude.ai（Safari）で開く

| # | 確かめること | 結果 | 気づいたこと |
|---|---|---|---|
| A1 | 初回、序章が全画面で出る。上下の端（ノッチ・ホームバー）に文字が隠れない | | |
| A2 | 序章の文字が1.2秒かけて浮かび上がり、カクつかない | | |
| A3 | すりガラス（ぼかし）が効いている。重くない | | |
| A4 | 画面を連打しても幕が飛ばない | | |
| A5 | 「戻る」「スキップ」が指で押しやすい（小さすぎない） | | |
| A6 | 「入門する」で師範の選択へ進む | | |
| A7 | 入門の問いで、選択肢が押しやすい。キーボードが入力欄を隠さない | | |
| A8 | 師範の写真：写真を選ぶ → 切り抜き → 保存できる | | |
| A9 | チュートリアルの吹き出しが、押す場所を隠さない | | |
| A10 | 下のタブ（道場・稽古場・記録・誓い）がホームバーと重ならない | | |
| A11 | タイマー（瞑想など）が画面を消しても大きくずれない | | |
| A12 | アプリを閉じて開き直すと、記録が残っている | | |
| A13 | 序章の途中で閉じると、続きの幕から始まる | | |
| A14 | 「記録を書き出す」でファイルが保存できる（ファイル App に入る） | | |
| A15 | 書き出したファイルを読み込むと、元に戻る | | |
| A16 | カレンダーに追加（.ics）が開ける | | |

## B. オフライン版（ホーム画面に追加）

| # | 確かめること | 結果 | 気づいたこと |
|---|---|---|---|
| B1 | Safari で開き「共有 → ホーム画面に追加」で、家紋のアイコンが付く | | |
| B2 | ホーム画面から開くと、アドレスバーのない全画面で開く | | |
| B3 | 一度開いた後、機内モードにしても起動する | | |
| B4 | 機内モードで記録でき、再起動後も残る | | |
| B5 | 機内モードで今日の言葉と16タイプの絵が出る | | |
| B6 | 7日以上開かなかった後も、記録が消えていない（※iOS はしばらく使わないサイトの保存分を消すことがある） | | |
| B7 | 文字（明朝体）がネットなしでも崩れない（初回にネットありで開いた後） | | |

## C. 設定と見え方

| # | 確かめること | 結果 | 気づいたこと |
|---|---|---|---|
| C1 | iPhone の「視差効果を減らす」をオンにすると、序章がすぐに表示される | | |
| C2 | iPhone の文字サイズを大きくしても、はみ出さない | | |
| C3 | アプリ内の文字サイズ「大」で、ボタンが重ならない | | |
| C4 | テーマ（黒・白・墨）をすべて切り替えて、読みにくい所がない | | |
| C5 | ダークモードのオン・オフで、表示が崩れない | | |
| C6 | 横向きにしても操作できる（または縦に固定される） | | |
| C7 | VoiceOver で、主なボタンの名前が読み上げられる | | |

## D. 古い・小さい端末

| # | 確かめること | 結果 | 気づいたこと |
|---|---|---|---|
| D1 | iPhone SE（第2・第3世代）で、序章の「入門する」が画面内に収まる | | |
| D2 | 古い端末（iPhone 11 以前）で、序章のぼかしと動きが重すぎない | | |
| D3 | 電池の減りが目立たない（10分使って確かめる） | | |
