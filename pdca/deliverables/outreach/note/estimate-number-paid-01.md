# 見積番号、毎回手で打ってませんか?日付から自動で出す式

「前の番号、いくつだっけ…」って台帳を見に行くの、地味にめんどくさいですよね。
しかも打ち間違えると、同じ番号が2枚になっちゃう。

見積日(A列)を2行目から入れているなら、月ごとに001から数え直す番号は、こんな式で出ます。

```
=IF(A2="","","Q"&TEXT(A2,"yyyymm")&"-"&TEXT(COUNTIFS($A$2:A2,">="&DATE(YEAR(A2),MONTH(A2),1),$A$2:A2,"<="&EOMONTH(A2,0)),"000"))
```

2026/10/01の見積が2件なら、`Q202610-001` と `Q202610-002` になりました。月が変わると001に戻ります。

ただし落とし穴があります。**この式は「上から数えて何件目か」で番号を決める**ので、台帳を並べ替えたり、途中に行を挿入したりすると、すでに相手に渡した番号とずれちゃいます。試しに同じ日付を逆順に並べたら、先頭の番号が変わりました。

そこで大事なのが「出した番号は値で固定する」こと。コピーして、形式を選択して貼り付けで「値」にすれば、並べ替えても番号は動きません。

じゃあ、会計年度(4月始まり)ごとに数えたい、取引先ごとに別の連番にしたい、次の番号だけ先に知りたい、というときは?ここから先は有料部分です。

## ここから有料

ここから先は、年度ごと・取引先ごとの連番の式、次の番号の出し方、10行の結果の全部です(300円)。

### 試したデータ(10行)

| 見積日 | 取引先 |
|---|---|
| 2026/03/30 | A社 |
| 2026/03/31 | B社 |
| 2026/04/01 | A社 |
| 2026/04/01 | C社 |
| 2026/09/15 | A社 |
| 2027/01/05 | B社 |
| 2027/03/31 | A社 |
| 2027/04/01 | B社 |
| 2024/02/29 | C社 |
| 2024/04/01 | A社 |

A列が見積日、B列が取引先です。日付は古い順に上から並べる前提です(上の表は、あえて途中で年が戻る並びで試しています)。

### 式1: 年度(4月始まり)ごとに001から

```
=IF(A2="","","Q"&(YEAR(A2)-(MONTH(A2)<4))&"-"&TEXT(COUNTIFS($A$2:A2,">="&DATE(YEAR(A2)-(MONTH(A2)<4),4,1),$A$2:A2,"<="&DATE(YEAR(A2)-(MONTH(A2)<4)+1,3,31)),"000"))
```

`YEAR(A2)-(MONTH(A2)<4)` が「年度」です。1〜3月なら前の年を引いて、2027/01/05は2026年度になります。

| 見積日 | 年度ごとの番号 |
|---|---|
| 2026/03/30 | Q2025-001 |
| 2026/03/31 | Q2025-002 |
| 2026/04/01 | Q2026-001 |
| 2026/04/01 | Q2026-002 |
| 2026/09/15 | Q2026-003 |
| 2027/01/05 | Q2026-004 |
| 2027/03/31 | Q2026-005 |
| 2027/04/01 | Q2027-001 |
| 2024/02/29 | Q2023-001 |
| 2024/04/01 | Q2024-001 |

3/31から4/1で年度が切り替わり、001に戻りました。うるう日(2024/02/29)は2023年度でした。

### 式2: 取引先ごとの連番

```
=IF(B2="","",B2&"-"&TEXT(COUNTIF($B$2:B2,B2),"000"))
```

「その行までに、同じ取引先が何回出てきたか」を数えます。

| 取引先 | 番号 |
|---|---|
| A社 | A社-001, A社-002, A社-003, A社-004, A社-005(出てきた順) |
| B社 | B社-001, B社-002, B社-003 |
| C社 | C社-001, C社-002 |

10行の結果は、A社が5回・B社が3回・C社が2回と、数えた期待値のとおりでした。

### 式3: 次の番号を先に出す

既存の番号が F2:F12 に入っていて、見積日が A20 にあるとき、その月の次の番号はこうです。

```
="Q"&TEXT(A20,"yyyymm")&"-"&TEXT(COUNTIF($F$2:$F$12,"Q"&TEXT(A20,"yyyymm")&"-*")+1,"000")
```

`Q202610-001` から `-003` までと、`Q202609-001` が入っている状態で試しました。

| 見積日 | 次の番号 |
|---|---|
| 2026/10/20 | Q202610-004 |
| 2026/11/02 | Q202611-001 |

同じ月の番号が3件あるので004に、11月はまだ無いので001になりました。**弱点**は、番号を途中で消して欠番ができると、数が減って同じ番号をもう一度出してしまうことです。その月のいちばん大きい番号を探す式は、この原稿では検証していません。

### つまずきチェックリスト

- [ ] 番号を出したら値で固定する(並べ替え・行の挿入・削除で変わるため)
- [ ] 日付は日付の形式にする(文字列だと数えられない)
- [ ] 年度の式は4月始まりの例。ほかの月始まりなら `<4` と `4,1` と `3,31` を直す
- [ ] 式3は欠番があると重複する。出した後に重複チェック(`COUNTIF`で2以上なら印)を入れる
- [ ] 取引先名の表記ゆれ(「A社」と「A社 」)は別の取引先として数えられる

### 自分の表で確かめる手順

1. 上の10行をそのまま入れて、式1〜3を試す
2. 年度ごとの番号と、A社-005までの取引先別の番号が同じになるか見る
3. 同じなら、自分の台帳の日付と取引先に入れ替える

### 限界

- Excelでは未確認です(LibreOfficeで計算しました)
- 複数人が同時に台帳を開いたときの重複防止はできません
- 請求書の番号の付け方の決まりや、インボイスの記載要件は判断しません
