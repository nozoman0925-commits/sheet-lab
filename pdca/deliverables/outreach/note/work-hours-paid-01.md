# 勤務時間の引き算で「####」が出る…を直す式(日またぎ・休憩つき)

「22:00〜翌6:00」の勤務時間を `=B2-A2` で出したら、「####」。
夜勤のある表あるあるですよね。

先に言うと、時刻は「1日=1」の小数として持っていて、日をまたぐと引き算がマイナスになっちゃうのが原因です。

## 無料でできること: MODで日またぎを直す

開始がA2、終了がB2に入っているなら、C2にこれ。

`=MOD(B2-A2,1)`

「引き算の結果がマイナスなら、1日(=1)足して戻す」という式です。セルの表示形式は「時刻」(h:mm)にします。

試した結果はこうでした(LibreOfficeで計算)。

- 9:00〜18:30 → 9:30
- 22:00〜6:00 → 8:00
- 23:30〜0:15 → 0:45

`=B2-A2` のままだと、2行目と3行目はマイナスになります。MODを付けるだけで直ります。

ただし、休憩を引いたり、合計が24時間を超えたり、「8.5時間」みたいな小数にしたい…となると、そこからが地味にハマります。

## ここから有料

ここから先は、試した式6つと、試した結果の全部です(300円)。

### 式の一覧(開始=A、終了=B、休憩の分=C)

| 目的 | 式 | 表示形式 |
|---|---|---|
| 休憩を引いた勤務時間 | `=MOD(B2-A2,1)-C2/1440` | 時刻(h:mm) |
| 勤務時間を分の整数に | `=ROUND(D2*1440,0)` | 標準 |
| 勤務時間を小数の時間に | `=ROUND(D2*24,2)` | 標準 |
| 文字で「時:分」を出す | `=TEXT(D2,"[h]:mm")` | 標準 |
| 15分単位に切り捨て | `=FLOOR(E2,15)`(Eは分の整数) | 標準 |
| 複数日の合計 | `=SUM(D2:D8)` | `[h]:mm` |

(D2が「休憩を引いた勤務時間」のセルです)

### 試した結果(10パターン)

| 開始〜終了・休憩 | 分 | 小数時間 | 時:分 | 15分切捨(分) |
|---|---|---|---|---|
| 9:00〜18:30・60分 | 510 | 8.5 | 8:30 | 510 |
| 9:00〜17:00・0分 | 480 | 8 | 8:00 | 480 |
| 22:00〜6:00・60分 | 420 | 7 | 7:00 | 420 |
| 23:30〜0:15・0分 | 45 | 0.75 | 0:45 | 45 |
| 9:00〜9:00・0分 | 0 | 0 | 0:00 | 0 |
| 8:45〜12:00・0分 | 195 | 3.25 | 3:15 | 195 |
| 13:00〜17:20・15分 | 245 | 4.08 | 4:05 | 240 |
| 0:00〜23:59・0分 | 1439 | 23.98 | 23:59 | 1425 |
| 6:00〜14:45・45分 | 480 | 8 | 8:00 | 480 |
| 10:10〜10:09・0分 | 1439 | 23.98 | 23:59 | 1425 |

### 合計が24時間を超えるときの表示

合計の表示形式を `h:mm` にすると、24時間を超えた分が消えます。`[h]:mm` と大かっこで囲むのがポイントでした。

| 入力 | `[h]:mm` | `h:mm` |
|---|---|---|
| 7:45、8:15、0:30 | 16:30 | 16:30 |
| 12:30、13:45 | 26:15 | 2:15 |
| 8:00を5回 | 40:00 | 16:00 |

週の合計が「16:00」と出ていたら、40時間働いたのに表示だけ消えている、ということがありえます。

### 小数時間はROUNDで2桁にそろえる

時刻の値に24を掛けると小数の時間になりますが、そのまま掛けた値は誤差を含むことがあります。`=ROUND(D2*24,2)` のように丸めてから使うと、表の数字が安定しました(上の表は全部この式です)。13:00〜17:20・休憩15分は、4.0833…が「4.08」になっています。

### つまずきチェックリスト

- [ ] 開始・終了のセルが「文字」になっていない(左寄せになっていたら文字の可能性。`=ISNUMBER(A2)` がTRUEか確かめる)
- [ ] 同じ時刻(9:00〜9:00)は0になる。24時間勤務を表したいときは別に考える
- [ ] 休憩は「分」で入れて、1440で割って引いている(1時間=60分)
- [ ] 合計のセルは `[h]:mm`
- [ ] 小数にするときは、ROUNDで丸めてから使う
- [ ] 15分単位などの丸めは、会社の規則に合わせる(この記事は規則を判断しません)

### できないこと

- 法定の休憩時間、残業・深夜の割増、給与の判断はしません
- 日をまたいで24時間以上の勤務は、開始と終了の2つの時刻だけでは表せません
- Excelでは未確認です。LibreOfficeで確認したので、本番の表では数行で試してからにしてください
