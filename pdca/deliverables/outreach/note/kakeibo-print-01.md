# 自作の家計簿、印刷したら3ページに割れた話

エクセルで家計簿を作って、紙に印刷して使いたい。
でも印刷すると、右の列だけ別のページに出たり、ページがいくつにも割れたりします。

試してみると、直し方は意外と短くて、**設定は4つだけ**でした。

## 残高の式

支出を入れるたびに残高が減っていく列は、これで作れます(E列、2行目の例)。

```
=IF(D2="","",$H$1-SUM($D$2:D2))
```

- H1に「月の予算」を入れておく
- `$D$2:D2` の最初だけ `$` を付けるのがコツ。下にコピーすると「2行目から今の行まで」の累計になる
- 支出が空欄の行は、残高も空欄になる

30行ぶんの支出を入れて試すと、最後の行の残高は 25,284円。予算100,000円から合計74,716円を引いた数字と一致しました。

## 印刷の4つの設定

「ページレイアウト」タブで、次の順に設定します。

1. 印刷したい範囲を選んで「印刷範囲の設定」
2. 用紙サイズ: A4
3. 向き: 縦
4. 拡大縮小: 「横1ページ・縦1ページ」(1ページに収める)

同じ表で試した結果です(LibreOfficeでPDFにして、ページ数を数えました)。

- 設定なしで、メモの列を広げた表: **3ページ**
- 上の設定をした表: **A4で1ページ**

## 注意

- 1ページに収めると、表が大きいほど文字が小さくなります。縮み具合は測っていないので、印刷プレビューで確かめてください
- 上の結果はLibreOfficeでの確認です。Excelの画面と、実際のプリンターでの印刷は試していません
- 費目の名前が1文字でもずれると、費目別の合計から漏れます(エラーにはなりません)
