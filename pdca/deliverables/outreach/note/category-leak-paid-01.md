# 家計簿の費目別合計が、全体の合計と合わない…原因は「食費 」の1文字でした

費目ごとの合計を出したのに、足したら全体の合計より少ない。
エラーも出ないから、どこが悪いか分からない…。家計簿あるあるですよね。

## 無料でできること: 費目別の合計と、合わない原因の切り分け

明細がA列(費目)とB列(金額)、2行目から入っているなら、食費の合計はこうです。

```
=SUMIFS($B$2:$B$11,$A$2:$A$11,"食費")
```

これで合計が出ます。ただ、**SUMIFSは文字が完全に同じ行だけ**を足します。

試した10行の明細(食費・日用品・交通費)で、食費の合計は3,750円でした。でも目で数えると、食費っぽい行はもっとあります。

- 「食費 」(末尾にスペース)800円
- 「食費(外食)」1,500円

これらは「食費」とは別の文字として扱われ、足されませんでした。**合計が合わない原因は、たいてい費目名のずれ**です。

じゃあ、どれだけ漏れているか、どう直すか。ここから先は有料部分です。

## ここから有料

ここから先は、取りこぼし額の出し方と、直す式2つ、10行の結果の全部です(300円)。

### 試した明細(10行)

| 行 | 費目 | 金額 |
|---|---|---|
| 2 | 食費 | 1,200 |
| 3 | 食費␣(末尾に半角スペース) | 800 |
| 4 | 食費 | 450 |
| 5 | 日用品 | 980 |
| 6 | 食費(外食) | 1,500 |
| 7 | 交通費 | 320 |
| 8 | 日用品␣(末尾に全角スペース) | 600 |
| 9 | 交通費 | 540 |
| 10 | (費目が空欄) | 700 |
| 11 | 食費 | 2,100 |

全明細の合計は9,190円です。

### 式1: 取りこぼし額を出す(まずここ)

```
=SUM($B$2:$B$11)-SUM(E2:E4)
```

E2:E4には、費目ごとの `SUMIFS(…,D2)` の合計が入っているとします。全明細の合計から費目別合計の合計を引くと、**漏れた金額**が出ます。0なら漏れなしです。

試した結果は3,600円でした。

### 式2: 前方一致にする(「食費(外食)」も食費に入れたい)

```
=SUMIFS($B$2:$B$11,$A$2:$A$11,D2&"*")
```

| 費目 | 完全一致(もとの式) | 前方一致 |
|---|---|---|
| 食費 | 3,750 | 6,050 |
| 日用品 | 980 | 1,580 |
| 交通費 | 860 | 860 |

取りこぼしは700円(空欄の行だけ)になりました。注意点は、「食費」で始まる別の費目があると混ざることです。

### 式3: スペースだけ直して完全一致のままにする

```
=SUMPRODUCT((TRIM(SUBSTITUTE($A$2:$A$11,"　"," "))=D2)*$B$2:$B$11)
```

| 費目 | 空白除去後の完全一致 |
|---|---|
| 食費 | 4,550 |
| 日用品 | 1,580 |
| 交通費 | 860 |

取りこぼしは2,200円(「食費(外食)」1,500円+空欄700円)でした。「(外食)」は別費目として扱いたいときはこちらです。

### 3つの式の結果まとめ

| 式 | 取りこぼし額 |
|---|---|
| もとのSUMIFS(完全一致) | 3,600円 |
| 前方一致 | 700円 |
| 空白除去+完全一致 | 2,200円 |

3つとも期待値と一致しました(不一致0件)。残る700円は、費目が空欄の行です。空欄の行は、式では直せないので、元の明細を見て費目を入れるしかありません。

### つまずきチェックリスト

- [ ] 費目別の合計だけ見て安心しない。全体の合計との差(取りこぼし額)を必ず出す
- [ ] 差が0でないときは、末尾スペース・全角スペース・「(外食)」のような付け足しを疑う
- [ ] 前方一致は、「食費」で始まる別の費目まで拾うので、費目名の付け方を確認する
- [ ] 費目が空欄の行は、どの式でも拾えない。明細側に入力する
- [ ] 費目名を入力規則のプルダウンにすると、ずれが減る(この記事では設定方法は検証していません)

### 自分の表で確かめる手順

1. 上の10行をそのまま入れて、3つの式を試す
2. 取りこぼし額が3,600円・700円・2,200円になるか見る
3. 同じなら、自分の明細に入れ替える
