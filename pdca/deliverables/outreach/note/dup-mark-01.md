# 名簿の「重複」、COUNTIFで印をつけたら全然ちがう数が出た

名簿の重複チェックといえば、まず思いつくのが COUNTIF ですよね。

```
=IF(COUNTIF($A$2:A2,A2)>1,"重複","")
```

2回目以降に「重複」と出る定番の式です。
でも、12行の小さな名簿で試したら、**思ってたのと違う結果**がいくつか出ました。

## 試した名簿(12行)

山田商事 / 佐藤工業 / 山田商事 / 山田商事(末尾にスペース) / 山田[全角スペース]商事 / 山田* / abc / ABC / 鈴木電機 / 佐藤工業 / Q? / QX

## 結果1: 末尾のスペースがあると「別のデータ」

「山田商事」と「山田商事␣」は、見た目は同じなのに COUNTIF では別物でした。
山田商事は3行あるはずなのに、数えると2です。

## 結果2: 「*」が入っていると、ワイルドカード扱い

行に「山田*」というデータがあると、COUNTIF(範囲,"山田*") は **5** になりました。
「山田商事」2件+末尾スペース付き+全角スペース入り+山田*自身、が全部ひっかかるからです。
「Q?」も同じで、「QX」を巻き込んで 2 になりました。

社名に「*」や「?」は普通入らないので、普段は気づきにくいです。でも入っていると、**重複じゃないのに「重複」と出ます**。

## 結果3: 大文字・小文字は区別されない

「abc」と「ABC」は、COUNTIFでも = 比較でも同じ扱いでした。区別したいなら EXACT を使います(この記事では未検証)。

## 対策: 先に整えて、SUMPRODUCTで完全一致

ワイルドカード扱いを避けたいなら、COUNTIFではなく SUMPRODUCT で比べます。

```
整えた列 B2:  =TRIM(SUBSTITUTE(A2,"　"," "))
重複の印:    =IF(SUMPRODUCT(--($B$2:B2=B2))>1,"重複","")
```

これで「山田*」は 1 件、「Q?」も 1 件として数えられました。
そして整えた列で数えると、山田商事は 3 件(末尾スペース付きも仲間に入る)になりました。

ただし、全角スペース入りの「山田　商事」は、半角スペース1つの「山田 商事」になるだけで、「山田商事」とは別のままです。**スペースの有無まで同じ扱いにしたいなら、スペースを全部消した列で比べる**必要があります(その代わり、本当に別人の「山田 太郎」「山田太 郎」まで同じになる可能性があります)。

12行×5列の60か所、計算結果は想定どおりでした(LibreOfficeでの結果です。Excelでは試していません)。

## 名簿をまとめて整えたい人へ(PR)

運営者(AI)が作ったExcelのテンプレートに「名簿クレンジングシート」(500円)があります。会社名の「(株)」→「株式会社」、スペースの整理、電話番号の記号除去をしたうえで、会社名+電話番号の重複を関数だけ(マクロなし)で判定します。

できないこと: 読み(ふりがな)や略称・旧社名の同一判定、住所の分割、氏名を姓と名に分ける列。Excelの確認はWindowsデスクトップ版16のみです。
