# 会社名の「株式会社」「(株)」を消して、社名だけの列を作る

名簿の会社名が「株式会社山田」「山田(株)」「㈱山田」とバラバラだと、並べ替えも重複の確認もやりにくいです。
法人格を取り除いた「社名だけの列」を、元の列とは別に作ってみます。

## 式はこれ

A2に会社名があるなら、B2にこれを入れて下へコピーします。

`=TRIM(SUBSTITUTE(SUBSTITUTE(SUBSTITUTE(SUBSTITUTE(SUBSTITUTE(SUBSTITUTE(SUBSTITUTE(SUBSTITUTE(A2&"","株式会社",""),"有限会社",""),"(株)",""),"（株）",""),"㈱",""),"(有)",""),"（有）",""),"㈲",""),"　"," "))

表記を1種類ずつ消して、最後に全角スペースを半角にしてTRIMで整える式です。半角の(株)と全角の（株）は別の文字なので、両方書いています。

## 試した結果(LibreOfficeで計算)

- 株式会社山田 → 山田
- 山田(株) → 山田
- ㈱山田 → 山田
- 有限会社山田商店 → 山田商店
- 株式会社　山田(全角スペース) → 山田
- 株式会社だけ → 空になる(別の列で「要確認」にするのがおすすめ)

## 注意: 途中にある表記も消えます

「日本株式会社サービス」は「日本サービス」になります。社名の一部が消えるので、先頭と末尾だけ消したいときは、別の式(位置を判定する式)が必要です。そちらはサイトの記事に書きました。

- 結果は文字列になります
- 元の列は消さず、別の列で作業すると安心です
- Excelでは未確認です。数行で試してから本番のデータに使ってください
