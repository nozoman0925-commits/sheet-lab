# 家計簿の「前月繰越」、毎月手で打ってませんか?

月ごとにシートを分けていると、月が変わるたびに
「先月の残高、いくらだっけ…」と前のシートを開いて打ち直すことになりがちですよね。

これ、**先月の月末残高を参照するだけ**で自動になります。

## 各月のシートの上に4行

```
A2: 前月繰越   B2: (最初の月だけ手入力)
A3: 収入合計   B3: =SUMIF(A8:A27,"収入",B8:B27)
A4: 支出合計   B4: =SUMIF(A8:A27,"支出",B8:B27)
A5: 月末残高   B5: =B2+B3-B4
```

A8以降は、A列に「収入」か「支出」、B列に金額を入れていきます。

## 翌月はこう

5月のシートのB2に `='4月'!B5`、6月のシートのB2に `='5月'!B5`。
これだけです。

## 試した結果

3パターン・3か月ずつで試しました。

- 通常: 4月の繰越50,000円 → 月末78,000円 → 5月の繰越も78,000円 → 月末66,766円 → 6月の繰越66,766円
- 赤字をはさむ: 4月の月末が-20,000円でも、そのまま5月の繰越になって、5月の月末は30,000円
- 明細が空の月: エラーにならず、0円のまま次の月へ

全部で36か所、期待した数字と一致しました(LibreOfficeでの結果です。Excelでは試していません)。

## つまずきポイント

- 4月の明細を直すと、5月・6月の数字も全部変わります(式のとおりの動きです)
- 「支出 」みたいに末尾にスペースが入ると、SUMIFで拾えず合計がズレます
- 通帳や財布の実際の残高とは別物です。月末に見比べてくださいね
- シートをコピーして翌月を作る方法は、まだ試していません
