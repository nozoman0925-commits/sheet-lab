# 勤務時間の合計が少ない…原因は「文字列の8:00」だった

勤務時間を SUM で合計したら、**エラーも出ないのに、合計が少ない**。
これ、地味に困りますよね。小さな表で試したら、原因の1つが分かりました。

## 試したこと

A1 に「8:00」を**文字列として**入れ、A2 に時刻の値としての 8:00 を入れて、合計しました。
見た目はどちらも「8:00」です。

| 式 | 結果 |
|---|---|
| =SUM(A1:A2) | 8:00 の1つ分だけ(0.3333…) |
| =ISTEXT(A1) | TRUE |
| =TIMEVALUE(A1)*24 | 8 |
| =SUM(TIMEVALUE(A1),A2)*24 | 16 |

**SUM は文字列の「8:00」を、エラーにせず黙って無視しました。**
16時間のはずが8時間分しか出ない、という状態です。

## 見分けるには

- ISTEXT(セル) が TRUE なら文字列です
- 左寄せで表示されることが多いです(右寄せなら値のことが多い、くらいの目安)

## 直すには

文字列の時刻は、TIMEVALUE で時刻の値にできます。

```
=TIMEVALUE(A1)
```

合計は、変換してから足します。

```
=SUM(TIMEVALUE(A1),A2)
```

「8時00分」のような別の書き方の文字列は試していません。

## ついでに: 合計が24時間を超えたら

別の落とし穴もあります。5日分(8:00×5)を合計すると、中身は40時間なのに、表示の書式が h:mm だと **16:00** と出ます。書式を [h]:mm にすると 40:00 と表示されました。合計が24時間未満のうちは違いが出ないので、月末に気づきがちです。

49通りの合計で試した結果は、サイトの記事にまとめています(LibreOfficeでの結果です。Excelでは試していません)。
