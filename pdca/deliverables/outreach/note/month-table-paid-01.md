# 月が変わるたびに、日付と曜日を打ち直してない?年月から全部出す式

シフト表や勤怠表、月初に日付と曜日を手で直してる…あるあるですよね。
月末が28日だったり31日だったりで、毎回ちょっとめんどくさい。

年と月の2セルだけ入れて、あとは全部式で出せます。
12か月分を計算して試したので、その結果ごと置いておきます。

## 無料でできること: 1日と月末を出す

A2に年(2026)、B2に月(10)を入れます。

`=DATE(A2,B2,1)` → その月の1日
`=EOMONTH(C2,0)` → その月の月末日

試した結果です(LibreOfficeで計算)。

| 年月 | 月末日 |
|---|---|
| 2024年2月 | 29日 |
| 2023年2月 | 28日 |
| 2100年2月 | 28日 |
| 2026年4月 | 30日 |

うるう年の判定を自分で書かなくても、DATEとEOMONTHがやってくれました。
ただし、EOMONTHの結果は書式を「日付」にしないと「45351」みたいな数字で出ます。ここ、地味にハマります。

ここまでで足りる人は、ここで終わりでOKです。

## ここから有料

(ここから有料部分: 以下に、5つの式の一覧と全テスト結果、つまずきチェックリストを置く)

### 5つの式(A列=年、B列=月、C列=その月の1日。すべて試した式です)

| やりたいこと | 式 |
|---|---|
| 1日 | `=DATE(A2,B2,1)` |
| 月末の日数 | `=DAY(EOMONTH(C2,0))` |
| 平日の日数(土日を除く。祝日は除かない) | `=NETWORKDAYS(C2,EOMONTH(C2,0))` |
| 土日の日数 | `=DAY(EOMONTH(C2,0))-NETWORKDAYS(C2,EOMONTH(C2,0))` |
| 1日が土日か | `=IF(WEEKDAY(C2,2)>=6,"休","平")` |
| 月曜始まりのカレンダーの行数(週数) | `=ROUNDUP((DAY(EOMONTH(C2,0))+WEEKDAY(C2,2)-1)/7,0)` |

土日の日数は、SUMPRODUCTを使った別の式でも数えて、上の式と同じになることを確かめました。

`=SUMPRODUCT(--(WEEKDAY(C2+ROW($1:$31)-1,2)>=6),--(ROW($1:$31)<=DAY(EOMONTH(C2,0))))`

### 全テスト結果

12か月で試して、6項目×12か月=72件がすべて期待値(Pythonの標準ライブラリで数えた値)と一致しました。

月の例: 2026年10月は平日22・土日9、2026年12月は平日23・土日8、2100年2月は平日20・土日8・週の行数4。
1日が土日になる月(2026年8月は土曜、2026年11月は日曜)も入れて試しています。

### つまずきチェックリスト

- [ ] EOMONTHの結果セルの書式を「日付」にした
- [ ] 平日の日数は祝日を引いていない(祝日は別に一覧が要る。この記事では扱わない)
- [ ] WEEKDAYの第2引数は2(月曜=1〜日曜=7)で、土日は6以上
- [ ] 月末日が30日以下の月で、31日目のセルが空欄になるか確認した
- [ ] 本番の表に使う前に、2月と、1日が土日の月で結果を見た(Excelでは未確認のため)

### 確認の手順

1. 年月を、2024年2月、2023年2月、1日が土曜の月に変えてみる
2. 平日の日数+土日の日数が、月末の日数と合うか見る
3. カレンダーを見て、数え間違いがないか1か月だけ目で確認する

## できないこと

- 祝日の判定はしません(祝日は法律の改正で変わるため、この原稿では扱いません)
- 土日に色を付ける設定、入力規則は、この原稿では試していません
- Excelでは未確認です。LibreOfficeでの結果です
