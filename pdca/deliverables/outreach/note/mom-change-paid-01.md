# 家計簿の「先月より増えた?」を費目別に出す式(先月が0円でエラーにならない版)

食費は先月より何%増えたんだっけ…と割り算したら、先月が0円の費目で「#DIV/0!」。
家計簿あるあるですよね。

## 無料でできること: 増減額と増減率

先月がB列、今月がC列に入っているなら、こうです。

```
増減額 D2: =C2-B2
増減率 E2: =IF(B2=0,"",D2/B2)
```

増減率のセルは表示形式を「パーセンテージ」にします。先月が0円のときは率を出さず、空白にする式です。

試した結果(LibreOfficeで計算)です。

- 食費 30,000→36,000円: 増減額 +6,000、増減率 20%
- 光熱費 36,000→30,000円: 増減額 -6,000、増減率 約-16.7%
- 教養娯楽 0→5,000円: 増減額 +5,000、率は空白(エラーなし)

ただ、空欄のセルがあったり、合計行の率を出したり、「増えた/減った」の文字も付けたい…となると、ここから地味にハマります。

## ここから有料

ここから先は、試した式と、10費目の結果の全部です(300円)。

### 式の一覧(先月=B、今月=C)

| 目的 | 式 |
|---|---|
| 増減額 | `=C2-B2` |
| 増減率(先月0は空白) | `=IF(B2=0,"",D2/B2)` |
| 増・減・同の判定 | `=IF(D2>0,"増",IF(D2<0,"減","同"))` |
| 合計の先月・今月 | `=SUM(B2:B11)` / `=SUM(C2:C11)` |
| 合計の増減率 | 合計行にも同じ増減率の式(合計の先月が0なら空白) |

合計の増減率は、各費目の率を足したり平均したりせず、合計額どうしで計算します。

### 試した結果(10費目)

| 費目 | 先月 | 今月 | 増減額 | 増減率 | 判定 |
|---|---|---|---|---|---|
| 食費 | 30,000 | 36,000 | 6,000 | 20% | 増 |
| 光熱費 | 36,000 | 30,000 | -6,000 | -16.7% | 減 |
| 通信費 | 8,000 | 8,000 | 0 | 0% | 同 |
| 教養娯楽 | 0 | 5,000 | 5,000 | (空白) | 増 |
| 医療 | 0 | 0 | 0 | (空白) | 同 |
| 衣服美容 | 5,000 | 0 | -5,000 | -100% | 減 |
| 交通費 | (空欄) | 3,000 | 3,000 | (空白) | 増 |
| 住居 | 80,000 | 80,000 | 0 | 0% | 同 |
| 日用品 | 1,234 | 2,345 | 1,111 | 90.0% | 増 |
| その他 | (空欄) | (空欄) | 0 | (空白) | 同 |
| 合計 | 160,234 | 164,345 | 4,111 | 2.6% | 増 |

10費目と合計は、すべて期待値と一致しました(不一致0件)。

### つまずきチェックリスト

- [ ] 先月が空欄のセルも、引き算では0として扱われた(交通費・その他)。ただし「文字」が入っていると引き算がエラーになるので、金額の列は数値だけにする
- [ ] 先月0円の費目は、率が計算できないので空白にしている(「増えた」は判定列で分かる)
- [ ] 合計の率は、費目の率の平均ではなく、合計額から計算する(上の表では2.6%)
- [ ] 率の列の表示形式が「標準」だと0.2のように出る。パーセンテージに変える
- [ ] 小数の端数は表示だけで丸まる。値そのものを丸めたいときは ROUND を使う(今回は未使用)

### 自分の表で確かめる手順

1. 先月・今月に、上の表の数字をそのまま入れて、式を下までコピー
2. 結果が上の表と同じか見る(特に先月0円・空欄の行)
3. 同じなら、自分の費目に入れ替える

### 限界

- Excelでは未確認です(LibreOfficeで計算しました)
- 数ヶ月分の推移グラフや、複数月の前月比を一度に出す表は、この式集の範囲外です
- 家計や税の判断はしません
