## 商品名案
工務店・リフォーム店向け|出来高管理表 Excel(工程ごとの進捗率から出来高金額・前回差・未出来高を自動計算・20工程・マクロなし)

## 結果を伝える見出し
- 工程ごとの進捗率を入れるだけで、出来高金額が自動で出る
- 前回までの出来高を入れると、今回の出来高が出る
- 契約額と工程金額の合計が合わないと、点検欄で気づける

## 冒頭3行
工程名・工程金額・進捗率を入力すると、出来高金額(工程金額×進捗率)・今回の出来高・未出来高を自動計算するExcelの表です。
進捗率が0〜100%の範囲外のときや、出来高が前回より減っているときは「確認」欄に表示されます。端数は円未満を四捨五入します。
A4横1ページで印刷できます。確認した環境は【Excelのバージョン】です(下の動作確認表)。

## 動作確認表
| 項目 | 結果 |
|---|---|
| 確認した環境 | Windows デスクトップ版Excel【バージョン】(オーナーPC、【日付】) |
| 確認していない環境 | Mac版Excel / ブラウザ版 / Googleスプレッドシート / スマホアプリ |
| 確認した内容 | 【合格ケース数】。出来高・今回の出来高・未出来高・合計・点検欄(進捗率の範囲外、前回より減少、端数、空欄)【検証記録から転記】 |
| 印刷 | A4横1ページ【倍率の実測値】 |

## 記入例(架空の工事)の説明文
画像は架空の現場「戸建て新築(架空)」の例です。基礎・躯体・内装などの工程に金額と進捗率を入れた状態で、今回の出来高と未出来高が出ています。実在の現場・金額ではありません。

## できないこと(商品ページに明記)
消費税の計算・請求書の作成 / 請負契約上の出来高の認定、検収・支払条件の判断、工事の会計処理 / 21工程以上(行を足すかシートを分ける) / 複数案件の自動合算(案件ごとにシートをコピー) / 工程表(日程)との自動連携。端数の扱いが契約で決まっている場合は、その定めに合わせて式を変えてください。
