## 追記(2026-10-13): 勝ちパターンの反映
各商品の案に、(1)冒頭の1文(誰の・どんな場面の・何がすぐできるか。時間の短縮は検証した範囲だけ)、(2)画面イメージとチェックリストを前に出す構成、(3)最後の「次の段」(同業界の商品、カスタム版の相談=ショップのメッセージ)、(4)改善版の無料再ダウンロードと声の窓口、を追記した。存在しない商品・サービスは書かない(販売中・提供中のものだけ)。

## 追記(2026-10-13): 商品名の付け方
先頭に「誰向け・どんな場面」(例: 工務店・リフォーム会社向け/事務の名簿整理に)を置く。「今日から使える」は、開いてすぐ入力できる商品に限る。「本番運用レディ」など分かりにくい言葉・誇大表現は使わない。

## 追記(2026-10-13): 不安を減らす部分
各商品に「こんな人向け/向いていない人」「対応環境(確認済みはWindowsデスクトップ版Excel 16のみ)」「FAQ3つ」「更新履歴」「実際の画面2〜3枚の指示」を追記。FAQの答えは仕様・検証記録で確かめた範囲だけ。名簿クレンジングシートの行数は検証記録に数字がなく「要確認」と記載(出品文に書く前に商品ファイルで確認)。購入後の案内文は shop-message.md。
