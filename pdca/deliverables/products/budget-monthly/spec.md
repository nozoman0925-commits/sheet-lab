# 仕様: 月間家計簿(A4印刷+Excel入力) slug: budget-monthly
作成: 2026-10-12(クラウド側AI) / 事業C / 種類: **pdf**(xlsxも同梱し、A4で印刷またはPDF出力できるもの)
作るのはオーナーPCのローカルClaude(Microsoft Excelで作成・検証・PDF出力)。販売用ファイルはリポジトリが公開の間は置かない。

## 商品名案・想定ユーザー
- 商品名案: 「月間家計簿(A4・1枚印刷対応)｜費目別集計つき Excelテンプレート(マクロなし)」
- 想定ユーザー: 家計を費目別に見たい個人。Excelに入力しても、印刷して手書きでも使いたい人。

## シート構成(2枚)
1. 「使い方」: 入力するセル(年・月・前月繰越・予算・明細)、色の意味、限界を記載。
2. 「家計簿」(印刷対象。以下のセル番地で作ると下の数式がそのまま使える)
   - A1: タイトル / A3:「年」B3: 入力(例2026)/ C3:「月」D3: 入力(例10)/ A4:「前月繰越」B4: 入力(円)
   - A6〜A11: ラベル、B6〜B11: 集計(下の数式)
   - 費目表: 見出し行13(費目|予算|支出|差額|支出比率)、A14:A23 に費目10個(食費・日用品・住居・光熱費・通信費・交通費・医療・教養娯楽・衣服美容・その他)、24行目が合計
   - 明細: 見出し行29(日付|費目|内容|収入|支出)、30〜69行の40行(A=日付、B=費目[A14:A23のリストから選ぶ入力規則]、C=内容、D=収入、E=支出)
   - 入力規則: B列=リスト(A14:A23)、A列=日付、D・E列=整数。入力セルは薄い色、数式セルは色なし+シート保護なし(利用者が行を足せるよう保護しない)。

## 数式(Excel関数名。マクロ・動的配列関数・LET/LAMBDA不使用。完全一致はSUMPRODUCT)
| セル | 数式 |
|---|---|
| B6 収入合計 | `=SUM(D30:D69)` |
| B7 支出合計 | `=SUM(E30:E69)` |
| B8 収支 | `=B6-B7` |
| B9 月末残高 | `=B4+B8` |
| B10 費目未選択の支出 | `=B7-C24` |
| B11 対象月外の日付の行数 | `=SUMPRODUCT(($A$30:$A$69<>"")*(((YEAR($A$30:$A$69)<>$B$3)+(MONTH($A$30:$A$69)<>$D$3))>0))` |
| C14:C23 費目別支出(14行目の例) | `=SUMPRODUCT(($B$30:$B$69=A14)*$E$30:$E$69)` |
| D14:D23 差額(予算-支出) | `=B14-C14` |
| E14:E23 支出比率 | `=IF($B$7=0,0,C14/$B$7)` |
| B24 / C24 / D24 / E24 | `=SUM(B14:B23)` / `=SUM(C14:C23)` / `=B24-C24` / `=SUM(E14:E23)` |
B14:B23(予算)は入力セル。B10が0でないときは「費目を選んでください」、B11が0でないときは「対象月と違う日付があります」を条件付き書式で赤字表示する(数式は上のセルを参照するだけ)。

## 印刷設定(PDF出力)
- 用紙: A4 / 向き: 縦 / 印刷範囲: A1:E69 / 拡大縮小: 横1ページ×縦1ページに収める / 余白: 狭め(上下1.5cm・左右1.2cm)
- 1ページに収める範囲: 全行(A1:E69)。倍率が70%を下回る場合は行の高さ・フォントを調整し、倍率の実測値を記録する。
- 印刷しない: 「使い方」シート(PDFにも含めない)。入力例は入れず、PDFは空欄の家計簿1ページ。
- 手書き用に、日付・内容・金額セルに罫線を引き、行の高さを手書きできる大きさ(0.6cm以上)にする。

## できないこと
- 銀行・クレジットカード連携や自動取り込み、グラフ、複数月の通年集計、家族での同時編集。
- 1か月40行まで(超える場合は行を挿入して数式の範囲を広げる必要がある。使い方に手順を書く)。
- 費目名の変更は A14:A23 で可能だが、明細の費目は選び直しが必要。
- Excel for Mac・ブラウザ版・スマホアプリでの動作は、確認するまで「未確認」と書く。
- 家計の助言・節約額の保証はしない。
