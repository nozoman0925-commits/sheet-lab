## シート構成(7枚)
1. 「使い方」: 入力する場所(黄色)、1件の流れ(マスター→見積→工程→請求記録→入金)、入力例の消し方、限界、確認用チェック欄の注意書き。
2. 「マスター」: 会社情報・取引先・工事一覧(下の番地)。**工事番号の元データはここだけ**。
3. 「見積」: 明細(1行=1項目)。工事番号を選んで入力する。
4. 「工程」: 工程の一覧とガント棒(6週間)。
5. 「台帳」: 工事ごとの契約額・請求済・入金済・原価・粗利を自動集計(入力は原価のみ)。
6. 「請求」: 請求書1枚(A4縦印刷)。請求記録の番号を選ぶと中身が出る。
7. 「入金管理」: 左=請求記録(どの工事を何%請求したか)、右=入金記録。

## 見積→請求の転記をなくすつなぎ方
- **マスターの工事番号**をすべてのシートが参照する。工事番号は「見積」「工程」の入力規則(リスト=マスター!A40:A59)で選ぶ。台帳・請求は工事番号を再入力しない(マスターを参照する)。
- 見積の金額 → 台帳の契約額は SUMPRODUCT で工事番号が完全一致する行を集計。請求は「請求記録の番号」を選ぶだけで、工事番号・割合・取引先・明細・金額が見積から自動表示される。
- 工事番号に「*」「?」「~」は使えない入力規則(カスタム: `=AND(ISERROR(FIND("*",A5)),ISERROR(FIND("?",A5)),ISERROR(FIND("~",A5)))`)を付ける(MATCHがワイルドカード扱いするため)。貼り付けで入った場合に備え、点検列で検知する(ケース14)。

## 各列の数式(Excel関数名。マクロ・動的配列・LET/LAMBDA不使用。完全一致は SUMPRODUCT か INDEX/MATCH の完全一致)
端数処理は「ROUND(…,6)」で浮動小数点の誤差を先に消してから行う。切り捨て・切り上げは0から遠ざかる/近づく方向(マイナスは絶対値で処理。ROUNDDOWN/ROUNDUP の挙動)。
以降 `端数(x)` は次の式を指す(各セルでは展開して書く): `CHOOSE(マスター!$B$11,ROUNDDOWN(ROUND(x,6),0),ROUND(x,0),ROUNDUP(ROUND(x,6),0))`

### 見積(5〜204行=200明細)
列: A=工事番号(入力) / B=項目 / C=数量 / D=単位 / E=単価(以上入力) / F=金額 / G=連番 / H=キー / I=確認
| セル | 数式(5行目の例) |
|---|---|
| F5 | `=IF($A5="","",CHOOSE(マスター!$B$11,ROUNDDOWN(ROUND(N(C5)*N(E5),6),0),ROUND(N(C5)*N(E5),0),ROUNDUP(ROUND(N(C5)*N(E5),6),0)))` |
| G5(同じ工事の何行目か) | `=IF($A5="","",SUMPRODUCT(--($A$5:$A5=$A5)))` |
| H5(請求の明細引当用キー) | `=IF($A5="","",$A5&"|"&G5)` |
| I5 | `=IF($A5="","",IF(SUMPRODUCT(--(マスター!$A$40:$A$59=$A5))=0,"工事番号がマスターにありません",IF(G5>20,"21行目以降は請求書に表示されません","")))` |

### 工程(5〜204行=200工程。ガント棒 I〜AX=42日)
列: A=工事番号(入力) / B=工程名 / C=担当 / D=開始日 / E=日数(以上入力) / F=終了日 / G=進捗(0〜1、入力) / H=状況 / I4:AX4=日付、I3:AX3=曜日。B2=表示開始日(入力)。
| セル | 数式 |
|---|---|
| F5 | `=IF(OR(D5="",E5=""),"",D5+E5-1)` |
| H5 | `=IF(OR(D5="",E5=""),"",IF(E5<1,"日数を確認",IF(N(G5)>=1,"完了",IF(マスター!$B$12="","",IF(マスター!$B$12>F5,"遅れ",IF(マスター!$B$12>=D5,"進行中","未着手"))))))` |
| I4 / J4 | `=$B$2` / `=I4+1` |
| I3 | `=CHOOSE(WEEKDAY(I4),"日","月","火","水","木","金","土")` |
| I5(棒。1=予定、2=進捗分) | `=IF(OR($D5="",$E5="",$E5<1),"",IF(AND(I$4>=$D5,I$4<=$F5),IF(I$4<$D5+ROUND($E5*N($G5),0),2,1),""))` |
工程の日数は暦日(土日・祝日を除かない)。棒の色は条件付き書式(1=薄色、2=濃色)。

| セル | 数式(40行目の例) |
|---|---|
| F40(取引先名) | `=IF($A40="","",IFERROR(INDEX($B$16:$B$35,MATCH($C40,$A$16:$A$35,0)),"取引先未登録"))` |

| 列/セル | 内容と数式(5行目の例) |
|---|---|
| A5 | `=IF(マスター!A40="","",マスター!A40)` |

| D5 契約額(税抜) | `=IF($A5="","",SUMPRODUCT(--(見積!$A$5:$A$204=$A5),見積!$F$5:$F$204))` |

|---|---|

| セル | 内容 |
|---|---|
| 請求書番号 | `="R-"&TEXT($C$3,"000")` |

| 請求先名 | `=IFERROR(INDEX(マスター!$F$40:$F$59,MATCH($C$4,マスター!$A$40:$A$59,0)),"")` |

| 請求日 | `=IFERROR(INDEX(入金管理!$C$5:$C$44,$C$3),"")` |

- 発行者欄はマスターの会社名・住所・電話・登録番号・振込先を表示。

## インボイスの記載項目は「確認用チェック欄」(請求シート右側。印刷範囲外)
- 請求書に載せる項目のチェック欄(○を入力する黄色セル)と、シートの自動判定(登録番号の形式のみ)を置く。**満たすことを保証する表示は一切しない**(「適合」「OK」とは書かず、「形式OK(実在は確認しません)」まで)。
- 項目の文言は、ローカル側が国税庁の公式案内(適格請求書の記載事項)を**開いて確認した内容**に合わせて入れる。クラウド側では出典を開いていないため、項目名は仕様に固定しない。使い方シートに「最終確認は国税庁の案内または税理士に」と書く。
- 計算結果の消費税は端数処理の設定どおりの数字であり、税務上の正しさは保証しない。

## 入力欄とシート保護
- 入力欄は**黄色**、それ以外は数式セルとしてロック。**シート保護はパスワードなし**(使う人が解除して列を足せる)。入力規則: 工事番号=リスト(上記の禁則つき)、数量・単価=数値、日付=日付、割合=0より大きく1以下、端数処理=1〜3、請求記録No=整数1〜40。
- 入力例(K-001〜K-003など)は黄色セルに入れておき、使い方に消し方を書く。

## 印刷設定
- 「請求」: A4縦・印刷範囲は請求書本体のみ(確認用チェック欄を除く)・1ページ。「台帳」: A4横・1ページ。「工程」: A4横・6週間表示1ページ。「見積」: A4縦(明細が多い場合は複数ページ可)。

## できないこと
- 消費税の区分・軽減税率・複数税率の混在、インボイス要件を満たすことの判定、源泉徴収、工事の会計処理(完成基準・進行基準)。税・法令の判断はしない。
- 21工事以上、見積201明細以上、40件を超える請求記録、1工事あたり20行を超える明細の請求書表示(増やしたいときは行を足すか別ファイルで運用)。
- 土日・祝日を除いた工程日数、複数人の同時編集、請求書の送付(PDF出力して送るのは使う人)。
- 既存の単品(見積・工程・台帳)ファイルのデータの自動取り込み(新しいブックに入力し直す)。
- Excel for Mac・ブラウザ版・スマホアプリでの動作は確認するまで「未確認」と書く。
