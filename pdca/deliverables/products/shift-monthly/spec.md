# 仕様: 月間シフト表(A4横・最大15人) slug: shift-monthly
作成: 2026-10-12(クラウド側AI) / 事業C / 種類: **pdf**(xlsxも同梱し、A4横で印刷またはPDF出力できるもの)
作るのはオーナーPCのローカルClaude(Microsoft Excelで作成・検証・PDF出力)。販売用ファイルはリポジトリが公開の間は置かない。

## 商品名案・想定ユーザー
- 商品名案: 「月間シフト表(A4横・15人・日付と曜日が自動)｜勤務時間の自動集計つき Excelテンプレート(マクロなし)」
- 想定ユーザー: 小規模店舗・教室・クリニックなどで、1か月分のシフトを手作業(Excel入力または印刷して手書き)で作る人。

## シート構成(2枚)
1. 「使い方」: 年月の入力、勤務コード表の編集、シフトの入力、印刷手順、限界を記載。
2. 「シフト表」(印刷対象。以下の番地で作ると下の数式がそのまま使える)
   - A1: タイトル / A3「年」B3: 入力(例2026) / C3「月」D3: 入力(例10)
   - 5行目: A5「氏名」、B5:AF5 = 日付(1日〜31日。表示形式は「d」)。6行目: B6:AF6 = 曜日
   - 7〜21行: 15人分。A=氏名(入力)、B:AF=その日の勤務コード(入力。入力規則=リスト A27:A31)
   - AG6「出勤日数」、AH6「実働時間」、AI6「未登録コード」(7〜21行に集計)
   - 22行: A22「出勤人数」、B22:AF22 = 日ごとの出勤人数。24行: A24「実働時間合計」B24
   - 勤務コード表: 見出し行26(コード|開始|終了|休憩(分)|実働(時間))、27〜31行の5コード。初期値: 休(開始・終了なし)/早 9:00-17:00 休憩60/遅 13:00-21:00 休憩60/通 10:00-19:00 休憩60/夜 22:00-6:00 休憩60。A27は必ず「休」(出勤に数えないコード)。
   - 入力セルは薄い色、数式セルは色なし。シート保護なし。コード表の開始・終了は時刻形式、休憩は整数(分)。

## 数式(Excel関数名。マクロ・動的配列関数・LET/LAMBDA不使用。完全一致はSUMPRODUCT)
| セル | 数式 |
|---|---|
| B5 | `=DATE($B$3,$D$3,1)` |
| C5〜AF5(C5の例。左隣を参照) | `=IF(B5="","",IF(MONTH(B5+1)=$D$3,B5+1,""))` |
| B6〜AF6(B6の例) | `=IF(B5="","",CHOOSE(WEEKDAY(B5),"日","月","火","水","木","金","土"))` |
| E27〜E31 実働(E27の例) | `=IF(OR(B27="",C27=""),0,MAX(0,MOD(C27-B27,1)*24-D27/60))` |
| AG7 出勤日数(7行目の例) | `=SUMPRODUCT(($B7:$AF7<>"")*($B7:$AF7<>$A$27)*($B$5:$AF$5<>""))` |
| AH7 実働時間 | `=SUMPRODUCT(($B7:$AF7=$A$27:$A$31)*($B$5:$AF$5<>"")*$E$27:$E$31)` |
| AI7 未登録コード | `=SUMPRODUCT(($B7:$AF7<>"")*1)-SUMPRODUCT(($B7:$AF7=$A$27:$A$31)*1)` |
| B22 出勤人数(B列の例) | `=IF(B$5="","",SUMPRODUCT((B$7:B$21<>"")*(B$7:B$21<>$A$27)))` |
| B24 | `=SUM(AH7:AH21)` |
AI列が0でない行は条件付き書式で赤字(「コード表にない文字があります」)。曜日が「土」「日」の列見出しは色を変える(条件付き書式。祝日は自動判定しない=できないこと)。
注意: 行方向(B7:AF7)と列方向(A27:A31)の比較は、SUMPRODUCT内で表になる。ExcelでもLibreOfficeでも同じ結果になる想定だが、Excelでの確認はローカル側(検証ケース1〜3)。

## 印刷設定(PDF出力)
- 用紙: A4 / 向き: 横 / 印刷範囲: A1:AI31 / 拡大縮小: 横1ページ×縦1ページに収める / 余白: 狭め(上下1.5cm・左右1.0cm)
- 1ページに収める範囲: A1:AI31(シフト表とコード表の両方)。倍率が60%を下回る場合は列幅(日付列は幅3前後)・フォントを調整し、倍率の実測値を記録する。
- 「使い方」シートはPDFに含めない。PDFは年月に例の値を入れず、空欄のシフト表1ページ(手書き用に氏名・シフト欄の行高0.7cm以上)。

## できないこと
- 祝日の自動判定、法定の休憩・残業・休日の判定、人件費や給与の計算、深夜割増の計算。
- 労働時間の適法性は判断しない。実働は「終了-開始-休憩」の単純計算で、労務管理の助言ではない(法令に関わる内容は、公式の出典を確認してから別途追記する)。
- 16人以上、1日に複数の勤務(分割勤務)、30分未満の細かい勤務区分の管理(コード表を増やす場合は行の挿入と数式範囲の拡張が必要)。
- 複数月の自動引き継ぎ、希望休の収集、自動割り当て、共同編集。
- Excel for Mac・ブラウザ版・スマホアプリでの動作は確認するまで「未確認」と書く。
