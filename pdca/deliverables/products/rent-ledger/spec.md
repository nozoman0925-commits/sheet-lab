# 仕様: 家賃入金管理表(月別の入金・滞納の見える化) slug: rent-ledger
作成: 2026-10-13(クラウド側AI) / 事業G(業界特化・業界=不動産・想定価格=1,980円) / 種類: **xlsx**(マクロなし・動的配列なし・LET/LAMBDAなし)
作るのはオーナーPCのローカルClaude(Microsoft Excelで作成・検証)。販売用ファイルはリポジトリが公開の間は置かない。税・法令の判断はしない(家賃の滞納への対応、督促、契約解除、敷金の扱いなどは扱わない。入力された金額と日付を集計・比較するだけ)。

## 商品名案・想定ユーザー
- 商品名案: 「家賃入金管理表(月別の入金・滞納日数を自動表示)｜小規模な大家さん・管理者向け Excel(マクロなし・20室)」
- 想定ユーザー: アパート・貸家を数室〜20室持つ大家、小規模な管理者。通帳を見ながら「今月はだれが入金済みで、だれが未入金か」を1枚で確認したい人。不動産セット(9,800円)の1本目の候補。

## シート構成(4枚)
1. 「使い方」: 入力する場所(薄い色)、部屋Noの決め方、対象月の入れ方(その月の1日の日付)、基準日の使い方、限界、入力例の消し方。
2. 「入居者」(5〜24行=20室): A 部屋No(入力) / B 入居者名(入力。空室は空欄でよい) / C 月額家賃(入力。数値) / D 支払期限日(入力。毎月の何日か。1〜28の整数)
3. 「入金記録」(5〜504行=500件): A 入金日(入力) / B 部屋No(入居者のA列と同じ文字。入力規則で入居者A5:A24のリストから選ぶ) / C 対象月(入力。その月の1日の日付。例 2026/10/1) / D 金額(入力。数値。返金や調整はマイナス) / E 確認(数式)
4. 「月次」: B2 対象月(入力。その月の1日) / B3 基準日(入力。今日の日付を手入力。TODAY()は使わない=過去月の確認が再現できるように) / 5〜24行が部屋ごとの表 / 26行が合計 / 28〜29行が点検・滞納集計

## 数式(Excel関数名。完全一致はSUMPRODUCT。SUMIFS/COUNTIFは部屋Noに「*」「?」が入るとワイルドカード扱いになるため部屋Noの突き合わせには使わない)
月次の5行目の例(24行までコピー。入居者の同じ行番号を参照):
| セル | 数式 |
|---|---|
| A5 部屋No | `=IF(入居者!A5="","",入居者!A5)` |
| B5 入居者名 | `=IF($A5="","",入居者!B5)` |
| C5 請求額 | `=IF($A5="","",N(入居者!C5))` |
| D5 期限日 | `=IF($A5="","",DATE(YEAR($B$2),MONTH($B$2),MIN(N(入居者!D5),28)))` |
| E5 入金額 | `=IF($A5="","",SUMPRODUCT(--(入金記録!$B$5:$B$504=$A5),--(入金記録!$C$5:$C$504>=DATE(YEAR($B$2),MONTH($B$2),1)),--(入金記録!$C$5:$C$504<DATE(YEAR($B$2),MONTH($B$2)+1,1)),入金記録!$D$5:$D$504))` |
| F5 未入金額 | `=IF($A5="","",C5-E5)`(過入金のときはマイナスになる) |
| G5 状況 | `=IF($A5="","",IF(C5=0,"請求なし",IF(E5>C5,"過入金",IF(E5=C5,"入金済",IF($B$3<=D5,"期限前","滞納")))))` |
| H5 滞納日数 | `=IF($A5="","",IF(G5="滞納",$B$3-D5,""))` |
| 合計 C26, E26, F26 | `=SUM(C5:C24)` など。F26は過入金のマイナスを含む差引になる(使い方に明記) |
| B28 滞納の件数 | `=COUNTIF(G5:G24,"滞納")` |
| B29 滞納の未入金額の合計 | `=SUMIF(G5:G24,"滞納",F5:F24)` |
| 入金記録 E5 | `=IF(B5="","",IF(SUMPRODUCT(--(入居者!$A$5:$A$24=B5))=0,"部屋Noが入居者にありません",""))` |
| 入金記録 F2(要確認件数) | `=COUNTIF(E5:E504,"?*")` |
対象月の突き合わせは「対象月が月初以上、翌月初未満」の日付範囲にする(入力された日付が1日でなくても同じ月なら集計される)。入金日ではなく対象月で集計するため、前払い・遅れて入金された分も対象月に正しく入る。
条件付き書式: G列「滞納」=赤、「期限前」=黄、「過入金」=青、H列は滞納日数が30以上で太字赤。

## 印刷設定
- 「月次」: A4横 / 印刷範囲 A1:H29 / 横1ページに収める。「入居者」「入金記録」は印刷対象外。
- 画面表示: 月次の見出し行(4行目)を固定。

## 検証ケース(私がLibreOfficeで同じ式を試作して再計算し、ケース1〜9の期待値と一致を確認済み。最終確認はExcelで)

| # | 内容 | 期待値(基準日=2026/10/20) |
|---|---|---|
| 1 | 101: 10/3に50,000の入金 | E=50,000、F=0、状況=入金済 |
| 2 | 102: 30,000と30,000の2回に分けて入金(合計60,000) | E=60,000、状況=入金済。期限日=10/28 |
| 3(境界) | 103: 20,000のみ入金、期限10/25、基準日10/20 | E=20,000、F=25,000、状況=期限前、滞納日数=空欄 |
| 4(境界) | 104: 40,000のみ入金、期限10/20、基準日=期限日 | 状況=期限前(期限当日は滞納にしない)、滞納日数=空欄 |
| 5(境界) | 同上、基準日を10/21にする | 状況=滞納、滞納日数=1、滞納の件数が1つ増える |
| 6 | 105: 対象月10月の入金なし(9月分55,000の記録はある)、期限10/1 | E=0(9月分は10月に入らない)、F=55,000、状況=滞納、滞納日数=19 |
| 7(境界) | 部屋No「A-*」に10,000の入金 | 「A-*」のE=10,000のみ。101〜107の入金額を巻き込まない |
| 8(境界) | 106: 月額家賃が空欄 | C=0、状況=請求なし、エラーなし |
| 9 | 107: 40,000の家賃に45,000入金 | F=-5,000、状況=過入金。F26(未入金額の合計)は過入金を差し引いた105,000になる。合計: C26=330,000、E26=225,000 |
| 10(基準日10/20の集計) | 滞納の件数・額 | B28=1、B29=55,000。基準日10/21なら B28=2、B29=85,000 |
| 11 | 入金記録の確認 | 部屋No「999」(入居者にない)の行=「部屋Noが入居者にありません」、F2=1 |
| 12(Excel確認) | 入居者・入金記録を全部空欄にする | 数式がエラーを出さない |
| 13(Excel確認) | 入力規則 | 入金記録Bが入居者のリストから選べる、Dは数値のみ、入居者Dは1〜28の整数のみ |
| 14(印刷確認) | 月次をPDF出力 | A4横1ページ、A〜H列が切れずに入る |
ケース1〜11はクラウド側のLibreOfficeで確認済み(試作の再計算値)。12〜14はExcelでの手動確認で、ローカル側が行う。
