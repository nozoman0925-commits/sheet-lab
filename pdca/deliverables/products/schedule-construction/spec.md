# 仕様: 工事・リフォーム用 工程表(ガント風・A4横・20工程) slug: schedule-construction
作成: 2026-10-12(クラウド側AI) / 事業G(業界特化)・C(印刷) / 種類: **pdf**(xlsxも同梱し、A4横で印刷またはPDF出力できるもの)
作るのはオーナーPCのローカルClaude(Microsoft Excelで作成・検証・PDF出力)。販売用ファイルはリポジトリが公開の間は置かない。法令に関わる記述はなし(工期の適法性・安全管理は扱わない)。

## 商品名案・想定ユーザー
- 商品名案: 「工事・リフォーム用 工程表テンプレート(A4横・20工程・6週間表示)｜棒グラフ自動表示・遅れ判定つき Excel(マクロなし)」
- 想定ユーザー: 工務店・リフォーム業・一人親方で、1現場の工程を施主や職人に見せる1枚にまとめたい人。見積書(工事・リフォーム用、980円)と同じ現場で使える。

## シート構成(2枚)
1. 「使い方」: 表示開始日・基準日・工程の入力、棒の色の意味、印刷手順、限界。
2. 「工程表」(印刷対象。以下の番地で作ると下の数式がそのまま使える)
   - A1: タイトル(現場名を入力できる)。A3「表示開始日」B3: 入力(日付。月曜始まりにしておくと見やすいが任意)。D3「基準日」E3: 入力(任意。今日の日付を手入力。空欄なら状況の遅れ判定をしない)
   - 5行目: A5「工程名」B5「担当」C5「開始日」D5「日数」E5「終了日」F5「進捗」G5「状況」、H5:AW5 = 日付(42日分=6週間、表示形式「d」)。6行目: H6:AW6 = 曜日
   - 7〜26行: 20工程。A,B,C,D,F=入力(薄い色)、E,G,H:AW=数式。F=0〜1(表示形式は%)
   - 28〜31行(集計): A28「全体の開始日」B28 / A29「全体の完了予定日」B29 / A30「全体の日数」B30 / A31「表示範囲外の工程数」B31
   - 工程の日数は暦日(土日・祝日を除かない)。休工日の自動除外はしない。

## 数式(Excel関数名。マクロ・動的配列関数・LET/LAMBDA不使用)
| セル | 数式 |
|---|---|
| H5 | `=$B$3` |
| I5〜AW5(I5の例。左隣を参照) | `=H5+1` |
| H6〜AW6(H6の例) | `=CHOOSE(WEEKDAY(H5),"日","月","火","水","木","金","土")` |
| E7(終了日。7行目の例) | `=IF(OR(C7="",D7=""),"",C7+D7-1)` |
| G7(状況) | `=IF(OR(C7="",D7=""),"",IF(D7<1,"日数を確認",IF(N(F7)>=1,"完了",IF($E$3="","",IF($E$3>E7,"遅れ",IF($E$3>=C7,"進行中","未着手"))))))` |
| H7〜AW26(H7の例。棒) | `=IF(OR($C7="",$D7="",$D7<1),"",IF(AND(H$5>=$C7,H$5<=$E7),IF(H$5<$C7+ROUND($D7*N($F7),0),2,1),""))` |
| B28 | `=IF(COUNT(C7:C26)=0,"",MIN(C7:C26))` |
| B29 | `=IF(COUNT(E7:E26)=0,"",MAX(E7:E26))` |
| B30 | `=IF(OR(B28="",B29=""),"",B29-B28+1)` |
| B31 | `=COUNTIFS(C7:C26,">"&$AW$5)+COUNTIFS(E7:E26,"<"&$H$5)` |
棒の表示: セルの値は 1(予定)・2(完了分)。表示形式を `;;;` にして数字は見えなくし、条件付き書式で 1=薄い青・2=濃い青に塗る。日付列の見出し(5〜6行目)は、曜日が土=青系・日=赤系の文字色(条件付き書式)。G列が「遅れ」なら赤字。基準日E3の列は見出しに枠線(条件付き書式 `=H$5=$E$3`)。祝日は自動判定しない。
完了分の日数 = ROUND(日数×進捗, 0)(0.5は切り上げ)。例: 5日で進捗50% → 3日分が濃色。

## 印刷設定(PDF出力)
- 用紙: A4 / 向き: 横 / 印刷範囲: A1:AW31 / 拡大縮小: 横1ページ×縦1ページに収める / 余白: 狭め(上下1.5cm・左右1.0cm)
- 日付列の幅は2.3前後、工程名は18前後。倍率の実測値を記録する(目安は80%前後だが未測定。60%を下回るなら列幅・フォントを調整)。「使い方」シートはPDFに含めない。
- PDFは、空欄の工程表1ページ(手書き用に工程の行高0.7cm以上)。入力例を入れた見本は商品画像用に別ファイルにしてよい。

## できないこと
- 土日・祝日・雨天の休工日の自動除外(日数は暦日)、工程の前後関係(依存関係)の自動調整、クリティカルパスの計算。
- 工期の適法性・安全管理・人員配置の判断、原価や請求の計算(見積書・請求書は別商品)。
- 21工程以上、6週間(42日)を超える表示(表示開始日を動かして複数枚にする運用)。
- 共同編集、進捗の自動更新、他の予定表との連携。
- Excel for Mac・ブラウザ版・スマホアプリでの動作は確認するまで「未確認」と書く。
