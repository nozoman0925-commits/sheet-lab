# 名簿クレンジングシート v1 再生成仕様(商品ファイルが無い場合用)
商品ファイル本体は公開しない方針。以下の仕様と検証ケースから、openpyxl + LibreOffice再計算で再生成できる。

## 設計
- シート「名簿」: A列=会社名(入力)、B列=電話番号(入力)。C列以降が整形結果。1行目は見出し。数百行分に数式を事前入力(合計約1,500数式)
- 会社名整形: TRIM + 全角スペース→半角スペース + 法人格置換(SUBSTITUTEの入れ子)。置換対象: 半角「(株)」→株式会社 / 全角「（株）」→株式会社 / 「㈱」→株式会社(有限会社の同様の置換は同形式。(有)(有)全角)
- 全角英数/半角カナの統一は関数1つでは不可(ASC/JISは片方向)。範囲外と明記する(記事 hyouki-yure-kansu 参照)
- 電話番号整形: SUBSTITUTEで「-」「ー」「(」「)」「（」「）」スペースを除去
- 重複判定: 整形後の会社名+電話番号でCOUNTIF。2件目以降に「重複」を表示
- 動的配列関数(UNIQUE/FILTER等)は使わない(LibreOffice検証不可・#SPILL!回避のため)

## 検証ケース(期待値)
| 入力 | 期待 |
|---|---|
| (株)山田商事 | 株式会社山田商事 |
| （株）山田商事 | 株式会社山田商事(全角カッコ版が半角と別の文字として置換されること) |
| ㈱山田商事 | 株式会社山田商事 |
| 株式会社 山田商事(スペース) | スペース整理後の表記が定義どおり |
| 03-1234-5678 / (03)1234-5678 | 0312345678 系(記号除去) |
| 上記の同一会社3行 | 2行目以降が重複 |
過去の不具合: 全角カッコ版の置換元が半角と同一文字になっていた → 必ず全角ケースを入れる。
検証手順: 再計算後、全セルで #NAME? #VALUE! #SPILL! #N/A #REF! #DIV/0! が0件であること。
