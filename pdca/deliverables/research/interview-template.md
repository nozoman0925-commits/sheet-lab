# 聞き取りの質問と記録の型(試用者向け)
工務店の事務セットを試してくれた人に、**事実**を聞くための質問と、記録の型です。話すのはオーナー。AIは送信・投稿しません。

## 目的
- 聞くのは事実だけ(いつ・何を使い・何分かかったか、どこで手が止まったか)。「使いやすかったですか」「いいと思いますか」は聞かない(気を遣った答えになるため)。
- 価格と導入サポートに需要があるかを、実際の反応で確かめる(METRICS.md の「判断の材料」に入る)。

## 進め方
- 30分。その場で一緒に、事務セットに実際の工事1件(または架空の1件)を入れてもらい、手が止まったところを見る。
- 録音するなら、**必ず相手の許可を取る**。許可がなければメモだけにする。
- 感想や声を商品ページに載せる場合は、載せる文面を見せて許可を得る(許可なし・未確認は載せない)。声を作らない。

## 質問(固定の6つ)
1. 最後に見積書を作ったのはいつで、何を使い、何分かかりましたか。
2. 見積から請求まで、同じ内容を何回打ち直していますか。
3. 今の方法で困った出来事は何ですか(請求の漏れ、計算の間違いなど)。
4. 事務セットを触って、最初に手が止まったところはどこですか。
5. これが月額¥980なら使いますか。¥3,980の買い切りなら買いますか。どちらでもないですか。
6. 同業者で、これを欲しがりそうな人はいますか。

### 追加で聞くこと
- 導入を一緒にやってくれるサポート(オンライン30分)があったら欲しいですか。
- スマホで見たいですか。複数人で使いたいですか。
- 今、いちばん時間がかかっている事務は何ですか。

## オーナーがメモを渡す方法
- pdca/INBOX.md に貼る、または会話中のClaudeに渡す。**実名は書かなくてよい**(A社などでよい)。電話番号・住所などの個人情報は書かない。

## 記録の型(コピーして使う。ファイル名例: interviews/2026-10-29-A社.md)
```
日付:
相手(匿名。A社など / 業種 / 人数):
Q1 最後の見積(いつ・何を使い・何分):
Q2 打ち直しの回数:
Q3 困った出来事:
Q4 最初に手が止まったところ:
Q5 価格の反応(月額¥980 / 買い切り¥3,980 / どちらでもない。払ってもよい金額):
Q6 同業者の心当たり:
導入サポート(オンライン30分)への反応:
スマホ・複数人の要望:
いちばん時間がかかっている事務:
事務セットへの改善点:
商品ページに声を載せる許可(あり / なし / 未確認):
※「答え」は相手が言ったことだけを書く。要約や言い換えで足さない。
```
記録は interviews/ に保存し、METRICS.md の「判断の材料」にリンクする。
