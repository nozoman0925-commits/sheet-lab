「今月、完工した工事はいくらで、粗利はいくら残ったのか」——工事台帳はあるのに、月が終わってから電卓で足し直している、という工務店・リフォーム店は少なくありません。**完了日の月ごとに「完工件数・完工高・粗利・粗利率」を並べる**と、忙しい月と薄利だった月が見えてきます。

この記事では、工事ごとに契約金額・原価合計・完了日を1行ずつ入れ、**集計の開始月を1つ決めるだけで、12か月分の月別集計**を出す式を示します。完了日が空欄の工事は「進行中」として集計から外し、完工済みなのに原価が空欄の行は、粗利が実際より大きく出てしまうので**数字を出さずに止めます**。

出典: 筆者がLibreOfficeで計算して確認(検証スクリプト: site/verify/monthly_completion.py)。外部サイトの説明は参照していません。**Excelでは未確認**です。使うのはIF・OR・NOT・ISNUMBER・INT・COUNTIF・DATE・YEAR・MONTH・EDATE・SUMIFS・SUMPRODUCTという一般的な関数ですが、本番で使う前に、数行を手計算と見比べてください。この記事は表の作り方の説明です。**売上をいつ計上するか(完成基準・進行基準など)や、決算・税務の扱いは、会社の経理のルール(必要なら税理士)に従ってください**。

## 先に結論: 完了日から「完工月」を作り、SUMIFSで月ごとに足す

- 完了日が入っている行 → **完工**。完了日の「月の1日」を、完工月として別の列に作る
- 完了日が空欄の行 → **進行中**。完工高にも粗利にも入れない
- 粗利 = 契約金額 − 原価合計、粗利率 = 粗利 ÷ 契約金額
- 月別の表は、開始月のセルから12か月分を `EDATE` で並べ、`SUMIFS` で完工月が一致する行だけを足す

完工月を「その月の1日」にそろえるのがコツです。日付そのものを範囲で比べるより、月の1日どうしの一致で数えるほうが、月末日(10/31)と月初(11/1)の取り違えが起きにくくなります。

## Excelの式

シート名は「完工」。2行目から使います。

| 列 | 内容 | 入れるもの |
|---|---|---|
| A | 工事番号 | 手入力(例: K-001) |
| B | 工事名 | 手入力 |
| C | 契約金額 | 手入力(1以上の整数。追加工事を含む現在の金額) |
| D | 原価合計 | 手入力(0以上の整数。進行中は空欄でもよい) |
| E | 完了日 | 手入力(日付。完工したら入れる。進行中は空欄) |
| F | 区分 | 式 |
| G | チェック | 式 |
| H | 完工月 | 式(月の1日) |
| I | 粗利 | 式 |
| J | 粗利率 | 式 |
| S2 | 集計の開始月 | 日付(例: 2026/04/01。月の途中の日付でもよい) |

```
G2: =IF(A2&B2&C2&D2&E2="","",IF(A2="","工事番号が空欄",
      IF(COUNTIF($A$2:$A$1000,A2)>1,"工事番号が重複",
      IF(C2="","契約金額が空欄",IF(NOT(ISNUMBER(C2)),"契約金額が数字でない",
      IF(OR(C2<1,C2<>INT(C2)),"契約金額は1以上の整数",
      IF(D2="",IF(E2="","","原価が空欄"),
      IF(NOT(ISNUMBER(D2)),"原価が数字でない",
      IF(OR(D2<0,D2<>INT(D2)),"原価は0以上の整数",
      IF(E2="","",IF(NOT(ISNUMBER(E2)),"完了日が日付でない",
      IF(OR(E2<1,E2<>INT(E2)),"完了日が日付でない","")))))))))))))
F2: =IF(OR(G2<>"",A2&B2&C2&D2&E2=""),"",IF(E2="","進行中","完工"))
H2: =IF(F2="完工",DATE(YEAR(E2),MONTH(E2),1),"")
I2: =IF(F2="完工",C2-D2,"")
J2: =IF(F2="完工",(C2-D2)/C2,"")
```

E列とS2は「日付」の表示形式、H列は「yyyy/mm」の表示形式、C・D・I列は「数値(桁区切り)」、J列は「パーセンテージ」にします。

月別の表は、右側のL〜P列に置きます(範囲は1000行まで)。

```
L2:  =IF(ISNUMBER($S$2),DATE(YEAR($S$2),MONTH($S$2),1),"")
L3:  =IF(L2="","",EDATE(L2,1))          (L13まで下にコピー)
M2:  =IF(L2="","",COUNTIF($H$2:$H$1000,L2))                    ← 完工件数
N2:  =IF(L2="","",SUMIFS($C$2:$C$1000,$H$2:$H$1000,L2))        ← 完工高
O2:  =IF(L2="","",SUMIFS($I$2:$I$1000,$H$2:$H$1000,L2))        ← 粗利
P2:  =IF(L2="","",IF(N2=0,"",O2/N2))                           ← 粗利率   (M2〜P2を13行目までコピー)
M14: =IF(L2="","",SUM(M2:M13))   N14・O14も同様。  P14: =IF(L2="","",IF(N14=0,"",O14/N14))
M15: =IF(L2="","",COUNT($H$2:$H$1000)-M14)                     ← 集計期間の外で完工した件数
M16: =COUNTIF($F$2:$F$1000,"進行中")                           ← 進行中の件数
M17: =SUMPRODUCT(--(LEN($G$2:$G$1000)>0))                      ← チェックが出ている行数
```

合計の粗利率は、月ごとの粗利率を平均せず、**粗利の合計 ÷ 完工高の合計**で出しています(大きな工事の月と小さな工事の月を、同じ重さで平均してしまわないためです)。

## 実際に計算して確認した結果

集計の開始月を2026/04にして、契約金額100,000円・原価60,000円(粗利40,000円)の工事1件で、完了日だけを変えた結果です。

| 完了日 | 入る月 | 備考 |
|---|---|---|
| 2026/10/31(月末) | 2026/10 | 10月に入る |
| 2026/11/01(月初) | 2026/11 | 11月に入る |
| 2026/04/01(期間の最初の日) | 2026/04 | 集計に入る |
| 2026/03/31(期間の前日) | - | 集計期間の外(M15が1) |
| 2027/03/31(12か月目の最後の日) | 2027/03 | 集計に入る |
| 2027/04/01(期間の翌日) | - | 集計期間の外(M15が1) |
| 2028/02/29(うるう日、開始月は2028/01) | 2028/02 | 集計に入る |

開始月のセルに2026/04/15のように月の途中の日付を入れても、4月分として数えます。開始月が空欄や文字のときは、月別の表を空にします(エラーは出しません)。

6件を入れた集計の確認では、次の結果になりました。

| 工事 | 契約金額 | 原価 | 完了日 | 扱い |
|---|---|---|---|---|
| K-001 | 1,000,000 | 700,000 | 2026/10/05 | 10月に入る(粗利300,000) |
| K-002 | 500,000 | 350,000 | 2026/10/31 | 10月に入る(粗利150,000) |
| K-003 | 800,000 | 560,000 | 2026/11/01 | 11月に入る(粗利240,000) |
| K-004 | 900,000 | 100,000 | 空欄 | 進行中(集計に入らない) |
| K-005 | 300,000 | 200,000 | 2027/06/01 | 集計期間の外(M15が1) |
| K-006 | 400,000 | 空欄 | 2026/10/09 | 「原価が空欄」で止める |

| 月 | 件数 | 完工高 | 粗利 | 粗利率 |
|---|---|---|---|---|
| 2026/10 | 2 | 1,500,000 | 450,000 | 30.0% |
| 2026/11 | 1 | 800,000 | 240,000 | 30.0% |
| 合計 | 3 | 2,300,000 | 690,000 | 30.0% |

進行中は1件、チェックが出ている行は1件です。K-006を止めずに計算すると、原価0円の工事として粗利400,000円・粗利率100%が出て、10月の粗利が実際より大きく見えてしまいます。そのため、完工済みで原価が空欄の行は集計に入れません。

入力ミスの行は、区分・完工月・粗利・粗利率を空欄にして、G列にこう出ます。

| 入力ミス | チェック |
|---|---|
| 工事番号が空欄 | 工事番号が空欄 |
| 工事番号が重複(K-001とk-001) | 工事番号が重複 |
| 契約金額が空欄 | 契約金額が空欄 |
| 契約金額が「10万」・全角「１００，０００」 | 契約金額が数字でない |
| 契約金額が0・小数 | 契約金額は1以上の整数 |
| 完工済み(完了日あり)で原価が空欄 | 原価が空欄 |
| 原価が「6万」 | 原価が数字でない |
| 原価がマイナス・小数 | 原価は0以上の整数 |
| 完了日が文字の「10/05」・全角の「２０２６/１０/０５」・0 | 完了日が日付でない |
| すべて空欄の行 | (何も出さない) |

原価が0円の完工は、粗利が契約金額と同じになりますが、入力としては通します(無償の工事や、原価の記録が別にある場合を想定しています)。原価がまだ入っていないだけなら、空欄のまま完了日も入れず「進行中」にしておくと、粗利が膨らみません。赤字の工事(原価が契約金額より大きい)は、粗利・粗利率がマイナスで出ます。

30ケースすべて、区分・完工月・粗利・粗利率・チェック表示と月別集計が、Pythonで計算した結果と一致しました。さらに、乱数で作った**500行**(工事番号の空欄・重複、契約金額・原価・完了日の文字・0・小数・マイナスを約12%混ぜ、約2割を進行中にしました)でも、**全項目と月別集計(12か月分・合計・期間外の件数)が一致**しました。Excelでの確認はしていません。

## つまずきやすい点

- **完了日を入れ忘れると進行中のまま**: 工事が終わったのに完了日が空欄だと、完工高に入りません。M16(進行中の件数)が、実際に動いている工事の数と合っているか、月に一度見てください。完了後なのに請求が出ていない工事は、[請求漏れを見つける記事](/billing-missing/)の式で拾えます。
- **契約金額は「現在の金額」を入れる**: 追加工事や減額があった工事は、変更後の金額を入れます。履歴から現在の契約金額を出す方法は、[追加工事・減額を反映する記事](/contract-change/)にあります。
- **原価の集め方**: 材料・外注・経費の内訳を分けて粗利を見る方法は[原価を材料・外注・経費に分ける記事](/job-margin/)に、日報から労務費を工事ごとに出す方法は[作業日報の記事](/daily-labor-by-job/)にあります。この記事では、その合計を原価合計の列に入れる前提です。
- **進行中の工事の採算**: 完工前に予算超過を見つけたいときは、[実行予算と原価実績を比べる記事](/budget-actual/)が向いています。この記事は、終わった工事の結果を月別に見るものです。
- **12か月を超えるとき**: L列の月を13行目より下に増やし、M〜P列の式をコピーします。合計の式の範囲(M2:M13など)も合わせて広げてください。
- **期間外の件数**: M15が0でないときは、開始月を見直すか、期間外の工事を別の期間の表で集計してください。

## 注意点: この記事ができないこと

- 売上の計上時期の判断や、決算・税務の処理は扱いません。完了日を売上の計上日として扱ってよいかは、会社の経理のルールで決めてください。
- 工期が月をまたぐ工事を、月ごとに按分する集計はしません。完了日の月に、全額が入ります。
- 金額は整数だけを前提にしています。税の取り扱いは扱いません(契約金額と原価は、税抜か税込のどちらかにそろえて入れてください)。
- 値引き・手直し・保証の費用など、完了日より後に発生する原価は、台帳の原価に足さないかぎり粗利に反映されません。

## 見積から工事台帳までつなげたいとき

見積の計算そのものから作りたい場合は、運営者が作った[工事・リフォーム用 見積書テンプレート(Excel・980円)](/go/estimate-construction/?from=monthly-completion)があります。数量×単価(四捨五入)、諸経費率、値引き、消費税10%(切り捨て)、税込合計を自動計算し、明細は20行、A4縦1枚で印刷できます。**この記事の「完工月ごとの集計」機能は、この商品には入っていません**。工事台帳への転記、請求書への変換、軽減税率の混在、インボイス要件の保証もできません。Excelの確認はWindowsデスクトップ版16のみです。(これは運営者の商品の案内です。)

見積の合計だけをすぐ確かめたいときは、無料の[見積の合計計算ツール](/tools/estimate-total/)が使えます(入力は外部に送信されません)。

## まとめ

- 工事ごとに契約金額・原価合計・完了日を入れ、完了日の月の1日を「完工月」にする
- 月別の表は、開始月から`EDATE`で12か月並べ、`SUMIFS`で完工月が一致する行の契約金額と粗利を足す
- 完了日が空欄の工事は進行中として外し、完工済みで原価が空欄の行は、粗利が膨らまないようチェック列で止める
- 合計の粗利率は、月の平均ではなく「粗利の合計 ÷ 完工高の合計」で出す
- 30ケースと500行の照合はLibreOfficeで一致。Excelでは未確認のため、本番では数行を手計算で見比べる
