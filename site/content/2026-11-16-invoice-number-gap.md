月末に請求書の台帳を見返したら、「R-0006の請求書が台帳にない。出したのか、出していないのか」と分からなくなる。あるいは、同じ番号を2通に振ってしまっていた。請求書を手作業で作っていると、**番号の飛びと重複は、起きてから気づく**ことになりがちです。

この記事では、台帳の「請求番号」の列だけを見て、**重複している番号**と、**直前で何件抜けているか**、全体の**欠番の合計**を出す式を示します。「R-0003」の形に合わない入力(全角数字、小文字のr、末尾の空白など)は、判定に使わず「形式が違う」と表示します。

出典: 筆者がLibreOfficeで計算して確認(検証スクリプト: site/verify/invoice_number_gap.py)。外部サイトの説明は参照していません。**Excelでは未確認**です。使うのは `COUNTIF`・`LARGE`・`FIND`・`SUMPRODUCT` などで、特別な新しい関数は使っていませんが、本番の前に自分の台帳で数行を見比べてください。なお、**請求書番号の付け方に関する法令上のルールの説明はこの記事では行いません**。税務上の扱いは、国税庁の資料や税理士にご確認ください。

## 先に作る表

「請求」シート(2行目から。1行目は見出し。ここでは50行目までの範囲で書きます)

| 列 | 内容 | 入れるもの |
|---|---|---|
| A | 請求番号 | 手入力(「R-」+4桁の数字。例: R-0003) |
| B | 入力チェック | 式 |
| C | 番号(数値) | 式(形式が正しいときだけ数字を取り出す) |
| D | 初出 | 式(その番号が初めて出た行なら1) |
| E | 判定 | 式 |
| F | 直前の欠番 | 式 |

```
B2: =IF(A2="","",IF(AND(LEN(A2)=6,EXACT(LEFT(A2,2),"R-"),
      SUMPRODUCT(--ISNUMBER(FIND(MID(A2,{3,4,5,6},1),"0123456789")))=4),"","形式が違う"))
C2: =IF(OR(A2="",B2<>""),"",VALUE(MID(A2,3,4)))
D2: =IF(C2="","",IF(COUNTIF(C$2:C2,C2)=1,1,0))
F2: =IF(C2="","",IFERROR(C2-LARGE($C$2:$C$50,COUNTIF($C$2:$C$50,">="&C2)+1)-1,0))
E2: =IF(A2="","",IF(B2<>"",B2,IF(COUNTIF($C$2:$C$50,C2)>1,"重複("&COUNTIF($C$2:$C$50,C2)&"件)",
      IF(F2>0,"直前に欠番"&F2&"件","OK"))))
I2: =IF(COUNT(C2:C50)=0,"",MAX(C2:C50)-MIN(C2:C50)+1-SUM(D2:D50))
```

I2は「欠番の合計」を入れる集計用のセルです。考え方は次の3つです。

- **B列で、番号の形を先に確かめます**。「6文字」「先頭が大文字の `R-`」「後ろ4文字がすべて半角の数字」の3つを満たすものだけを、番号として使います。`EXACT` で大文字小文字を区別し、`FIND` で半角の0〜9だけを許しているので、全角数字や小文字のrは「形式が違う」になります。
- **直前の欠番は、「自分より小さい番号のうち最大のもの」との差−1**です。`LARGE` に「自分以上の番号の個数+1」を渡すと、自分より小さい番号の中で最大のものが取れます。重複していても、同じ番号を何件数えても結果がずれません。表が逆順や不ぞろいに並んでいても同じ結果になります。
- **欠番の合計は「最大−最小+1−番号の種類」**です。D列の「初出」を数えれば、重複を除いた番号の種類が分かります。

## 実際に計算した結果

| 入力(A列) | 判定 |
|---|---|
| R-0001 | OK |
| R-0002 | OK |
| R-0003 | OK |
| R-0005 | 重複(2件) |
| R-0005 | 重複(2件) |
| R-0008 | OK |
| R-0007 | 直前に欠番1件(R-0006が無い) |
| R-0010 | 直前に欠番1件(R-0009が無い) |
| (空欄) | (表示なし) |
| R-０００９(全角数字) | 形式が違う |
| r-0011(小文字) | 形式が違う |
| R-0012 (末尾に空白) | 形式が違う |
| R-12(桁が足りない) | 形式が違う |
| R-00A3(英字混じり) | 形式が違う |
| Ｒ-0013(全角のＲ) | 形式が違う |
| R-0020 | 直前に欠番9件 |

欠番の合計(I2)は **12** です。これは、R-0001〜R-0020のうち、有効な番号に含まれない4・6・9・11〜19の12個にあたります。

注意点が1つあります。**R-0004は表のどこにもありませんが、「欠番」と出ている行はありません**。R-0004の次に来るR-0005は重複しているため、重複の表示を優先しているからです。このように、重複の行では直前の欠番を表示しませんが、R-0004は欠番の合計(12個)にはきちんと数えられています。

上のケースに加え、乱数で作った36行を10組、さらに「空のみ」「1件のみ」「逆順で欠番なし」の表でも、判定と欠番の合計がPythonの総当たりと**全件一致**しました(計396行。検証はLibreOfficeのみ。Excelでは未確認)。

## 使うときの注意

- **何が抜けているかは、この式では番号を一つずつ列挙しません**。「R-0007の直前に1件」と出たら、R-0006が無い、と自分で読み替えてください。欠番の理由(取り消しした、まだ発行していない、台帳への入力漏れ)は、人が確かめます。
- **最小の番号より前の欠番は分かりません**。台帳の先頭がR-0003なら、R-0001・R-0002が無くても欠番とは数えません。年度や月で番号を振り直している場合は、期間ごとに表を分けてください。
- 「R-」+4桁の形にしています。別の書き方(例: 「2026-001」)を使っている場合は、`LEN(A2)=6` と `MID(A2,3,4)` の数字を、自分の形に合わせて変えてください。変えたあとは、必ず数行で手計算と見比べてください。
- 範囲を `$C$2:$C$50` のように固定しているので、行を増やしたときは範囲を広げてください。行を削除すると式が壊れることがあるため、削除ではなく中身を消すほうが安全です。
- 全角数字や小文字を「形式が違う」にしているのは、そのまま判定すると**別の番号として扱われ、重複や欠番を見落とす**ためです。表記の揺れを直す方法は[SUBSTITUTEとTRIMで不要な文字・スペースを取り除く方法](/space-remove-zenkaku-hankaku/)が参考になります。

## この記事ができないこと

- 請求書の記載項目(インボイスの要件など)が満たされているかの確認はしません。法令の要件を満たすことを保証するものではありません。
- 請求書番号を自動で振る式は、別記事の[見積番号を自動で振る方法(月ごとに001から・通し番号の2通り)](/estimate-number/)にあります(請求番号にも考え方は使えます)。
- 完了した工事の請求漏れ(完了日はあるが請求日がない)の調べ方は、[請求漏れを見つける式](/billing-missing/)にあります。

## 見積から工事台帳・請求まで一続きにしたいとき

請求番号は、工事ごとの請求の台帳と並べて持つと、番号の飛びの理由も追いかけやすくなります。見積から工事台帳への転記の式は[見積から工事台帳への転記](/quote-to-ledger/)にまとめています。見積の計算(数量×単価、諸経費、値引き、消費税)そのものを作りたい場合は、運営者が作った[工事・リフォーム用 見積書テンプレート(Excel・980円)](/go/estimate-construction/?from=invoice-number-gap)があります。数量×単価(四捨五入)、諸経費率、値引き、消費税10%(切り捨て)、税込合計を自動計算し、明細は20行、A4縦1枚で印刷できます。**この記事の請求番号の欠番・重複の判定は、この商品には入っていません**。軽減税率の混在や、インボイス要件の保証もできません。Excelの確認はWindowsデスクトップ版16のみです。(これは運営者の商品の案内です。)

見積の合計だけをすぐ確かめたいときは、無料の[見積の合計計算ツール](/tools/estimate-total/)が使えます(入力は外部に送信されません)。

## まとめ

- 番号の形(6文字・先頭がR-・後ろ4文字が半角数字)を先に確かめ、合わない行は「形式が違う」にして判定から外す
- 重複は `COUNTIF`、直前の欠番は `LARGE` で「自分より小さい最大の番号」を取って差を見る。欠番の合計は「最大−最小+1−番号の種類」
- 最小の番号より前の欠番や、欠番の理由は分からない。期間ごとに表を分け、飛びは人が確かめる
- 固定ケースと乱数396行の照合はLibreOfficeで一致、Excelでは未確認のため、本番では自分の台帳で数行を見比べる
