見積書を直して送り直したのに、工事台帳の「契約金額」は最初の見積のまま。請求の段になって気づいて、金額を直す。見積から台帳への転記は、**見積が改訂されるたびに古い数字が残る**のが厄介なところです。

この記事では、見積の一覧を「工事番号・版・税抜合計」で1行ずつ持っておき、台帳側で**最新版の金額だけを自動で引き**、台帳に手で書いた金額との**ズレを表示する**式を示します。転記を無くすのではなく、「転記した金額が最新版と合っているか」を毎回確かめられる形にします。

出典: 筆者がLibreOfficeで計算して確認(検証スクリプト: site/verify/quote_to_ledger.py)。外部サイトの説明は参照していません。**Excelでは未確認**です。また、最新版を選ぶのに使うMAXIFSは**Excel 2019以降・Microsoft 365**の関数で、Excel 2016以前では動きません。

## 先に作る表: 2枚のシート

**「見積」シート**(1行1見積。2行目から。1行目は見出し)

| 列 | 内容 | 入れるもの |
|---|---|---|
| A | 工事番号 | 手入力(例: K-001) |
| B | 版 | 手入力(1, 2, 3…。作り直すたびに+1) |
| C | 税抜合計 | 手入力(見積書の税抜の合計) |
| D | 整えた番号 | 式 |
| E | チェック | 式 |
| F | 有効 | 式(1なら集計に使う) |
| G | 最新版 | 式(その工事の有効な行のうち、最大の版なら1) |

```
D2: =ASC(TRIM(A2))
E2: =IF(AND(A2="",B2="",C2=""),"",IF(A2="","工事番号が空欄",IF(ISNA(MATCH(D2,台帳!$A$2:$A$2000,0)),"工事番号なし",
     IF(NOT(ISNUMBER(B2)),"版が1以上の整数でない",IF(OR(B2<1,B2<>INT(B2)),"版が1以上の整数でない",
     IF(NOT(ISNUMBER(C2)),"金額が数値でない",IF(C2<0,"金額がマイナス","")))))))
F2: =IF(AND(A2="",B2="",C2=""),0,IF(E2="",1,0))
G2: =IF(F2=1,IF(B2=MAXIFS($B$2:$B$2000,$D$2:$D$2000,D2,$F$2:$F$2000,1),1,0),0)
J1: =SUMPRODUCT(--(E2:E2000<>""))      ← 入力を見直す行の数(I1に「要確認の行数」と見出し)
```

`NOT(ISNUMBER(B2))` と `B2<1…` を別のIFに分けているのがポイントです。1つのORにまとめると、版の欄に「第2版」のような文字が入ったとき `INT` がエラーになり、チェック列全体が崩れます(最初に書いた版でこれが起き、検証で見つけました)。

**「台帳」シート**(1行1工事。A列に工事番号、D列に台帳へ手で書いた金額)

| 列 | 内容 | 入れるもの |
|---|---|---|
| A | 工事番号 | 手入力 |
| B | 最新版 | 式 |
| C | 見積金額(税抜) | 式(最新版の金額) |
| D | 転記済みの金額 | 手入力(これまで台帳に書いていた金額) |
| E | 状態 | 式 |
| F | 差額 | 式 |

```
B2: =IF(A2="","",IF(COUNTIFS(見積!$D$2:$D$2000,A2,見積!$F$2:$F$2000,1)=0,"見積なし",MAXIFS(見積!$B$2:$B$2000,見積!$D$2:$D$2000,A2,見積!$F$2:$F$2000,1)))
C2: =IF(A2="","",IF(B2="見積なし","",IF(COUNTIFS(見積!$D$2:$D$2000,A2,見積!$G$2:$G$2000,1)>1,"同じ版が重複",
     SUMIFS(見積!$C$2:$C$2000,見積!$D$2:$D$2000,A2,見積!$G$2:$G$2000,1))))
E2: =IF(A2="","",IF(NOT(ISNUMBER(C2)),"見積を確認",IF(D2="","未転記",IF(NOT(ISNUMBER(D2)),"転記額が数値でない",IF(D2=C2,"一致","ズレ")))))
F2: =IF(E2="ズレ",D2-C2,"")
```

考え方は3つです。

- **最新版は「その工事で有効な行のうち、版が最大の行」**とします。行の並び順には頼りません(版2が先の行にあっても正しく選ばれます)。
- **同じ版が2行ある**ときは、どちらが正しいか式では決められないので、金額を出さずに「同じ版が重複」と表示します。足し合わせると二重計上になるためです。
- **入力に誤りのある行は集計から外し**、J1に件数を出します。誤りのある行が最新版だった場合は、前の版の金額が出てしまうので、J1が0でないときは必ず見直してください。

## 実際に計算した結果

| ケース | 見積の入力 | 台帳に書いた金額 | 台帳の表示 |
|---|---|---|---|
| 1版だけ | 版1: 1,000,000 | 1,000,000 | 最新版1・1,000,000・一致 |
| 改訂したのに古いまま | 版1: 1,000,000 / 版2: 1,250,000 | 1,000,000 | 最新版2・1,250,000・**ズレ(差額 −250,000)** |
| 版が行の順と逆 | 版2: 1,250,000 を先の行に / 版1: 1,000,000 | 1,250,000 | 最新版2・一致 |
| 未転記 | 版1: 800,000 | 空欄 | 未転記 |
| 見積が1行もない | (なし) | 500,000 | 見積なし・見積を確認 |
| 同じ版を2行入力 | 版1: 900,000 を2行 | 900,000 | 同じ版が重複・見積を確認 |
| 存在しない工事番号 | K-070 の見積 | − | 見積シートに「工事番号なし」、J1=1 |
| 工事番号が空欄 | (空欄)版1 | − | 「工事番号が空欄」、J1=1 |
| 金額欄に「300,000円」と入力 | 版1: 文字 | − | 「金額が数値でない」、台帳は見積を確認 |
| 版が1.5・0・「第2版」 | 3行 | − | 3行とも「版が1以上の整数でない」、J1=3 |
| 値引きを別行のマイナス金額で入力 | 版1: 500,000 / 版2: −50,000 | − | 版2を「金額がマイナス」とし、版1の500,000を採用(J1=1) |
| 全角・前後スペースの番号 | 「Ｋ－012」版1: 600,000 /「 K-012 」版2: 700,000 | 700,000 | 同じ工事として集計し、最新版2・一致 |
| 転記額が「120万」 | 版1: 1,200,000 | 文字 | 転記額が数値でない |
| まったくの空行 | (なし) | − | 空欄 |

14ケースすべて、最新版・見積金額・状態・差額・J1の件数が、Pythonでの計算と一致しました。

さらに、工事300件・見積1,000行の乱数データ(番号の誤り・空欄・全角・前後スペース、金額の文字・マイナス、版の小数・ゼロを約20%混ぜた)で照合し、**すべて一致**しました。台帳の状態は「一致」99件、「ズレ」83件、「見積を確認」98件、「未転記」13件、「転記額が数値でない」7件でした(乱数なので、件数そのものに意味はありません)。

## 使うときの注意

- **マイナス金額の行は集計に入りません**。値引きは、見積書の合計に反映した「税抜合計」を新しい版として入力する運用が前提です(上の表の「版2: −50,000」は、誤りとして弾かれる例です)。
- **「見積を確認」の工事は、金額を出していません**。見積の入力を直すか、見積自体がまだ無いかを確かめてください。
- **「一致」は金額が同じというだけ**です。見積の内容が正しいか、契約した金額かどうかは式では分かりません。契約・変更契約の取り決めは、会社のやり方に従ってください。
- **見積書の金額は、税抜か税込かをそろえてください**。この記事の式は、C列に入れた数字をそのまま足し引きするだけで、消費税の計算はしません。
- 工事番号は「K-001」のように、台帳と見積で表記をそろえてください(ハイフンの有無や大文字小文字の違いは吸収しません)。
- 行を削除すると、他のシートからの参照が崩れることがあります。見積の行を消すときは、削除ではなく「版」を残したまま、使わない行は内容を消す運用にしてください。

## この記事ができないこと

- 見積書の明細から税抜合計を計算することはしません(合計は別に出して入力します)。
- 追加工事・変更契約の扱いが取り決めどおりかの判断はしません。
- 請求書の作成や、入金の確認はしません。請求の残額は別の記事で扱っています。

## 見積から請求までをあわせて見たいとき

見積の最新版を台帳に引いたあとの流れは、次の記事にまとめています。請求の残額は[工事の分割請求の残額をExcelで管理する式](/split-billing-balance/)に、工事ごとの原価と粗利は[工事の原価を材料・外注・経費に分けて粗利を見る式](/job-margin/)に、工程の遅れは[工程表で遅れている工程を自動で表示する式](/schedule-delay/)にあります。

見積書そのものから作りたい場合は、運営者が作った[工事・リフォーム用 見積書テンプレート(Excel・980円)](/go/estimate-construction/?from=quote-to-ledger)があります。数量×単価(四捨五入)、諸経費率、値引き、消費税10%(切り捨て)、税込合計を自動計算し、明細は20行、A4縦1枚で印刷できます。**この記事の「見積の版を台帳に引く」機能は、この商品には入っていません**。軽減税率の混在や、インボイス要件の保証もできません。Excelの確認はWindowsデスクトップ版16のみです。(これは運営者の商品の案内です。)

見積の小計から税込までを一度に出すなら、無料の[見積の合計計算ツール](/tools/estimate-total/)が使えます(入力は外部に送信されません)。

## まとめ

- 見積は「工事番号・版・税抜合計」で1行ずつ入力し、作り直したら版を+1して新しい行に入れる
- 台帳では、有効な行のうち最大の版をMAXIFSで選び、その金額をSUMIFSで引く(行の順には頼らない)
- 台帳に書いた金額と最新版の金額を比べて、「一致・ズレ・未転記」を表示し、ズレは差額も出す
- 同じ版の重複、番号の誤り、文字の金額・版は集計から外し、J1の件数で見直す行を知らせる
- 14ケースと、工事300件・見積1,000行の照合はLibreOfficeで一致。Excelは未確認でMAXIFSは2019以降のため、本番では数行を手で検算する
