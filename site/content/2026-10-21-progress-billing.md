「工事は半分くらい進んだから、中間金はいくら請求していいのか」。契約金額に進捗率をかけ、すでに請求した分を引く。頭ではわかっていても、手計算や電卓だと、**進捗率を50と入れて5,000%になる**、**着手金を引き忘れる**、**請求済みがすでに出来高より多いのに気づかない**といった間違いが起きます。

この記事では、工事ごとの契約金額(税抜)と進捗率を入れると、**出来高(円未満切り捨て)**と**請求済みの合計**、そして**今回請求できる額**を自動で出す式を示します。入力の間違いは「要確認」と表示して、計算に混ぜません。

出典: 筆者がLibreOfficeで計算して確認(検証スクリプト: site/verify/progress_billing.py)。外部サイトの説明は参照していません。**Excelでは未確認**です。使うのはIF・ROUNDDOWN・ROUND・SUMIFS・COUNTIF・MATCH・ISNUMBER・ASC・TRIMなどの一般的な関数ですが、本番で使う前に数行で結果を確かめてください。

## 先に作る表: 2枚のシート

**「台帳」シート**(1行1工事。2行目から。1行目は見出し)

| 列 | 内容 | 入れるもの |
|---|---|---|
| A | 工事番号 | 手入力(例: K-001) |
| B | 契約金額(税抜) | 手入力(数値) |
| C | 進捗率 | 手入力。**セルの表示形式を「%」にして**、50%なら「50%」と入れる |
| D | 出来高 | 式 |
| E | 請求済み | 式(請求シートから集める) |
| F | 今回請求できる額 | 式 |
| G | チェック | 式 |

**「請求」シート**(1行1回の請求。工事ごとに何回入れてもよい)

| 列 | 内容 | 入れるもの |
|---|---|---|
| A | 工事番号 | 手入力 |
| B | 請求額(税抜) | 手入力(数値) |
| C | 整えた番号 | 式 |
| D | チェック | 式 |

```
台帳 G2: =IF(A2="","",IF(NOT(ISNUMBER(B2)),"契約金額が未入力か数値でない",IF(B2<=0,"契約金額が0以下",
      IF(NOT(ISNUMBER(C2)),"進捗率が未入力か数値でない",IF(OR(C2<0,C2>1),"進捗率が0〜100%の範囲外",
      IF(COUNTIF(A$2:A2,A2)>1,"工事番号が重複",
      IF(SUMIFS(請求!$B$2:$B$2000,請求!$C$2:$C$2000,A2)>ROUNDDOWN(ROUND(B2*C2,6),0),"請求済みが出来高を超えている","")))))))
台帳 D2: =IF(A2="","",IF(G2="請求済みが出来高を超えている",ROUNDDOWN(ROUND(B2*C2,6),0),IF(G2<>"","",ROUNDDOWN(ROUND(B2*C2,6),0))))
台帳 E2: =IF(A2="","",SUMIFS(請求!$B$2:$B$2000,請求!$C$2:$C$2000,A2))
台帳 F2: =IF(OR(A2="",G2<>""),"",D2-E2)

請求 C2: =ASC(TRIM(A2))
請求 D2: =IF(AND(A2="",B2=""),"",IF(A2="","工事番号が空欄",IF(ISNA(MATCH(C2,台帳!$A$2:$A$2000,0)),"工事番号なし",
      IF(NOT(ISNUMBER(B2)),"請求額が数値でない",""))))

台帳 I1: 要確認の件数    J1: =COUNTIF(G2:G2000,"?*")+COUNTIF(請求!D2:D2000,"?*")
```

考え方は3つです。

- **出来高 = 契約金額 × 進捗率**。円未満は切り捨てています(`ROUNDDOWN`)。`ROUND(…,6)` を間に挟んでいるのは、小数の計算誤差で1円ずれるのを避けるためです。円未満の扱い(切り捨て・四捨五入)は取引先との取り決めに合わせて、`ROUNDDOWN` を `ROUND` に変えてください。
- **今回請求できる額 = 出来高 − 請求済みの合計**。請求済みは「請求」シートの同じ工事番号の行を `SUMIFS` で足し上げます。着手金、中間金など何回請求していても自動で引かれます。
- **請求シートの工事番号は `ASC(TRIM(…))` で整えてから**台帳と照合します。全角の「Ｋ－017」や前後のスペースがあっても、同じ工事に集計されます。

進捗率の欄は、**表示形式を「%」にしてから**入力するのが前提です。数値の「50」を表示形式「標準」のセルに入れると、5,000%(= 50)として扱われ、チェック列が「進捗率が0〜100%の範囲外」と知らせます。

## 実際に計算した結果

| ケース | 契約金額 × 進捗率 | 請求済み | 出来高 | 今回請求できる額 | チェック |
|---|---|---|---|---|---|
| 基本 | 1,000,000 × 35% | なし | 350,000 | 350,000 | |
| 着手金を請求済み | 1,500,000 × 30% | 450,000 | 450,000 | 0 | |
| 円未満の切り捨て | 1,234,567 × 33.3% | なし | 411,110 | 411,110 | |
| 進捗率0% | 800,000 × 0% | なし | 0 | 0 | |
| 100%・2回請求済み | 800,000 × 100% | 300,000 + 200,000 | 800,000 | 300,000 | |
| 前払い超過 | 1,000,000 × 20% | 300,000 | 200,000 | (空欄) | 請求済みが出来高を超えている |
| 進捗率50(%を付け忘れ) | 1,000,000 × 5000% | | (空欄) | (空欄) | 進捗率が0〜100%の範囲外 |
| 進捗率マイナス | 1,000,000 × −10% | | (空欄) | (空欄) | 進捗率が0〜100%の範囲外 |
| 進捗率に「半分」 | 1,000,000 × 文字 | | (空欄) | (空欄) | 進捗率が未入力か数値でない |
| 契約金額が空欄・0・文字 | | | (空欄) | (空欄) | 契約金額が未入力か数値でない/0以下 |
| 全角・スペース付きの請求番号 | 1,000,000 × 60% | 100,000 + 200,000 | 600,000 | 300,000 | (同じ工事に集計) |
| 工事番号の重複 | 2行目のK-018 | | (空欄) | (空欄) | 工事番号が重複 |

請求シート側では、台帳にない工事番号は「工事番号なし」、番号が空欄なら「工事番号が空欄」、請求額に文字が入っていれば「請求額が数値でない」と表示します。これらの行は請求済みの合計に入りません。

全19ケースで、出来高・請求済み・今回請求できる額・チェック表示が、Pythonの整数計算と一致しました。さらに、工事300件・請求1,000行の乱数データ(進捗率の範囲外や文字、契約金額の空欄・0・文字、存在しない番号、番号の空欄、全角、前後スペース、請求額の文字を約2割混ぜた)で照合し、**すべて一致**しました(Excelでは未確認)。

## 使うときの注意

- **「要確認」の行は今回請求できる額が空欄になります**。J1が0でなければ、チェック列を見て入力を直してください。
- **請求シートの「工事番号なし」の行は、請求済みの合計に入りません**。台帳の請求済みが少なく出ているときは、請求シートのチェック列を見てください。入れ間違いを直さないと、今回請求できる額が実際より多く出ます。
- **進捗率は現場の実態に合わせて自分で決めます**。この式は進捗率の妥当性を判断しません。進捗率の決め方(工程の完了割合、材料費ベースなど)は、契約や取引先との取り決めに従ってください。
- **契約金額は税抜の金額を入れます**。消費税を足した請求書の金額にするには、別に税の計算が必要です。消費税の端数処理は[消費税の端数処理の比較ツール](/tools/tax-rounding-compare/)で並べて確認できます。
- **追加工事や契約変更**は、契約金額を書き換えると出来高も変わります。変更前の請求済みはそのまま残るため、「請求済みが出来高を超えている」と出たら金額の入力を見直してください。
- 工事番号は「K-001」のように、台帳と請求で表記をそろえてください(ハイフンの有無や大文字小文字の違いは吸収しません)。

## この記事ができないこと

- 請求書そのものの作成や、請求書に必要な記載項目の判断はしません。
- 契約書の条件(支払い条件、出来高払いの定め)の確認はしません。
- 出来高が請求できる額として適切かどうかの判断はしません。

## 工事全体の原価や工程もあわせて見たいとき

この記事の式は、自分で作った台帳にそのまま使えます。工事ごとの原価と粗利は[工事の原価を材料・外注・経費に分けて粗利を見る式](/job-margin/)に、分割請求の残額と番号の入力ミスの拾い方は[工事の分割請求の残額をExcelで管理する式](/split-billing-balance/)に、工程の遅れは[工事の工程表で遅れている工程を自動で表示する式](/schedule-delay/)にまとめています。見積の計算(数量×単価、諸経費、値引き、消費税)から作りたい場合は、運営者が作った[工事・リフォーム用 見積書テンプレート(Excel・980円)](/go/estimate-construction/?from=progress-billing)があります。数量×単価(四捨五入)、諸経費率、値引き、消費税10%(切り捨て)、税込合計を自動計算し、明細は20行、A4縦1枚で印刷できます。**この記事の出来高・請求済みの機能は、この商品には入っていません**。軽減税率の混在や、インボイス要件の保証もできません。Excelの確認はWindowsデスクトップ版16のみです。(これは運営者の商品の案内です。)

税込み・税抜の計算だけなら、無料の[見積の合計計算ツール](/tools/estimate-total/)が使えます(入力は外部に送信されません)。

## まとめ

- 台帳に「工事番号・契約金額(税抜)・進捗率(%表示)」、請求シートに「工事番号・請求額」を入れる
- 出来高は契約金額×進捗率を円未満切り捨て。今回請求できる額は、出来高から請求済みの合計を引く
- 請求済みはSUMIFSで工事ごとに集める。請求の番号は `ASC(TRIM(…))` で整えて、全角やスペースの違いを吸収する
- 進捗率の範囲外・文字、契約金額の空欄・0、番号の重複、請求済みの超過は「要確認」にして、J1で件数を見る
- 19ケースと、工事300件・請求1,000行の照合はLibreOfficeで一致。Excelでは未確認のため、本番では数行を手で検算する
