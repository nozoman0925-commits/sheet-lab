外注先(大工、電気、設備、塗装などの協力業者)に仕事を頼んだとき、「いくら発注して、いくら請求が来て、いくら払ったか」が頭の中や紙の控えにしかなく、月末の支払いで慌てた経験はないでしょうか。請求書が来ていない分と、来ているのに払っていない分は、分けて見ないと支払い漏れや二重払いのもとになります。

この記事では、**発注額・請求額・支払済**を1行ずつ入れるだけで、**「未請求／未払あり／支払済(発注残あり)／完了／発注額超過」の表示、未払額、発注残、全体の未払い合計、外注先ごとの未払額**を出す式を示します。

出典: 筆者がLibreOfficeで計算して確認(検証スクリプト: site/verify/subcontract_balance.py)。外部サイトの説明は参照していません。**Excelでは未確認**です。使うのはIF・OR・AND・NOT・ISNUMBER・INT・N・COUNTIF・SUM・SUMIF・SUMIFSという一般的な関数ですが、本番で使う前に、数行を手計算と見比べてください。この記事は表の作り方の説明です。**支払期限や支払条件は、外注先との取り決め(発注書・契約)に従ってください**。税の取り扱いも扱いません(金額は税抜でそろえる前提です)。

## 先に結論: 「発注額 − 請求額」が発注残、「請求額 − 支払済」が未払額

- 発注残 = 発注額 − 請求額(まだ請求が来ていない分)
- 未払額 = 請求額 − 支払済(請求は来ているが払っていない分)
- 請求額が空欄なら「未請求」、請求額が発注額を超えていたら「発注額超過」(追加工事の確認漏れや請求ミスの可能性があるので要確認)
- 外注先名を1つ指定すると、その外注先の未払額だけを合計できる

## Excelの式

シート名は「外注」。2行目から使います。

| 列 | 内容 | 入れるもの |
|---|---|---|
| A | 発注番号 | 手入力(例: H-001) |
| B | 外注先 | 手入力 |
| C | 発注額(税抜) | 手入力(1以上の整数) |
| D | 請求額 | 手入力。請求が来るまで空欄 |
| E | 支払済 | 手入力。払うまで空欄 |
| F | 状態 | 式 |
| G | チェック | 式 |
| H | 未払額 | 式 |
| I | 発注残 | 式 |
| K3 | 外注先を指定 | 集計したい外注先の名前(空欄なら集計しない) |

```
F2: =IF(OR(G2<>"",A2&B2&C2&D2&E2=""),"",IF(N(D2)>C2,"発注額超過",IF(N(D2)=0,"未請求",
      IF(N(E2)<N(D2),"未払あり",IF(N(D2)<C2,"支払済(発注残あり)","完了")))))
G2: =IF(A2&B2&C2&D2&E2="","",IF(A2="","発注番号が空欄",
      IF(COUNTIF($A$2:$A$1000,A2)>1,"発注番号が重複",
      IF(B2="","外注先が空欄",
      IF(NOT(ISNUMBER(C2)),"発注額が数字でない",
      IF(OR(C2<1,C2<>INT(C2)),"発注額は1以上の整数",
      IF(AND(D2<>"",NOT(ISNUMBER(D2))),"請求額が数字でない",
      IF(AND(ISNUMBER(D2),OR(D2<0,D2<>INT(D2))),"請求額は0以上の整数",
      IF(AND(E2<>"",NOT(ISNUMBER(E2))),"支払済が数字でない",
      IF(AND(ISNUMBER(E2),OR(E2<0,E2<>INT(E2))),"支払済は0以上の整数",
      IF(N(E2)>N(D2),"支払済が請求額を超えている","")))))))))))
H2: =IF(F2="","",N(D2)-N(E2))
I2: =IF(F2="","",C2-N(D2))
```

N関数は、空欄を0として扱うために使っています(`N(D2)`は、D2が空欄なら0、数字ならその数字を返します)。入力ミスの行はチェック列に理由が出て、状態・未払額・発注残は空欄になり、集計に入りません。

集計は右側のセルに置きます(範囲は1000行まで)。

```
K5 未払い合計:     =SUM($H$2:$H$1000)
K6 発注残の合計:   =SUMIF($I$2:$I$1000,">0")
K7 発注額超過の件数: =COUNTIF($F$2:$F$1000,"発注額超過")
K8 指定した外注先の未払額: =IF($K$3="","",SUMIFS($H$2:$H$1000,$B$2:$B$1000,$K$3))
```

K6で「0より大きいものだけ」を足しているのは、発注額超過の行の発注残がマイナスになるためです。マイナスを足すと、他の行の発注残を打ち消してしまいます。

## 実際に計算して確認した結果

| ケース | 発注額 | 請求額 | 支払済 | 状態 | 未払額 | 発注残 |
|---|---|---|---|---|---|---|
| まだ請求なし | 500,000 | 空欄 | 空欄 | 未請求 | 0 | 500,000 |
| 請求が来て未払 | 500,000 | 500,000 | 空欄 | 未払あり | 500,000 | 0 |
| 一部だけ支払済 | 500,000 | 500,000 | 200,000 | 未払あり | 300,000 | 0 |
| 出来高の一部を請求して支払済 | 500,000 | 300,000 | 300,000 | 支払済(発注残あり) | 0 | 200,000 |
| 全額請求して全額支払済 | 500,000 | 500,000 | 500,000 | 完了 | 0 | 0 |
| 請求が発注額を超過 | 500,000 | 550,000 | 100,000 | 発注額超過 | 450,000 | -50,000 |

複数行の集計の確認では、4件(A工業500,000円が請求済・200,000円支払済、B電気300,000円が請求100,000円・支払済100,000円、A工業200,000円が請求250,000円・未払い、C設備400,000円が請求なし)で、未払い合計 550,000円、発注残の合計 600,000円、発注額超過 1件と出ました。外注先に「A工業」を指定した別の3件のケースでは、A工業の2件の未払額(300,000円と150,000円)の合計450,000円が出ました。一覧にない外注先を指定した場合は0になります。

入力ミスの行は、状態・未払額・発注残を空欄にして、G列にこう出ます。

| 入力ミス | チェック |
|---|---|
| 発注番号が空欄 | 発注番号が空欄 |
| 発注番号が重複(H-001とh-001) | 発注番号が重複 |
| 外注先が空欄 | 外注先が空欄 |
| 発注額が「50万」・全角「５００，０００」・空欄 | 発注額が数字でない |
| 発注額が0・小数 | 発注額は1以上の整数 |
| 請求額が「済」 | 請求額が数字でない |
| 請求額がマイナス・小数 | 請求額は0以上の整数 |
| 支払済が「払い済み」 | 支払済が数字でない |
| 支払済がマイナス・小数 | 支払済は0以上の整数 |
| 支払済が請求額より多い(請求が空欄で支払済だけ入力した場合も) | 支払済が請求額を超えている |
| すべて空欄の行 | (何も出さない) |

26ケースすべて、状態・未払額・発注残・チェック表示と集計が、Pythonで計算した結果と一致しました。さらに、乱数で作った**500行**(発注番号の空欄・重複、外注先の空欄、発注額の文字・0・小数・マイナス、請求額・支払済の文字・マイナス・小数、支払済の超過を約12%混ぜました)でも、**全項目と集計4つが一致**しました。Excelでの確認はしていません。

## つまずきやすい点

- **請求書が届いたら、その日に請求額を入れる**: 入れ忘れると「未請求」のまま残り、未払い合計に入りません。
- **支払ったら、その日に支払済を入れる**: 請求額に対する累計の金額を入れてください(分けて払った場合は、合計額に書き換えます)。
- **外注先名は表記をそろえる**: 「A工業」と「A工業 」(末尾に空白)は別の外注先として集計されます。入力規則のリストで選ぶ運用が安全です。この記事の検証は式の動作についてで、入力規則そのものは確認していません。
- **外注先名に「*」や「?」を使わない**: 外注先ごとの集計で、条件として別の意味になることがあります(この記事では確認していません)。
- **発注額超過は「ミス」とは限らない**: 追加の作業を口頭で頼んでいた場合などもあります。発注額を直すか、追加の発注として別の行にするかは、外注先と相談して決めてください。

## 注意点: この記事ができないこと

- 支払期限の計算、振込、支払いの通知はしません。支払期限の出し方は[締め日と支払日から支払期限を出す記事](/payment-due/)にあります。
- 外注費として扱ってよいか、源泉徴収が要るかなど、税務・法律の判断はしません。迷うときは税理士など専門家に確認してください。
- 金額は税抜の整数だけを前提にしています。

## 工事ごとの原価・請求までつなげたいとき

この表で出した外注費を、工事ごとの粗利に反映する方法は[工事の原価を材料・外注・経費に分けて粗利を見る記事](/job-margin/)に、日報から労務費を出す方法は[作業日報から工事ごとの人工と労務費を集計する記事](/daily-labor-by-job/)に、お客様からの入金との照合は[請求と入金をExcelで照合する記事](/payment-match/)にまとめています。見積の計算そのものから作りたい場合は、運営者が作った[工事・リフォーム用 見積書テンプレート(Excel・980円)](/go/estimate-construction/?from=subcontract-balance)があります。数量×単価(四捨五入)、諸経費率、値引き、消費税10%(切り捨て)、税込合計を自動計算し、明細は20行、A4縦1枚で印刷できます。**この記事の「外注先の支払管理」機能は、この商品には入っていません**。請求書への変換、軽減税率の混在、インボイス要件の保証もできません。Excelの確認はWindowsデスクトップ版16のみです。(これは運営者の商品の案内です。)

税込み・税抜の計算だけなら、無料の[見積の合計計算ツール](/tools/estimate-total/)が使えます(入力は外部に送信されません)。

## まとめ

- 発注残 = 発注額 − 請求額、未払額 = 請求額 − 支払済で、「請求待ち」と「払い待ち」を分けて見る
- 請求額が発注額を超えた行は「発注額超過」として、確認のきっかけにする
- 発注残の合計は、超過行のマイナスを足さないよう「0より大きいものだけ」を足す
- 数字でない金額、全角、マイナス、小数、支払済が請求額より多い行は、状態を出さずチェック列で止める
- 26ケースと500行の照合はLibreOfficeで一致。Excelでは未確認のため、本番では数行を手計算で見比べる
