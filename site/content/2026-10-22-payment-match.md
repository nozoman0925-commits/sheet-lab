「あの現場の請求、もう入っているはずだけど通帳を見ないと分からない」。工事の請求は金額が大きく、着手・中間・完了と分けて出すため、**どの請求書がいくら入金済みで、どれが期限を過ぎているか**が頭の中だけだと追いきれなくなります。

この記事では、請求を1行ずつ、入金を1行ずつ入力するだけで、**各請求書を「入金済み・一部入金・未入金・入金遅れ・過入金」に自動で分け、未入金の額と遅れ日数**を出す式を示します。請求番号の打ち間違いで入金がどこにも結びつかないミスも、表に出るようにします。

出典: 筆者がLibreOfficeで計算して確認(検証スクリプト: site/verify/payment_match.py)。外部サイトの説明は参照していません。**Excelでは未確認**です。使うのはIF・SUMIFS・COUNTIF・ISNUMBER・AND・ASC・TRIMなどの一般的な関数ですが、本番の台帳に使う前に数行で結果を確かめてください。金額は請求書に書いた額(税込でも税抜でも、そろえて入れれば同じ動きです)をそのまま入れる例で、消費税・インボイスの扱いの判断はこの記事では行いません。

## 先に結論

2枚のシートを使います。

**「請求」シート**(1行1請求書。2行目から。範囲は2〜2000行の例)

| 列 | 内容 | 入れるもの |
|---|---|---|
| A | 請求番号 | 手入力(例: S-001) |
| B | 請求日 | 手入力(日付) |
| C | 入金期限 | 手入力(日付) |
| D | 請求額 | 手入力 |
| E | 入金済み | 式 |
| F | 未入金 | 式 |
| G | 状態 | 式 |
| H | 遅れ日数 | 式 |
| I | チェック | 式 |
| K | 整えた番号 | 式(全角→半角、前後のスペース除去) |
| N1 | 基準日 | `=TODAY()`(今日の日付で判定する場合) |

```
K2: =ASC(TRIM(A2))
E2: =IF(A2="","",SUMIFS(入金!$C$2:$C$2000,入金!$D$2:$D$2000,K2))
F2: =IF(A2="","",D2-E2)
G2: =IF(A2="","",IF(F2<0,"過入金",IF(F2=0,"入金済み",
      IF(AND(ISNUMBER(C2),$N$1>C2),"入金遅れ",IF(E2>0,"一部入金","未入金")))))
H2: =IF(G2="入金遅れ",$N$1-C2,"")
I2: =IF(A2="","",IF(NOT(ISNUMBER(C2)),"入金期限が日付でない",
      IF(AND(ISNUMBER(B2),C2<B2),"期限が請求日より前","")))
```

**「入金」シート**(1行1回の入金。2行目から)

| 列 | 内容 | 入れるもの |
|---|---|---|
| A | 入金日 | 手入力 |
| B | 請求番号 | 手入力 |
| C | 入金額 | 手入力(実際に通帳に入った額) |
| D | 整えた番号 | 式 |
| E | チェック | 式 |

```
D2: =ASC(TRIM(B2))
E2: =IF(AND(B2="",C2=""),"",IF(B2="","請求番号が空欄",
      IF(COUNTIF(請求!$K$2:$K$2000,D2)=0,"請求番号なし","")))
```

照合用に、請求シートの端に次の式を置きます。

```
P1: 未紐づけの入金額
Q1: =SUM(入金!C2:C2000)-SUM(E2:E2000)
```

入金シートに入力した金額の合計と、請求シート側の入金済みの合計の差です。**0でなければ、どこかの入金が請求書に結びついていません**。入金シートの「チェック」列に出た行を直してください。

ポイントは次の4つです。

- 入金済みは「整えた番号」で集計します。手入力の番号で集計すると、全角や前後のスペースが入った行が集計から漏れます。
- 判定の順番は **過入金 → 入金済み → 入金遅れ → 一部入金 → 未入金** です。期限を過ぎた一部入金は「一部入金」ではなく「入金遅れ」と表示します(入金済みの額は別の列で見えます)。
- 入金期限の**当日**はまだ遅れではありません。基準日が期限より後の日付になったときに「入金遅れ」です。
- 入金期限が空欄や文字のときは、遅れの判定ができません。その請求書は「未入金」などと表示されるだけで、**遅れとは出ません**。そのため、チェック列に「入金期限が日付でない」と表示するようにしています。

## 実際に計算した結果

基準日を2026-11-30に固定して、次の14ケースを計算しました。

| ケース | 請求額 | 入力した入金 | 入金済み | 未入金 | 状態 |
|---|---|---|---|---|---|
| 全額入金 | 1,100,000 | 1,100,000 | 1,100,000 | 0 | 入金済み |
| 2回に分けて入金の途中(期限内) | 500,000 | 200,000 | 200,000 | 300,000 | 一部入金 |
| 未入金・期限内 | 300,000 | なし | 0 | 300,000 | 未入金 |
| 未入金・期限超過(期限10/31) | 300,000 | なし | 0 | 300,000 | 入金遅れ(30日) |
| 期限が基準日と同じ日 | 300,000 | なし | 0 | 300,000 | 未入金(遅れではない) |
| 一部入金のまま期限超過 | 300,000 | 100,000 | 100,000 | 200,000 | 入金遅れ(30日) |
| 二重に振り込まれた | 300,000 | 300,000 + 300,000 | 600,000 | −300,000 | 過入金 |
| 振込手数料440円を引かれた | 330,000 | 329,560 | 329,560 | 440 | 一部入金 |
| 存在しない請求番号 | 330,000 | S-090(請求にない)に330,000 | 0 | 330,000 | 入金側「請求番号なし」、Q1=330,000 |
| 請求番号が空欄の入金 | 330,000 | 番号なしで330,000 | 0 | 330,000 | 入金側「請求番号が空欄」、Q1=330,000 |
| 全角・前後スペースの番号 | 330,000 | 「Ｓ－011」に100,000、「 S-011 」に230,000 | 330,000 | 0 | 入金済み |
| 期限が請求日より前 | 330,000 | なし | 0 | 330,000 | 入金遅れ(20日)+チェック「期限が請求日より前」 |
| 入金期限が空欄 | 330,000 | なし | 0 | 330,000 | 未入金+チェック「入金期限が日付でない」 |
| 入金期限が文字(「月末」) | 330,000 | なし | 0 | 330,000 | 未入金+チェック「入金期限が日付でない」 |

14ケースすべて、入金済み・未入金・状態・遅れ日数・チェック表示・Q1が、Pythonでの計算結果と一致しました。

さらに、請求300件・入金450行の乱数データで照合しました。入金のうち約80%は正しい番号、約6%は存在しない番号、約5%は空欄、約5%は全角、約4%は前後にスペースです。金額は満額・半額・手数料440円差引・ばらばらの額を混ぜ、請求のうち約7%は入金期限を請求日より前、空欄、文字にしています。**全項目が一致**しました(Excelでの確認はしていません)。

## つまずきやすい点

- **振込手数料を引かれて入金されたとき**: この式は差額(例の440円)を、そのまま未入金として表示します。差額を「入金済み」にする処理は入れていません。手数料を相手が引く取り決めがある場合は、入金シートに「手数料分」として同じ請求番号で440円の行を足す運用にすると、未入金が0になります(これも式としては通常の入金と同じ扱いです)。取り決めの有無は取引先との契約が優先です。
- **請求書を作り直したとき**: 番号を変えたなら、古い番号の行を請求シートに残したままにしないでください。残すと未入金として表示され続けます。
- **請求番号の付け方がそろっていないとき**: 請求側が「S-001」、入金側が「S001」のようにハイフンの有無が違うと一致しません。この式は全角→半角と前後のスペースだけを整えます。
- **TODAY関数**: 基準日を `=TODAY()` にすると、ファイルを開くたびに更新されます。この記事の検証では基準日を固定の日付にしており、TODAY関数そのものの動きは確認していません。月末にある日の状態を残したいときは、N1に日付を直接入力してください。
- **範囲の上限**: 式は2000行までです。増えたら範囲を広げてください。
- **行を消したとき**: 請求の行を消すと、その請求あての入金は「請求番号なし」と表示され、Q1に現れます。入金の行を消すと、その分が未入金に戻ります(行の削除操作そのものはExcelでは試していません)。

## 注意点: この記事ができないこと

- 消費税、インボイスの記載要件、請求書の書式の適否は判断しません。
- 入金遅れに対する督促の文面、遅延損害金の計算、取引先との支払条件の妥当性は扱いません。
- 通帳やネットバンクのデータを自動で取り込む機能はありません。入金は手で入力する前提です。
- 契約金額に対する請求の残りを追うには、[工事の分割請求の残額をExcelで管理する式](/split-billing-balance/)を併せて使います。この記事は、**出した請求書がいつ入金されたか**を追う式です。

## 見積から請求までを1つのひな形で

この記事の式は、自分で作った台帳にそのまま使えます。見積の段階の計算(数量×単価、諸経費、値引き、消費税)から作りたい場合は、運営者が作った[工事・リフォーム用 見積書テンプレート(Excel・980円)](/go/estimate-construction/?from=payment-match)があります。数量×単価(四捨五入)、諸経費率、値引き、消費税10%(切り捨て)、税込合計を自動計算し、明細は20行、A4縦1枚で印刷できます。**この記事の請求・入金の照合の機能は、この商品には入っていません**。軽減税率の混在や、インボイス要件の保証もできません。Excelの確認はWindowsデスクトップ版16のみです。(これは運営者の商品の案内です。)

見積の計算の考え方は[見積書の合計・税込計算の記事](/estimate-total/)に、消費税だけをさっと出したいときは無料の[消費税 計算ツール](/tools/tax/)、見積の小計から税込までを一度に出すなら[見積の合計計算ツール](/tools/estimate-total/)が使えます(入力は外部に送信されません)。

## まとめ

- 請求を「請求」シート、入金を「入金」シートに1行ずつ入力し、入金済みはSUMIFSで集計する
- 集計の鍵は、全角・スペースを整えた「整えた番号」の列
- 状態は 過入金 → 入金済み → 入金遅れ → 一部入金 → 未入金 の順で判定し、期限の当日はまだ遅れではない
- 存在しない番号・空欄の入金は、入金側のチェック列と、請求側のQ1(未紐づけの入金額)に出る
- 14ケースと、請求300件・入金450行の照合はLibreOfficeで一致。Excelでは未確認のため、本番では数件を通帳と突き合わせる
