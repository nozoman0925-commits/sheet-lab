見積書を出したあと、返事が来ないまま何週間も経ってしまった、という経験はないでしょうか。忙しいと「出した」ことで安心してしまい、お客様から連絡がなければそのままになりがちです。

この記事では、見積の**提出日**と**金額**、結果(受注・失注)を入れるだけで、**有効期限・「期限切れ／7日以内／回答待ち」・受注額・回答待ちの金額・受注率**を自動で出す式を示します。「そろそろ連絡したほうがいい見積」が一覧で分かるようになります。

出典: 筆者がLibreOfficeで計算して確認(検証スクリプト: site/verify/quote_followup.py)。外部サイトの説明は参照していません。**Excelでは未確認**です。使うのはIF・OR・AND・NOT・ISNUMBER・INT・COUNTIF・SUMIFSという一般的な関数ですが、本番で使う前に、数行を手計算と見比べてください。この記事は表の作り方の説明です。**見積の有効期限を何日にするかは、各社の取り決めに従ってください**(30日は例です)。

## 先に結論: 提出日に「有効日数」を足して、基準日と比べる

- 有効期限 = 提出日 + 有効日数(例: 30日)
- 結果が「受注」「失注」なら、そのまま表示。空欄なら返事待ちとして、有効期限と基準日(今日)を比べる
- 有効期限が基準日より前なら「期限切れ」、7日以内なら「7日以内」、それ以外は「回答待ち」
- 受注額、返事待ちの金額、期限切れの件数、受注率(受注 ÷ (受注+失注))を右側にまとめる

基準日はK1に `=TODAY()` と入れておくと、開くたびに今日になります(検証では日付を直接入れて確認しました)。有効日数はK2に入れます。

## Excelの式

シート名は「見積」。2行目から使います。

| 列 | 内容 | 入れるもの |
|---|---|---|
| A | 見積番号 | 手入力 |
| B | 提出日 | 手入力(日付) |
| C | 金額(税抜) | 手入力(0以上の整数) |
| D | 結果 | 「受注」「失注」のどちらかを入力。まだなら空欄 |
| E | 有効期限 | 式 |
| F | 状態 | 式 |
| G | チェック | 式 |
| K1 | 基準日 | `=TODAY()` または日付 |
| K2 | 有効日数 | 例: 30 |

```
E2: =IF(OR(G2<>"",A2&B2&C2&D2=""),"",B2+$K$2)
F2: =IF(OR(G2<>"",A2&B2&C2&D2=""),"",IF(D2="受注","受注",IF(D2="失注","失注",
      IF(E2<$K$1,"期限切れ",IF(E2-$K$1<=7,"7日以内","回答待ち")))))
G2: =IF(A2&B2&C2&D2="","",IF(A2="","見積番号が空欄",
      IF(COUNTIF($A$2:$A$1000,A2)>1,"見積番号が重複",
      IF(NOT(ISNUMBER($K$1)),"基準日が日付でない",
      IF(OR(NOT(ISNUMBER($K$2)),$K$2<1,$K$2<>INT($K$2)),"有効日数は1以上の整数",
      IF(NOT(ISNUMBER(B2)),"提出日が日付でない",
      IF(OR(B2<1,B2>73050),"提出日が範囲外",
      IF(B2>$K$1,"提出日が基準日より後",
      IF(NOT(ISNUMBER(C2)),"金額が数字でない",
      IF(OR(C2<0,C2<>INT(C2)),"金額は0以上の整数",
      IF(AND(D2<>"受注",D2<>"失注",D2<>""),"結果は受注・失注・空欄のどれか","")))))))))))
```

集計は右側のセルに置きます(ここでは範囲を1000行までにしています)。

```
K5 受注額:           =SUMIFS($C$2:$C$1000,$F$2:$F$1000,"受注")
K6 回答待ちの金額:   =SUMIFS($C$2:$C$1000,$F$2:$F$1000,"期限切れ")
                      +SUMIFS($C$2:$C$1000,$F$2:$F$1000,"7日以内")
                      +SUMIFS($C$2:$C$1000,$F$2:$F$1000,"回答待ち")
K7 期限切れの件数:   =COUNTIF($F$2:$F$1000,"期限切れ")
K8 受注率:           =IF(COUNTIF($F$2:$F$1000,"受注")+COUNTIF($F$2:$F$1000,"失注")=0,"",
                         COUNTIF($F$2:$F$1000,"受注")/(COUNTIF($F$2:$F$1000,"受注")+COUNTIF($F$2:$F$1000,"失注")))
```

K8は「パーセント表示」にしてください。入力ミスの行は状態が空欄になるため、集計には入りません(G列のチェックを先に直す運用です)。

**D列(結果)は、入力規則(リスト「受注,失注」)を付けておくと、入力ゆれを防げます。** この記事の検証は式の動作についてで、入力規則そのものは確認していません。

## 実際に計算して確認した結果(基準日 2026/10/26、有効日数30)

| ケース | 入力 | 有効期限 | 状態 |
|---|---|---|---|
| 提出から10日 | 提出2026/10/16、結果なし | 2026/11/15 | 回答待ち |
| 期限まで7日 | 提出2026/10/3 | 2026/11/2 | 7日以内 |
| 期限まで8日 | 提出2026/10/4 | 2026/11/3 | 回答待ち |
| 期限が今日 | 提出2026/9/26 | 2026/10/26 | 7日以内 |
| 期限が昨日 | 提出2026/9/25 | 2026/10/25 | 期限切れ |
| 受注 | 提出2026/8/1、結果「受注」 | 2026/8/31 | 受注(期限が過ぎていても「受注」) |
| 失注 | 提出2026/8/1、結果「失注」 | 2026/8/31 | 失注 |
| 有効日数14日に変更 | 提出2026/10/10 | 2026/10/24 | 期限切れ |

集計の確認では、受注2件(200万円と40万円)、失注1件(80万円)、返事待ち2件(30万円は回答待ち、10万円は期限切れ)の5行で、受注額 2,400,000、回答待ちの金額 400,000、期限切れ 1件、受注率 66.7%(2÷3)と出ました。結果がすべて空欄なら、分母が0になるため受注率は空欄になります。

入力ミスの行は、有効期限・状態を空欄にして、G列にこう出ます。

| 入力ミス | チェック |
|---|---|
| 見積番号が空欄 | 見積番号が空欄 |
| 見積番号が重複(Q-001とq-001) | 見積番号が重複 |
| 提出日が文字「10/20」、または空欄 | 提出日が日付でない |
| 提出日が0 | 提出日が範囲外 |
| 提出日が基準日より後(日付の逆転) | 提出日が基準日より後 |
| 金額が「30万」・全角「３００，０００」・空欄 | 金額が数字でない |
| 金額が小数・マイナス | 金額は0以上の整数 |
| 結果が「受注済」・「受注␣」(末尾に空白)・「○」 | 結果は受注・失注・空欄のどれか |
| 基準日が空欄または文字 | 基準日が日付でない |
| 有効日数が0・小数・空欄 | 有効日数は1以上の整数 |
| すべて空欄の行 | (何も出さない) |

31ケースすべて、有効期限・状態・チェック表示・集計が、Pythonで計算した結果と一致しました。さらに、乱数で作った**500行**(見積番号の空欄・重複、提出日の文字・空欄・0・基準日より後、金額の文字・全角・マイナス・小数、結果の入力ゆれを約10%混ぜました)でも、**全項目と集計4つが一致**しました。Excelでの確認はしていません。

## つまずきやすい点

- **結果は、決まったら必ずその日に入れる**: 受注・失注を入れ忘れると、いつまでも「期限切れ」に残り、受注率も正しく出ません。
- **「受注」の後ろに空白が付くとエラーになる**: 見た目では分かりません。入力規則のリストで選ぶ運用が安全です。
- **提出日は「2026/10/16」のように入れる**: セルの中で左寄せになっていたら文字です。
- **「7日以内」の7は変えられる**: F列の式の `<=7` を、連絡に余裕がほしければ `<=14` などに変えてください。
- **期限切れ＝失注、ではない**: 有効期限を過ぎても、お客様が検討中のことはあります。「連絡のきっかけ」として使ってください。

## 注意点: この記事ができないこと

- お客様への連絡(メール・電話・通知)そのものはしません。表示するだけです。
- 見積の有効期限を何日にするか、期限を過ぎたときの金額の扱いの助言はしません。
- 金額は税抜の整数だけを前提にしています。税込みの金額や、値引き後の金額を使う場合は、入れる金額をそろえてください。

## 見積から台帳・請求までを1つで見たいとき

受注したあとの流れは、見積の明細から台帳に渡す方法を[見積の明細から台帳に渡す記事](/quote-to-ledger/)に、請求の残額は[分割請求の残額を管理する記事](/split-billing-balance/)に、請求と入金の照合は[請求と入金をExcelで照合する記事](/payment-match/)にまとめています。見積の計算そのものから作りたい場合は、運営者が作った[工事・リフォーム用 見積書テンプレート(Excel・980円)](/go/estimate-construction/?from=quote-followup)があります。数量×単価(四捨五入)、諸経費率、値引き、消費税10%(切り捨て)、税込合計を自動計算し、明細は20行、A4縦1枚で印刷できます。**この記事の「提出後の回答待ち管理」機能は、この商品には入っていません**。請求書への変換、軽減税率の混在、インボイス要件の保証もできません。Excelの確認はWindowsデスクトップ版16のみです。(これは運営者の商品の案内です。)

税込み・税抜の計算だけなら、無料の[見積の合計計算ツール](/tools/estimate-total/)が使えます(入力は外部に送信されません)。

## まとめ

- 提出日 + 有効日数で有効期限を出し、基準日と比べて「期限切れ／7日以内／回答待ち」を出す
- 結果が「受注」「失注」になったものは別扱いにして、受注額・回答待ちの金額・受注率を集計する
- 日付が文字・空欄、提出日が基準日より後、金額が全角や小数、結果の入力ゆれは、状態を出さずチェック列で止める
- 31ケースと500行の照合はLibreOfficeで一致。Excelでは未確認のため、本番では数行を手計算で見比べる
- 期限切れは「連絡のきっかけ」であって、失注の判定ではない
