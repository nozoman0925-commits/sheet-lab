会社名の列から「株式会社」や「(株)」を取り除いて**社名だけの列**を作ると、並べ替えや突き合わせ、重複の確認がしやすくなります。この記事では、法人格の表記を取り除く式を、パターン別に実際に計算して確かめた結果だけを紹介します。

出典: 筆者がLibreOfficeで計算して確認(検証スクリプト: site/verify/kaisha_remove.py)。外部サイトの説明は参照していません。**Excelでは未確認**です。使う関数はExcelにもありますが、本番のデータに使う前に、数行で結果を確かめてください。

## 先に結論

- 取り除きたい表記(株式会社・有限会社・(株)・（株）・㈱・(有)・（有）・㈲)を`SUBSTITUTE`で順に消せば、社名だけの列が作れます(B列)。
- ただしこの式は**文字列の途中にある表記も消します**。「日本株式会社サービス」は「日本サービス」に変わります。
- 先頭と末尾の表記だけを消したいときは、IFで位置を判定する式にします(別の列でそろえる手順は後半)。
- 消したあとに何も残らない行(「株式会社」だけなど)は、「要確認」にして人が見ます。

## 手順1: 法人格の表記を全部消す(B列)

A2に会社名が入っているとして、B2に次の式を入れ、下へコピーします。

```
=TRIM(SUBSTITUTE(SUBSTITUTE(SUBSTITUTE(SUBSTITUTE(SUBSTITUTE(SUBSTITUTE(SUBSTITUTE(SUBSTITUTE(A2&"","株式会社",""),"有限会社",""),"(株)",""),"（株）",""),"㈱",""),"(有)",""),"（有）",""),"㈲",""),"　"," "))
```

表記を1種類ずつ`SUBSTITUTE(…,"その表記","")`で消しています。半角の`(株)`と全角の`（株）`(かっこの幅が違うもの)は別の文字なので、両方を書きます。`A2&""`は、数値などのセルも文字列として扱うための書き方です。

前後に全角スペースや半角スペースが残ると「株式会社 山田」が「 山田」になるため、最後に`TRIM`で整えています(全角スペースは先に半角スペースへ置き換えています)。

## 手順2: 何も残らない行を「要確認」にする(C列)

C2に次の式を入れます。

```
=IF(A2="","",IF(B2="","要確認",B2))
```

元が空欄なら空欄のまま、元はあるのに社名が残らない行(「株式会社」だけなど)は「要確認」になります。

## 実際に計算した結果

| 入力 | B列(全部消す) | C列(要確認つき) |
|---|---|---|
| 株式会社山田 | 山田 | 山田 |
| 山田株式会社 | 山田 | 山田 |
| (株)山田(半角かっこ) | 山田 | 山田 |
| 山田(株)(半角かっこ) | 山田 | 山田 |
| （株）山田(全角かっこ) | 山田 | 山田 |
| ㈱山田 | 山田 | 山田 |
| 有限会社山田商店 | 山田商店 | 山田商店 |
| 株式会社 山田 | 山田 | 山田 |
| 株式会社　山田　(全角スペース混じり) | 山田 | 山田 |
| 山田商事(法人格なし) | 山田商事 | 山田商事 |
| 株式会社(これだけ) | (空) | 要確認 |
| 日本株式会社サービス(途中) | 日本サービス | 日本サービス |
| (空欄) | (空) | (空) |

13パターンすべて、B・C列とも想定どおりの結果でした。ただし最後から2番目の「日本株式会社サービス」は、**社名の一部が消えています**。

## 手順3: 先頭と末尾の表記だけを消す(途中は残す)

途中の表記を残したいときは、先頭を取り除く列と、末尾を取り除く列に分けます。D2〜G2に、次の式を入れて下へコピーします。

```
D2: =TRIM(SUBSTITUTE(A2&"","　"," "))
E2: =IF(OR(LEFT(D2,4)="株式会社",LEFT(D2,4)="有限会社"),MID(D2,5,99),IF(OR(LEFT(D2,3)="(株)",LEFT(D2,3)="（株）",LEFT(D2,3)="(有)",LEFT(D2,3)="（有）"),MID(D2,4,99),IF(OR(LEFT(D2,1)="㈱",LEFT(D2,1)="㈲"),MID(D2,2,99),D2)))
F2: =IF(OR(RIGHT(E2,4)="株式会社",RIGHT(E2,4)="有限会社"),LEFT(E2,LEN(E2)-4),IF(OR(RIGHT(E2,3)="(株)",RIGHT(E2,3)="（株）",RIGHT(E2,3)="(有)",RIGHT(E2,3)="（有）"),LEFT(E2,LEN(E2)-3),IF(OR(RIGHT(E2,1)="㈱",RIGHT(E2,1)="㈲"),LEFT(E2,LEN(E2)-1),E2)))
G2: =IF(A2="","",IF(TRIM(F2)="","要確認",TRIM(F2)))
```

- D列: 全角スペースを半角にして、前後を整えます。
- E列: 先頭が法人格の表記なら、その文字数分を取り除きます(4文字・3文字・1文字を順に判定)。
- F列: 同じことを末尾に対して行います。
- G列: 空欄は空欄、何も残らないときは「要確認」にします。

同じ13パターンで計算すると、「日本株式会社サービス」はG列でも**そのまま「日本株式会社サービス」**で残りました。ほかの12パターンはB・C列と同じ結果です。途中の表記を残したいデータでは、こちらを選びます。

## 注意点: この式ができないこと

- 「合同会社」「一般社団法人」「医療法人」など、上の8種類にない法人格は取り除きません。必要なら、手順1の`SUBSTITUTE`を足してください(足した分は、使う前に数行で確かめてください)。
- 社名の中に法人格と同じ文字列がある会社(手順1のとおり、途中に表記がある場合)は、手順1の式だと名前が変わります。手順3の式でも、「株式会社」が先頭か末尾にあれば消えます。
- 取り除いた社名が同じ会社を指すとは限りません。「山田商事」と「山田商事株式会社」が同じ会社かどうかは、式では判断できません。
- 式は元の列(A列)を書き換えません。結果を残すときは、列をコピーして「値として貼り付け」をしてから元の列を削除します。

## 名簿全体を整えるなら

会社名の法人格のほかに、前株・後株、全角・半角、スペース、電話番号や郵便番号のハイフンなど、名簿には直したい表記ゆれが重なりがちです。運営者が作った「名簿クレンジングシート」は、これらをまとめて整えるExcelのシートです。まず試したい方向けに、50行までの[無料お試し版](https://nozoman.booth.pm/items/8978060)があります。この記事の方法で足りる場合は、使う必要はありません。

ブラウザで手軽に整えたいときは、無料の[全角・半角スペースの削除ツール](/tools/space-remove/)や[電話番号の整形ツール](/tools/phone-format/)も使えます(入力は外部に送信されません)。関連記事: [前株・後株をそろえる方法](/kabu-position/)、[全角・半角スペースの一括削除](/space-remove-zenkaku-hankaku/)。

## まとめ

- 法人格の表記は、`SUBSTITUTE`を重ねて消し、`TRIM`で余ったスペースを整える
- 途中に表記がある社名まで変わる点に注意。気になるなら先頭・末尾だけを消す式にする
- 何も残らない行は「要確認」で残し、無理に直さない

式はいずれもLibreOfficeで計算した結果です。Excelでは未確認のため、本番のデータに使う前に、数行で結果を確かめてください。
