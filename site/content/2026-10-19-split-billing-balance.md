工事の請求を「着手金・中間金・完了時」の3回に分けると、**いくら請求済みで、あといくら残っているか**を台帳で追うのが面倒になります。請求書を作るたびに契約金額を見に行き、電卓で引き算して、工事番号を打ち間違えて別の工事に積み上がっていた——というのもよくある失敗です。

この記事では、**「請求」の表に1行ずつ入力するだけで、「台帳」の表に請求済みと残額が自動で出る**式を示します。あわせて、入力ミス(存在しない工事番号、空欄、全角、契約日より前の日付、請求しすぎ)を表に表示させる列も作ります。

出典: 筆者がLibreOfficeで計算して確認(検証スクリプト: site/verify/split_billing.py)。外部サイトの説明は参照していません。**Excelでは未確認**です。使うのはSUMIFS・INDEX・MATCH・IFERROR・ASC・TRIMなどの一般的な関数ですが、本番の台帳に使う前に、数行で結果を確かめてください。金額はすべて税抜で管理する例です。税込の請求額や、消費税の扱い、インボイスの記載要件の判断はこの記事では行いません。

## 先に結論

2枚のシートを使います。

**「台帳」シート**(1行1工事。2行目から。範囲は2〜2000行の例)

| 列 | 内容 | 入れるもの |
|---|---|---|
| A | 工事番号 | 手入力(例: K-001) |
| B | 契約日 | 手入力 |
| C | 契約金額(税抜) | 手入力 |
| D | 請求済み | 式 |
| E | 残額 | 式 |
| F | 状態 | 式 |

```
D2: =IF(A2="","",SUMIFS(請求!$C$2:$C$2000,請求!$D$2:$D$2000,A2))
E2: =IF(A2="","",C2-D2)
F2: =IF(A2="","",IF(E2<0,"請求超過",IF(E2=0,"請求完了","")))
```

**「請求」シート**(1行1回の請求。2行目から)

| 列 | 内容 | 入れるもの |
|---|---|---|
| A | 請求日 | 手入力 |
| B | 工事番号 | 手入力 |
| C | 請求額(税抜) | 手入力 |
| D | 整えた番号 | 式(全角→半角、前後のスペース除去) |
| E | 契約金額 | 式(台帳から引く) |
| F | チェック | 式 |

```
D2: =ASC(TRIM(B2))
E2: =IF(D2="","",IFERROR(INDEX(台帳!$C$2:$C$2000,MATCH(D2,台帳!$A$2:$A$2000,0)),""))
F2: =IF(AND(B2="",C2=""),"",IF(B2="","工事番号が空欄",IF(E2="","工事番号なし",
      IF(AND(A2<>"",INDEX(台帳!$B$2:$B$2000,MATCH(D2,台帳!$A$2:$A$2000,0))>A2),"契約日より前の日付",""))))
```

さらに、台帳の端のセルに**照合用**として次の式を置きます。

```
H1: 未紐づけの請求額
I1: =SUM(請求!C2:C2000)-SUM(D2:D2000)
```

「請求」に入力した金額の合計と、「台帳」の請求済みの合計が一致していれば0です。**0でなければ、どこかの請求が工事に結びついていません**(工事番号の間違いなど)。請求の「チェック」列に出た行を直してください。

ポイントは3つです。

- 「台帳」の請求済みは、請求の**D列(整えた番号)**で集計します。B列(手入力の番号)で集計すると、全角や前後のスペースが入った行が集計から漏れます。
- 工事番号が台帳にない行は、金額が**どの工事にも足されません**。その代わり、チェック列に「工事番号なし」と出て、I1に未紐づけの額として現れます。
- 行を追加するときは、式の範囲(2〜2000行)の中に入れてください。範囲を超える行は集計されません。

## 実際に計算した結果

次の8ケースを計算しました。

| ケース | 契約金額 | 入力した請求 | 請求済み | 残額 | 表示 |
|---|---|---|---|---|---|
| 分割3回 | 1,000,000 | 300,000 / 400,000 / 100,000 | 800,000 | 200,000 | (なし) |
| ちょうど全額 | 500,000 | 200,000 / 300,000 | 500,000 | 0 | 請求完了 |
| 請求しすぎ | 500,000 | 300,000 / 300,000 | 600,000 | −100,000 | 請求超過 |
| 存在しない工事番号 | 800,000 | K-040(台帳にない)に100,000 | 0 | 800,000 | 請求側「工事番号なし」、I1=100,000 |
| 工事番号が空欄 | 800,000 | 番号なしで100,000 | 0 | 800,000 | 請求側「工事番号が空欄」、I1=100,000 |
| 全角・スペース | 800,000 | 「Ｋ－006」に100,000、「 K-006 」に50,000 | 150,000 | 650,000 | (なし。正しく集計される) |
| 日付の逆転 | 800,000 | 契約日より前の日付で100,000 | 100,000 | 700,000 | 「契約日より前の日付」 |
| 請求なし | 800,000 | なし | 0 | 800,000 | (なし) |

8ケースすべて、請求済み・残額・チェック表示・I1が、Pythonでの計算結果と一致しました。

さらに、工事300件・請求1,000行の乱数データで照合しました。請求のうち約80%は正しい入力、約6%は存在しない番号、約5%は空欄、約5%は全角、約4%は前後にスペースを入れ、日付も契約日の5日前〜90日後にばらつかせています。**請求済み・残額・チェック表示・未紐づけ額のすべてが一致**しました(Excelでの確認はしていません)。

## つまずきやすい点

- **請求の行を消したとき**: **台帳の行を消す**と、その工事あての請求は台帳にない番号になるので、「工事番号なし」と表示され、I1にも現れます(上の「存在しない工事番号」と同じ動きです。行の削除操作そのものはExcelでは試していません)。
- **工事番号の付け方がそろっていないとき**: 台帳が「K-001」、請求が「K001」のようにハイフンの有無が違うと、一致しません。この式は全角→半角と前後のスペースだけを整えます。ハイフンや大文字小文字の違いまでは吸収しません。
- **番号が数字だけのとき**: 台帳と請求の両方を同じ形(どちらも文字列、またはどちらも数値)で入力してください。この記事では数字だけの工事番号の動きを、Excelでは確認していません。「K-001」のように英字を含めると迷いません。
- **範囲の上限**: 式は2000行までです。工事が増えたら、範囲を広げて(`$2000`を`$5000`などに)ください。
- **残額がマイナスになる**のは、請求しすぎ、または契約金額の変更が台帳に反映されていないときです。変更契約(追加工事)の扱いは、この記事では扱いません。台帳の契約金額を直すか、別の工事番号で台帳に足す運用にしてください。
- **日付のチェック**は「請求日が契約日より前」だけです。請求日が空欄の行は、日付のチェックを飛ばします。

## 注意点: この記事ができないこと

- 消費税、インボイスの記載要件、請求書の書式の適否は判断しません。金額を税抜で管理する例です。
- 入金の管理(入金済みか、入金が遅れていないか)は扱いません。
- 出来高に応じた請求割合(例: 30%・50%・20%)の取り決めの妥当性は扱いません。取り決めは取引先との契約が優先です。

## 見積から請求までを1つのひな形で

この記事の式は、自分で作った台帳にそのまま使えます。見積の段階の計算(数量×単価、諸経費、値引き、消費税)から作りたい場合は、運営者が作った[工事・リフォーム用 見積書テンプレート(Excel・980円)](/go/estimate-construction/?from=split-billing-balance)があります。数量×単価(四捨五入)、諸経費率、値引き、消費税10%(切り捨て)、税込合計を自動計算し、明細は20行、A4縦1枚で印刷できます。**この記事の台帳・請求の機能は、この商品には入っていません**。軽減税率の混在や、インボイス要件の保証もできません。Excelの確認はWindowsデスクトップ版16のみです。(これは運営者の商品の案内です。)

見積の計算の考え方は[見積書の合計・税込計算の記事](/estimate-total/)に、消費税だけをさっと出したいときは無料の[消費税 計算ツール](/tools/tax/)、見積の小計から税込までを一度に出すなら[見積の合計計算ツール](/tools/estimate-total/)が使えます(入力は外部に送信されません)。

## まとめ

- 請求を1行ずつ「請求」シートに入力し、「台帳」の請求済みはSUMIFSで集計する
- 集計の鍵は、全角・スペースを整えた「整えた番号」の列
- 存在しない番号・空欄・契約日より前の日付・請求しすぎは、チェック列と状態列に表示させる
- 台帳の請求済みの合計と請求の合計の差(I1)が0でなければ、工事に結びついていない請求がある
- 8ケースと、工事300件・請求1,000行の照合はLibreOfficeで一致。Excelでは未確認のため、本番の台帳では数件を電卓で検算する
