「来週、田中さんは2現場に入る予定になっていた」と、前日になって気づく。工程表を現場ごとに作っていると、**同じ人の予定が別の現場と重なっていても目に入りません**。

この記事では、「工事名・担当・開始日・終了日」を並べた表から、**同じ担当の予定が日付で重なっている工事**に印を付ける式を示します。日付が文字だったり、終了日が開始日より前になっていたりする行は、判定に使わずに理由を表示します。

出典: 筆者がLibreOfficeで計算して確認(検証スクリプト: site/verify/crew_overlap.py)。外部サイトの説明は参照していません。**Excelでは未確認**です。使うのは `COUNTIFS` と `IF` だけですが、本番の前に自分の予定表で数行を見比べてください。

## 先に作る表

「配置」シート(2行目から。1行目は見出し。ここでは50行目までの範囲で書きます)

| 列 | 内容 | 入れるもの |
|---|---|---|
| A | 工事名 | 手入力 |
| B | 担当 | 手入力(職人名・班名) |
| C | 開始日 | 手入力(日付) |
| D | 終了日 | 手入力(日付。1日だけなら開始日と同じ) |
| E | 入力チェック | 式 |
| F | 有効 | 式(判定に使える行なら1) |
| G | 重なり数 | 式 |
| H | 判定 | 式 |

```
E2: =IF(AND(B2="",C2="",D2=""),"",IF(B2="","担当が空欄",IF(NOT(ISNUMBER(C2)),"開始日が日付でない",
      IF(NOT(ISNUMBER(D2)),"終了日が日付でない",IF(D2<C2,"終了日が開始日より前","")))))
F2: =IF(AND(B2<>"",E2="",NOT(AND(B2="",C2="",D2=""))),1,0)
G2: =IF(F2=1,COUNTIFS($B$2:$B$50,B2,$F$2:$F$50,1,$C$2:$C$50,"<="&D2,$D$2:$D$50,">="&C2)-1,"")
H2: =IF(E2<>"",E2,IF(F2=0,"",IF(G2>0,"重なりあり("&G2&"件)","OK")))
```

考え方は2つです。

- **2つの期間が重なる条件は「Aの開始日 ≦ Bの終了日」かつ「Aの終了日 ≧ Bの開始日」**です。G列は、同じ担当で、この条件を満たす行を数えています。自分自身も数えてしまうので、最後に1を引いています。
- 日付が文字の行や、終了日が開始日より前の行は、数えると結果がずれます。そこでF列で「判定に使える行」だけに1を付け、**G列の数え上げもF列が1の行だけ**にしています。おかしい行が混ざっていても、ほかの行の判定はそのまま正しくなります。

## 実際に計算した結果(12月の例)

| 工事 | 担当 | 期間 | 判定 |
|---|---|---|---|
| A邸 内装 | 田中 | 12/1〜12/5 | 重なりあり(1件) |
| B邸 水まわり | 田中 | 12/5〜12/8 | 重なりあり(1件)(12/5が重なる) |
| C邸 外壁 | 田中 | 12/9〜12/12 | OK |
| D邸 解体 | 鈴木 | 12/1〜12/3 | OK |
| E邸 解体 | 鈴木 | 12/4〜12/6 | OK(日が隣り合うだけ) |
| F邸 大工 | 佐藤 | 12/1〜12/20 | 重なりあり(2件) |
| G邸 大工 | 佐藤 | 12/10〜12/10 | 重なりあり(2件) |
| H邸 大工 | 佐藤 | 12/10〜12/11 | 重なりあり(2件) |
| I邸 | (空欄) | 12/1〜12/2 | 担当が空欄 |
| J邸 | 山本 | 「12月1日」(文字)〜12/2 | 開始日が日付でない |
| K邸 | 山本 | 12/1〜(空欄) | 終了日が日付でない |
| L邸 | 山本 | 12/9〜12/3 | 終了日が開始日より前 |
| M邸 | 山本 | 12/1〜12/30 | OK(山本さんの有効な行はこの1件だけのため) |
| N邸 | 田中 | 12/20〜12/22 | OK |
| O邸 | 「田中 」(末尾に空白) | 12/20〜12/21 | OK(別の人として扱われる) |

2件の重なりが出た F・G・H 邸は、F邸の期間(12/1〜12/20)の中に、G邸とH邸が入っているためです。重なりがあった行は、行ごとに「何件と重なるか」が出ます。

上の16ケース(空行を含む)に加え、乱数で作った360行(10組)でも、判定が**全件一致**しました(Pythonの総当たりと比較。検証はLibreOfficeのみ。Excelでは未確認)。

## 使うときの注意

- **「重なり」は日付だけで見ています**。午前と午後で現場を分けている場合も「重なりあり」と出ます。出た行を人が見て判断してください。
- **担当名の表記を揃えます**。「田中」と「田中 」(末尾の空白)や「田中」と「田中さん」は別の人として数えられ、重なりを見落とします。担当は選択式にするなど、入力の揺れを減らしてください。名前の揺れをそろえる関数は[SUBSTITUTEとTRIMで不要な文字・スペースを取り除く方法](/space-remove-zenkaku-hankaku/)が参考になります。
- 土日・休工日は考慮しません。開始日から終了日までの**カレンダーの日付すべて**を対象にしています。
- 判定はこの表の中だけです。**表に入れていない予定(別の仕事、休み)とは比べません**。
- 範囲を `$B$2:$B$50` のように固定しているので、行を増やしたときは範囲を広げてください。行を削除すると式が壊れることがあるため、削除ではなく中身を消すほうが安全です。
- 日付は日付として入力してください。全角数字や「12月1日」のような文字は、日付と見なされず「日付でない」と出ます。

## この記事ができないこと

- 人員の手配の最適化や、空いている職人の自動提案はしません。
- 工程の遅れの判定は、別記事の[工事の工程表で遅れている工程を自動で表示する式](/schedule-delay/)にあります。
- 労働時間や法令の基準の確認はしません。

## 見積から工事台帳・請求まで一続きにしたいとき

配置表の工事名は、見積や工事台帳と同じ名前で揃えておくと、後で突き合わせやすくなります。見積から工事台帳への転記の式は[見積から工事台帳への転記](/quote-to-ledger/)にまとめています。見積の計算(数量×単価、諸経費、値引き、消費税)そのものを作りたい場合は、運営者が作った[工事・リフォーム用 見積書テンプレート(Excel・980円)](/go/estimate-construction/?from=crew-overlap)があります。数量×単価(四捨五入)、諸経費率、値引き、消費税10%(切り捨て)、税込合計を自動計算し、明細は20行、A4縦1枚で印刷できます。**この記事の職人の重なりの判定は、この商品には入っていません**。軽減税率の混在や、インボイス要件の保証もできません。Excelの確認はWindowsデスクトップ版16のみです。(これは運営者の商品の案内です。)

見積の合計だけをすぐ確かめたいときは、無料の[見積の合計計算ツール](/tools/estimate-total/)が使えます(入力は外部に送信されません)。

## まとめ

- 期間の重なりは「Aの開始日≦Bの終了日 かつ Aの終了日≧Bの開始日」。`COUNTIFS` で同じ担当を数え、自分の分を1引く
- 担当の空欄・日付が文字・終了日が前の行は、有効フラグで判定から外し、理由を表示する
- 日付だけで判定するため、半日ずつの配置も「重なりあり」と出る。担当名の揺れは重なりの見落としになる
- 16ケースと乱数360行の照合はLibreOfficeで一致、Excelでは未確認のため、本番では自分の予定で数行を見比べる
