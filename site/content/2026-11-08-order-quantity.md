「床材は20㎡だから、1箱1.62㎡で割って…何箱だっけ。ロスも見ないと足りなくなる」。材料の発注は、数量にロス(切りくずや失敗の分)を足して、箱や枚の単位に**切り上げる**ところで、電卓の計算がずれやすい作業です。足りなければ現場が止まり、多すぎれば余ります。

この記事では、**必要数量・ロス率・1箱の入数**を入れると、**発注箱数・発注数量・余り**が出る式を示します。ロス率を「10」と入れてしまうような誤入力も、結果を出す前に止めます。

出典: 筆者がLibreOfficeで計算して確認(検証スクリプト: site/verify/order_qty.py)。外部サイトの説明は参照していません。**Excelでは未確認**です。使うのはROUNDUP・ROUND・IF・N・ISNUMBERなどの一般的な関数ですが、本番で使う前に数行で結果を確かめてください。なお、**ロス率の目安は材料・現場・施工者で違うため、この記事では決めません**(自分の現場の数字を入れてください)。

## 先に作る表

「発注」シート(1行1品目。2行目から。1行目は見出し)

| 列 | 内容 | 入れるもの |
|---|---|---|
| A | 品名 | 手入力 |
| B | 必要数量 | 手入力(図面から拾った数量。単位は入数とそろえる) |
| C | ロス率 | 手入力(10%なら `10%` または `0.1`。空欄は0%) |
| D | 1箱の入数 | 手入力(1箱1.62㎡なら `1.62`) |
| E | チェック | 式 |
| F | 発注箱数 | 式 |
| G | 発注数量 | 式(箱数×入数) |
| H | 余り | 式(発注数量−必要数量) |

```
E2: =IF(AND(A2="",B2="",D2=""),"",IF(OR(NOT(ISNUMBER(B2)),NOT(ISNUMBER(D2))),"数量か入数が数字でない",
      IF(OR(B2<0,D2<=0),"数量が負か入数が0以下",IF(AND(C2<>"",NOT(ISNUMBER(C2))),"ロス率が数字でない",
      IF(N(C2)<0,"ロス率が負",IF(N(C2)>1,"ロス率が100%超",""))))))
F2: =IF(OR(E2<>"",AND(A2="",B2="",D2="")),"",ROUNDUP(ROUND(B2*(1+N(C2))/D2,6),0))
G2: =IF(F2="","",F2*D2)
H2: =IF(F2="","",ROUND(G2-B2,6))
```

考え方は3つです。

- **必要数量×(1+ロス率)÷1箱の入数**で必要な箱数を出し、**ROUNDUPで整数に切り上げ**ます(13.58箱なら14箱)。
- 小数の計算では、割り切れるはずの値が `55.00000000000001` のようにごくわずかに大きくなることがあり、ROUNDUPだけだと1箱多くなる心配があります。そこで**ROUNDで小数6桁にそろえてから切り上げ**ています。今回のLibreOfficeの検証では、ROUNDを挟まない式でも結果は変わりませんでしたが、Excelでは未確認なので、安全のために挟む形で書いています。
- ロス率の空欄は0%として扱います(`N(C2)`)。文字が入っているときはチェックで止めます。

## 実際に計算した結果

| ケース | 必要数量・ロス率・入数 | 結果 |
|---|---|---|
| 床材 | 20㎡・10%・1.62㎡/箱 | 14箱(22.68㎡、余り2.68㎡) |
| 石こうボード | 12㎡・10%・1.65㎡/枚 | 8枚(13.2㎡、余り1.2㎡) |
| 割り切れる | 50・10%・1 | 55(余り5) |
| ロス率0で割り切れる | 10・0%・2.5 | 4(余り0) |
| ロス率が空欄 | 10・(空欄)・2 | 5(余り0) |
| 必要数量が0 | 0・10%・2 | 0箱 |
| 釘 | 1,200本・5%・500本/箱 | 3箱(1,500本、余り300本) |
| 入数が0 | 10・10%・0 | チェック「数量が負か入数が0以下」 |
| 入数が空欄 | 10・10%・(空欄) | チェック「数量か入数が数字でない」 |
| 数量に「約20」 | 約20・10%・2 | チェック「数量か入数が数字でない」 |
| ロス率に「1割」 | 10・1割・2 | チェック「ロス率が数字でない」 |
| ロス率を10と入力(10%のつもり) | 10・10(=1000%)・2 | チェック「ロス率が100%超」 |
| ロス率が負 | 10・-10%・2 | チェック「ロス率が負」 |
| 数量が負 | -5・10%・2 | チェック「数量が負か入数が0以下」 |
| 空行 | (なし) | すべて空欄 |

16ケースすべて、チェック表示・発注箱数・発注数量・余りが分数計算の期待値と一致しました。さらに、必要数量・ロス率・入数を乱数で組み合わせた500行でも**全件一致**しました(検証はLibreOfficeのみ。Excelでは未確認)。

## 使うときの注意

- **ロス率は「10%」か「0.1」で入れます**。「10」だけだと1,000%の意味になるので、チェックで止まります。ただし、ロス率を上限100%までにしているだけなので、「0.5」を5%のつもりで入れた場合(実際は50%)は止まりません。
- **単位をそろえてください**。必要数量が㎡なら入数も㎡、本数なら本数にします。㎡を坪や畳に換算する計算は、この式には入っていません。
- **余りは「在庫として使えるか」まで判断しません**。箱を開けたあとの端材が使えるか、次の現場で使えるかは現場しだいです。
- **メーカーの最小発注単位や、まとめ買いの割引は考慮していません**。入数に「1箱の入数」を入れる前提です。バラ売りの有無は仕入先に確認してください。
- 品名ごとに1行を使います。同じ品名の複数の部屋を足し合わせたいときは、先に必要数量を合計してから入れてください(部屋ごとに切り上げると、合計では余りが増えます)。

## この記事ができないこと

- 施工に必要なロス率や必要数量の決定はしません(自分の現場の実績や仕入先の目安で決めてください)。
- 図面からの数量拾いはしません。
- 仕入先への発注書づくりや、価格・納期の管理はしません。

## 見積や請求とあわせて管理したいとき

材料費を工事ごとの原価に入れて粗利を見る式は[工事の原価を材料・外注・経費に分けて粗利を見る式](/job-margin/)に、見積から台帳への転記は[見積から工事台帳への転記](/quote-to-ledger/)にまとめています。見積の計算(数量×単価、諸経費、値引き、消費税)から作りたい場合は、運営者が作った[工事・リフォーム用 見積書テンプレート(Excel・980円)](/go/estimate-construction/?from=order-quantity)があります。数量×単価(四捨五入)、諸経費率、値引き、消費税10%(切り捨て)、税込合計を自動計算し、明細は20行、A4縦1枚で印刷できます。**この記事の発注数の機能は、この商品には入っていません**。軽減税率の混在や、インボイス要件の保証もできません。Excelの確認はWindowsデスクトップ版16のみです。(これは運営者の商品の案内です。)

見積の合計だけをすぐ確かめたいときは、無料の[見積の合計計算ツール](/tools/estimate-total/)が使えます(入力は外部に送信されません)。

## まとめ

- 発注箱数は「必要数量×(1+ロス率)÷1箱の入数」を切り上げる。小数のごく小さな誤差を避けるため、ROUNDで小数6桁にそろえてからROUNDUPする
- 余りは「箱数×入数−必要数量」で出し、1箱追加で足りるか・余らせすぎていないかを見る
- ロス率を10と入れる、入数が0、数量が文字などの誤入力は、チェック列で止めて結果を出さない
- ロス率の目安は決めない。16ケースと乱数500行の照合はLibreOfficeで一致、Excelでは未確認のため、本番では数行を電卓で検算する
