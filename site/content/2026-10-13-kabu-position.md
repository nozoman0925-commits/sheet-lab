名簿に「山田株式会社」と「株式会社山田」が混ざっていると、並べ替えても同じ会社が離れてしまい、重複も探せません。この記事では、「株式会社」の位置を**前株(株式会社山田)か後株(山田株式会社)のどちらかにそろえる**式を、パターン別に実際に計算して確かめた結果だけを紹介します。

出典: 筆者がLibreOfficeで計算して確認(検証スクリプト: site/verify/kabu_position.py)。外部サイトの説明は参照していません。**Excelでは未確認**です。使う関数はExcelにもありますが、本番のデータに使う前に、数行で結果を確かめてください。

## 先に結論

- 「株式会社」は4文字なので、`LEFT(A2,4)`と`RIGHT(A2,4)`で前株か後株かを判定できます。
- 前株にそろえるなら、後株の行だけ「株式会社」を頭につけて、末尾の4文字を取り除きます。
- 間や末尾にスペースが混じると判定が外れるので、先にスペースを整えます。
- 「株式会社」が両端にある、社名の途中にある、といった行は、式で無理にそろえず、人が確認します。

## 手順1: まず位置を判定する(B列)

A2に会社名が入っているとして、B2に次の式を入れ、下へコピーします。

```
=IF(A2="","",IF(AND(LEFT(A2,4)="株式会社",RIGHT(A2,4)="株式会社",LEN(A2)>4),"要確認",IF(LEFT(A2,4)="株式会社","前株",IF(RIGHT(A2,4)="株式会社","後株",IF(ISNUMBER(FIND("株式会社",A2)),"途中","なし")))))
```

実際に計算した結果は次のとおりです。

| 入力 | 判定 |
|---|---|
| 山田株式会社 | 後株 |
| 株式会社山田 | 前株 |
| 有限会社山田 | なし |
| 山田商事 | なし |
| 山田株式会社東京 | 途中 |
| 株式会社山田株式会社 | 要確認 |
| (空欄) | (空欄) |

「要確認」は、先頭と末尾の両方が「株式会社」の行です。どちらが本来の位置か式では決められないため、人が見るための印にしています。

## 手順2: 前株にそろえる(C列)

B列の判定を使い、後株の行だけ作り替えます。

```
=IF(B2="後株","株式会社"&LEFT(A2,LEN(A2)-4),A2)
```

「山田株式会社」は、末尾の4文字を除いた「山田」の前に「株式会社」をつけて「株式会社山田」になりました。前株・なし・途中・要確認の行は、元の文字のまま出ます。

## 手順3: 後株にそろえる(D列)

反対に後株にそろえるなら、前株の行だけ作り替えます。

```
=IF(B2="前株",MID(A2,5,LEN(A2))&"株式会社",A2)
```

「株式会社山田」は「山田株式会社」になりました。`MID(A2,5,LEN(A2))`は、5文字目から最後までを取り出します。

## 注意点: スペースが混じると判定が外れる

実際に計算すると、スペースが混じる2つの入力は、次のように動きました。

| 入力 | 判定 | 前株にそろえた結果 |
|---|---|---|
| 山田 株式会社(間にスペース) | 後株 | 「株式会社山田 」(末尾にスペースが残る) |
| 山田株式会社 (末尾にスペース) | 途中 | 変わらない(末尾が「株式会社」ではないため) |

つまり、間のスペースは結果に残り、末尾のスペースは判定そのものを外します。先に、全角スペースを半角に直してからTRIMで前後と連続のスペースを整えておくと防げます。

```
=TRIM(SUBSTITUTE(A2,"　"," "))
```

計算では、「山田株式会社 」(末尾スペース)は「山田株式会社」に、「　株式会社　山田」は「株式会社 山田」になりました。この式の結果の列を元に、手順1〜3を行うと安全です。間に残る半角スペースまで消したい場合は、[全角・半角スペースの一括削除](/space-remove-zenkaku-hankaku/)の式を組み合わせてください。

## 注意点: この式ができないこと

- 「(株)」「㈱」「（株）」など、略した書き方は判定しません。先に「株式会社」に置き換える必要があります。
- 「有限会社」「合同会社」など、ほかの法人格は対象外です。同じ考え方で文字数(有限会社も4文字)を変えて作れますが、今回は「株式会社」だけを確認しました。
- 社名の途中にある「株式会社」(例: 山田株式会社東京)は、式では動かしません。
- 前株と後株で別の会社になる場合もあるため、そろえた結果は元の列を残して確認してください。

## 元のデータに戻すとき

式の結果を残したいときは、結果の列をコピーして「値として貼り付け」をしてから、元の列を削除します。いきなり元の列を上書きすると、やり直せなくなるので、列を分けておくのが安全です。

## 名簿全体を整えるなら

会社名の位置のほかに、電話番号のハイフン、全角・半角、スペースの混在など、名簿には直したい表記ゆれが重なりがちです。運営者が作った「名簿クレンジングシート」は、法人格の表記や電話番号などをまとめて整えるExcelのシートです。まず試したい方向けに、50行までの[無料お試し版](https://nozoman.booth.pm/items/8978060)があります。この記事の方法で足りる場合は、使う必要はありません。

ブラウザで手軽に整えたいときは、無料の[スペース一括削除ツール](/tools/space-remove/)や[電話番号の整形ツール](/tools/phone-format/)も使えます(どちらも入力は外部に送信されません)。

## まとめ

- 「株式会社」は4文字。`LEFT`と`RIGHT`で位置を判定する
- 前株にそろえるなら`"株式会社"&LEFT(A2,LEN(A2)-4)`、後株なら`MID(A2,5,LEN(A2))&"株式会社"`
- スペースが混じると判定が外れるので、先に整える
- 両端や途中にあるものは「要確認」にして人が見る

式はいずれもLibreOfficeで計算した結果です。Excelでは未確認のため、本番のデータに使う前に、数行で結果を確かめてください。
