「最初は300万円の工事だったのに、追加で20万円、あとで5万円の減額……今の契約金額はいくらだっけ」。追加工事が出るたびに台帳の契約金額を**上書き**していると、当初の金額も、いつ・いくら変わったかも分からなくなります。

この記事では、契約金額を上書きせずに、**当初の契約金額**と**変更履歴(追加・減額)**を別の表に持ち、**現在の契約金額**と**変更回数**を式で出す方法を示します。ここで出した現在の契約金額は、[出来高と今回請求できる額の式](/progress-billing/)の「契約金額」や、[分割請求の残額の式](/split-billing-balance/)にそのまま使えます。

出典: 筆者がLibreOfficeで計算して確認(検証スクリプト: site/verify/contract_change.py)。外部サイトの説明は参照していません。**Excelでは未確認**です。使うのはIF・OR・NOT・ISNUMBER・INT・SUMIFS・COUNTIF・COUNTIFSという一般的な関数ですが、本番で使う前に、契約書・変更契約書(注文書)の金額と手計算の数行を見比べてください。この記事は表の作り方の説明であり、追加工事の金額の決め方や、変更契約に関する法令上の扱いの助言はしません。金額はすべて**税抜**で扱います(消費税の計算は含みません)。

## 先に結論: 「契約表」と「変更履歴」の2枚に分ける

- **契約シート**: 1工事1行。工事番号と、**当初の**契約金額(変更しない)だけを手入力する
- **変更シート**: 変更のたびに1行追加。工事番号・変更日・内容・増減額(追加はプラス、減額はマイナス)を手入力する
- 現在の契約金額 = 当初の契約金額 + その工事の増減額の合計(SUMIFS)

当初の金額が残るので、「当初300万円、追加2回・減額1回で現在○円」と経緯をさかのぼれます。

## Excelの式

### 契約シート(シート名は「契約」。2行目から使う)

| 列 | 内容 | 入れるもの |
|---|---|---|
| A | 工事番号 | 手入力(例: A-001) |
| B | 当初の契約金額(税抜) | 手入力(円・整数) |
| C | 変更の合計 | 式 |
| D | 現在の契約金額 | 式 |
| E | 変更回数 | 式 |
| F | チェック | 式 |

```
C2: =IF(OR(F2<>"",A2&B2=""),"",SUMIFS(変更!$D$2:$D$1000,変更!$A$2:$A$1000,A2))
D2: =IF(OR(F2<>"",A2&B2=""),"",B2+C2)
E2: =IF(OR(F2<>"",A2&B2=""),"",COUNTIFS(変更!$A$2:$A$1000,A2))
F2: =IF(A2&B2="","",IF(A2="","工事番号が空欄",
      IF(COUNTIF($A$2:$A$1000,A2)>1,"工事番号が重複",
      IF(NOT(ISNUMBER(B2)),"当初契約額が数字でない",
      IF(OR(B2<0,B2<>INT(B2)),"当初契約額は0以上の整数",
      IF(COUNTIFS(変更!$A$2:$A$1000,A2,変更!$E$2:$E$1000,"?*")>0,"この工事の変更行にエラーがある",
      IF(B2+SUMIFS(変更!$D$2:$D$1000,変更!$A$2:$A$1000,A2)<0,
         "変更の合計が大きすぎる(現契約額がマイナス)","")))))))
```

### 変更シート(シート名は「変更」。2行目から使う)

| 列 | 内容 | 入れるもの |
|---|---|---|
| A | 工事番号 | 手入力(契約シートと同じ表記) |
| B | 変更日 | 手入力(日付) |
| C | 内容 | 手入力(例: 外構の追加) |
| D | 増減額(税抜) | 手入力(追加はプラス、減額はマイナス) |
| E | チェック | 式 |

```
E2: =IF(A2&B2&C2&D2="","",IF(A2="","工事番号が空欄",
      IF(COUNTIF(契約!$A$2:$A$1000,A2)=0,"契約表にない工事番号",
      IF(NOT(ISNUMBER(B2)),"変更日が日付でない",
      IF(OR(B2<1,B2>73050),"変更日が範囲外",
      IF(NOT(ISNUMBER(D2)),"増減額が数字でない",
      IF(D2<>INT(D2),"増減額は整数の円",
      IF(D2=0,"増減額が0","")))))))) 
```

ポイントは次の4つです。

- **文字になった金額は、SUMIFSが黙って無視します**。「20万」や全角の「２００，０００」と入っていても、合計はエラーにならず、その行だけ抜けた金額が出ます。これがいちばん気づきにくい間違いなので、変更シートのE列で「増減額が数字でない」と止め、契約シートでも**その工事の現在の契約金額を空欄にして**「この工事の変更行にエラーがある」と出します(間違った金額を見せないためです)。
- 契約シートのチェックは、変更シートのチェック列に文字が入っているかを `"?*"`(1文字以上の文字)で数えて見つけています。
- 範囲を `$2:$1000` と大きめにとっておくと、行を足しても式を直さなくて済みます。行の数が1000を超えるときは、数字を大きくしてください。
- 工事番号の照合は、**大文字小文字を区別しません**(a-001とA-001は同じ扱い)。一方、**全角の「Ａ-００１」や、末尾にスペースのある「A-001␣」は別の番号**として扱われ、「契約表にない工事番号」になります(LibreOfficeでの結果です)。

## 実際に計算した結果

契約シートは、A-001(当初3,000,000円)とA-002(当初1,500,000円)の2行で、変更シートに1行ずつ入れて確認しました。

| 存在しない工事番号 | 「A-009」、+100,000 | 契約表にない工事番号 | 3,000,000(変更回数0) |
| 全角の工事番号 | 「Ａ-００１」、+100,000 | 契約表にない工事番号 | 3,000,000(変更回数0) |

22ケースすべて、変更の合計・現在の契約金額・変更回数・チェック表示が、Pythonで計算した結果と一致しました。

さらに、乱数で作った**契約200行・変更履歴600行**(工事番号の大文字小文字・全角・末尾スペース・空欄、日付の文字・空欄、増減額の文字・空欄・小数・0、当初契約額の文字・空欄・負の数・小数、番号の重複などを約10%混ぜました)でも、**全項目が一致**しました。Excelでの確認はしていません。

なお、この確認の途中で、変更履歴が600行あるのに式の範囲を500行までにしていたため、後ろの行が合計から抜けて乱数照合が合わない、という間違いを自分で出しました。範囲の下端が足りないと**エラーも出ずに合計だけが少なくなる**ので、行が増えても大丈夫な大きさにしておくこと、そして数行を手で検算することをおすすめします。

## つまずきやすい点

- **行を消すときは、変更シートの行も見る**: 契約シートの工事の行を消すと、その工事の変更行が「契約表にない工事番号」になって残ります(上の表の最後のケース)。変更行のチェックを見て片づけてください。
- **値引き・減額は、マイナスで入れる**: 減額を「50000」と入れると増額として計算されます。内容の欄に「減額」と書いておくと、あとで見直しやすくなります。
- **税込で入れない**: 当初の契約金額と増減額は、同じ税抜で入れてください。税込と税抜が混ざると、現在の契約金額が合いません。
- **工事番号は、見た目だけで同じに見えても別のものになることがある**: 全角と半角、末尾のスペースは別の番号になります。入力欄にコピーして貼る前に、半角にそろえてください。

## 注意点: この記事ができないこと

- 追加工事の金額の決め方、変更契約書の作り方、契約変更に関する法令上の扱いの確認はしません。契約書・注文書を正としてください。
- 消費税・インボイス(適格請求書)の記載項目の計算や判断はしません。
- 請求済みの管理は[分割請求の残額の記事](/split-billing-balance/)、出来高は[出来高の記事](/progress-billing/)で扱っています。この記事は現在の契約金額を出すところまでです。

## 見積から台帳・請求までを1つで見たいとき

見積から台帳への転記は[見積の明細から台帳に渡す記事](/quote-to-ledger/)に、工事ごとの原価と粗利は[原価を材料・外注・経費に分けて粗利を見る記事](/job-margin/)にまとめています。見積の計算そのものから作りたい場合は、運営者が作った[工事・リフォーム用 見積書テンプレート(Excel・980円)](/go/estimate-construction/?from=contract-change)があります。数量×単価(四捨五入)、諸経費率、値引き、消費税10%(切り捨て)、税込合計を自動計算し、明細は20行、A4縦1枚で印刷できます。**この記事の「変更履歴から現在の契約金額を出す」機能は、この商品には入っていません**。請求書への変換、軽減税率の混在、インボイス要件の保証もできません。Excelの確認はWindowsデスクトップ版16のみです。(これは運営者の商品の案内です。)

税込み・税抜の計算だけなら、無料の[見積の合計計算ツール](/tools/estimate-total/)が使えます(入力は外部に送信されません)。

## まとめ

- 契約金額は上書きしない。「契約」シート(当初の金額)と「変更」シート(増減額の履歴)に分ける
- 現在の契約金額は、当初の契約金額に、SUMIFSで集めた増減額の合計を足して出す。変更回数はCOUNTIFSで数える
- SUMIFSは文字の金額を黙って無視する。変更シートのチェックで止め、その工事の現在の契約金額は空欄にして「要確認」にする
- 工事番号は大文字小文字を区別せず、全角・末尾スペースは別物として「契約表にない工事番号」で拾える
- 22ケースと、契約200行・変更600行の照合はLibreOfficeで一致。Excelでは未確認のため、本番では契約書の金額と数行を手で検算する
