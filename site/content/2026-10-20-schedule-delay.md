「あの現場、解体はもう終わっているはずなのに、次の大工が入れない」。工程の遅れは、気づいた時にはすでに後ろの工程に響いていることが多いものです。工程表を毎日眺めて遅れを探すのではなく、**予定終了日を過ぎているのに終わっていない工程に、自動で「遅れ」と出る**ようにしておくと、確認の手間が減ります。

この記事では、工程を1行ずつ入力すると、各工程を**「遅れ・進行中・着工前・完了・完了(遅れ)」**に自動で分け、**遅れ日数**と**工事ごとの遅れ工程数**を出す式を示します。

出典: 筆者がLibreOfficeで計算して確認(検証スクリプト: site/verify/schedule_delay.py)。外部サイトの説明は参照していません。**Excelでは未確認**です。使うのはIF・MAX・COUNTIFS・SUMIFS・MATCH・ISNUMBER・ASC・TRIMなどの一般的な関数ですが、本番の工程表に使う前に数行で結果を確かめてください。

## 先に作る表: 2枚のシート

**「工程」シート**(1行1工程。2行目から。1行目は見出し)

| 列 | 内容 | 入れるもの |
|---|---|---|
| A | 工事番号 | 手入力(例: K-001) |
| B | 工種 | 手入力(解体、大工、電気など) |
| C | 予定開始 | 手入力(日付) |
| D | 予定終了 | 手入力(日付) |
| E | 実績終了 | 終わったら手入力(日付)。終わるまで空欄 |
| F | 整えた番号 | 式(全角→半角、前後のスペース除去) |
| G | チェック | 式 |
| H | 遅れ日数 | 式 |
| I | 状態 | 式 |

右端に基準日を置きます。**本番ではK1に `=TODAY()` を入れます**(開くたびに今日の日付になります)。

```
J1: 基準日    K1: =TODAY()
K2: =COUNTIF(I2:I2000,"要確認")      ← 入力を見直す行の数
```

```
F2: =ASC(TRIM(A2))
G2: =IF(AND(A2="",C2="",D2=""),"",IF(A2="","工事番号が空欄",IF(ISNA(MATCH(F2,台帳!$A$2:$A$2000,0)),"工事番号なし",
      IF(OR(NOT(ISNUMBER(C2)),NOT(ISNUMBER(D2))),"予定日が未入力か日付でない",IF(D2<C2,"日付が逆転",
      IF(AND(E2<>"",NOT(ISNUMBER(E2))),"実績日が日付でない",""))))))
H2: =IF(G2<>"","",IF(AND(A2="",C2="",D2=""),"",IF(E2<>"",MAX(0,E2-D2),MAX(0,$K$1-D2))))
I2: =IF(AND(A2="",C2="",D2=""),"",IF(G2<>"","要確認",IF(E2<>"",IF(H2>0,"完了(遅れ)","完了"),
      IF(H2>0,"遅れ",IF($K$1<C2,"着工前","進行中")))))
```

**「台帳」シート**(1行1工事。A列に工事番号)

```
B2: =IF(A2="","",COUNTIFS(工程!$F$2:$F$2000,A2,工程!$H$2:$H$2000,">0"))   ← 遅れ工程の数
C2: =IF(A2="","",SUMIFS(工程!$H$2:$H$2000,工程!$F$2:$F$2000,A2))          ← 遅れ日数の合計
```

考え方は2つです。

- **まだ終わっていない工程**は、基準日が予定終了日を過ぎた日数が遅れ日数です。
- **すでに終わった工程**は、実績終了が予定終了を過ぎた日数が遅れ日数です(終わった後も、遅れた事実が残ります)。

予定終了日の**当日は遅れにしません**(予定終了日の翌日から「遅れ1日」)。ここは会社の考え方に合わせて、`$K$1-D2` を `$K$1-D2+1` などに変えることもできますが、この記事の検証は当日を遅れにしない形で行っています。

15ケースすべて、チェック表示・遅れ日数・状態・台帳の遅れ工程数と遅れ日数の合計が、Pythonでの計算と一致しました。

さらに、工事300件・工程1,000行の乱数データ(正しい入力は約76%、存在しない番号・番号の空欄・全角・前後スペース・日付の逆転・予定終了の空欄・日付欄の文字を混ぜた)で照合し、**すべて一致**しました(基準日は固定の日付を入れて検証。Excelでは未確認)。

## 使うときの注意

- **「要確認」の行は遅れの集計に入りません**。K2が0でなければ、チェック列を見て入力を直してください。直すまでは、その工程の遅れは台帳に出ません。
- **日付は日付として入力してください**。「10月20日」のように入れても日付として認識されることが多いですが、「未定」「調整中」などの文字は日付ではないので「要確認」になります。予定が決まっていない工程は、決まるまで行を作らないか、仮の日付を入れる運用にします。
- **実績終了を入れ忘れると、終わった工程が「遅れ」のまま増え続けます**。完了したらその日のうちにE列に入れる習慣が前提です。
- **休日・天候での順延は考慮していません**。予定終了日は、順延後の日付に直して入力します。
- **TODAYは開くたびに変わります**。昨日の画面を保存した資料(PDFなど)は、その日の基準日のままです。報告用に出すときは、基準日を確認してください。
- 工事番号は「K-001」のように、台帳と工程で表記をそろえてください(ハイフンの有無や大文字小文字の違いは吸収しません)。

## この記事ができないこと

- 工程どうしの前後関係(解体が終わらないと大工が始まらない、など)による自動の日程の組み替えはしません。
- 遅れの原因や、請求・支払いへの影響の判断はしません。
- 工期や契約の取り決めの適否は扱いません。

## 工事全体の原価や請求もあわせて見たいとき

この記事の式は、自分で作った工程表にそのまま使えます。工事ごとの原価と粗利は[工事の原価を材料・外注・経費に分けて粗利を見る式](/job-margin/)に、請求の残額は[工事の分割請求の残額をExcelで管理する式](/split-billing-balance/)にまとめています。見積の計算(数量×単価、諸経費、値引き、消費税)から作りたい場合は、運営者が作った[工事・リフォーム用 見積書テンプレート(Excel・980円)](/go/estimate-construction/?from=schedule-delay)があります。数量×単価(四捨五入)、諸経費率、値引き、消費税10%(切り捨て)、税込合計を自動計算し、明細は20行、A4縦1枚で印刷できます。**この記事の工程の機能は、この商品には入っていません**。軽減税率の混在や、インボイス要件の保証もできません。Excelの確認はWindowsデスクトップ版16のみです。(これは運営者の商品の案内です。)

見積の小計から税込までを一度に出すなら、無料の[見積の合計計算ツール](/tools/estimate-total/)が使えます(入力は外部に送信されません)。

## まとめ

- 工程は「工事番号・工種・予定開始・予定終了・実績終了」で1行ずつ入力し、基準日(本番は `=TODAY()`)と予定終了日を比べる
- 終わっていない工程は「基準日−予定終了」、終わった工程は「実績終了−予定終了」が遅れ日数。予定終了日の当日は遅れにしない
- 番号の間違い、日付の逆転、日付欄の文字は「要確認」にして、遅れの集計から外し、K2で件数を見る
- 台帳ではCOUNTIFSとSUMIFSで、工事ごとの遅れ工程数と遅れ日数を集める
- 15ケースと、工事300件・工程1,000行の照合はLibreOfficeで一致。Excelでは未確認のため、本番では数行を手で検算する
