家計簿を自分でエクセルに作って、**A4の紙1枚に印刷したい**ときの作り方です。残高を自動で出す式と、1ページに収める印刷設定を、LibreOfficeで実際に計算し、PDFにして確かめました。

出典: 筆者がLibreOfficeで計算して確認(検証スクリプト: site/verify/kakeibo_print.py)。外部サイトの説明は参照していません。**Excelの画面と、実際のプリンターでの印刷は未確認**です。印刷の設定項目はExcelにもありますが、プレビューで確かめてから印刷してください。

## 先に結論

- 表は「日付・費目・内容・支出・残高」の5列に、横に費目別の集計を置く形が作りやすいです。
- 残高は `=IF(D2="","",$H$1-SUM($D$2:D2))` で、月の予算から累計を引いて出せます。空欄の行は残高も空欄になります。
- 1枚に収めるには、**印刷範囲を決めて、用紙をA4・縦にし、「拡大縮小」を「1ページに収める」(横1・縦1)にする**だけです。
- 設定をしないまま列を広げると、横にはみ出して複数ページになりました(今回の例では3ページ)。

## 表の作り方

2行目から41行目までを明細欄(40行)とします。G〜H列に費目別の集計を置きます。

| セル | 内容 | 式・入力 |
|---|---|---|
| A〜C列 | 日付・費目・内容 | 手入力 |
| D列 | 支出 | 手入力 |
| E列 | 残高 | `=IF(D2="","",$H$1-SUM($D$2:D2))` |
| H1 | 月の予算 | 100000(手入力) |
| G3〜G8 | 費目名 | 食費、日用品、交通費、光熱費、通信費、趣味 |
| H3〜H8 | 費目別の合計 | `=SUMIFS($D$2:$D$41,$B$2:$B$41,G3)` |
| H9 | 合計 | `=SUM(D2:D41)` |

E列の式は、`$D$2:D2` の最初だけに `$` を付けるのがポイントです。下へコピーすると、範囲が「2行目から今の行まで」と伸びて、累計になります。

## 実際に計算した結果

試すために、30行分の支出を入れ(残り10行は空欄)、予算は100,000円としました。

| 費目 | 合計 |
|---|---|
| 食費 | 16,790 |
| 日用品 | 25,494 |
| 交通費 | 11,512 |
| 光熱費 | 6,395 |
| 通信費 | 5,269 |
| 趣味 | 9,256 |
| 合計 | 74,716 |

31行目(最後に入力した行)の残高は 25,284 円で、100,000 − 74,716 と一致しました。入力のない32行目以降は、残高が空欄のままでした。

## A4・1枚に印刷する設定

エクセルの「ページレイアウト」タブから、次の順に設定します。

1. **印刷範囲**: 印刷したい範囲(今回は A1:H41)を選んで「印刷範囲」→「印刷範囲の設定」。
2. **サイズ**: A4。
3. **印刷の向き**: 縦(横長の表は横にしてもかまいません)。
4. **拡大縮小**: 「横:1ページ」「縦:1ページ」にする(「1ページに収める」)。

設定を保存したファイルをLibreOfficeでPDFにしたところ、**用紙はA4(595×842pt)で1ページ**になりました。一方、同じ表で設定をせずに列Cを70文字分の幅にしたものは、**3ページ**に分かれました。

## つまずきやすい点

- **1ページに収める**と、表が大きいほど文字は小さく縮みます。40行に加えて列が多いと、手書きしにくい大きさになることがあります。今回の縮み具合までは測っていないので、印刷プレビューで確かめてください。
- 印刷範囲に**空欄の行も含める**と、紙に書き込む欄として残せます。含めたくないときは範囲を狭めます。
- 残高の式は、支出を**上から順に入力する**前提です。途中の行を空けると、その行の残高は空欄になりますが、次の行からは累計が続きます。
- 収入の入力欄は、この表にはありません。収入が毎月あるなら、予算のセル(H1)に今月の使える金額を入れて使います。

## 注意点: この表ができないこと

- 費目名のずれ(末尾スペースなど)は集計から漏れます。対策は[費目別の合計をSUMIFSで出す方法](/category-sum/)にまとめています。
- 月をまたいだ集計や、前月からの繰越は別の式が必要です([前月繰越を翌月に引き継ぐ方法](/kakeibo-carryover/))。
- 家計の助言や、節約できる金額の保証はしません。

## 自作せずに済ませたいなら

運営者が作った[月間家計簿(Excelテンプレート・400円)](/go/budget-monthly/?from=kakeibo-a4-print)は、A4印刷とExcel入力の両方に対応し、費目名を変更できます。明細は1か月40行までで、**複数月の通年集計、グラフ、銀行・カード連携はできません**。Excelの確認はWindowsデスクトップ版16のみで、Mac版・ブラウザ版・スマホアプリでの動作は未確認です。この記事の方法で足りる場合は、買う必要はありません。

先月と比べた増減の割合は、無料の[割合・増減率の計算ツール](/tools/percent/)も使えます(入力は外部に送信されません)。

## まとめ

- 残高は `=IF(D2="","",$H$1-SUM($D$2:D2))` で、累計は `$D$2:D2` の形で作る
- 印刷は「印刷範囲・A4・縦・横1縦1ページに収める」の設定で、PDF出力では1ページになった
- 設定をしないと列幅しだいで複数ページに分かれる(今回は3ページ)
- 式とPDFのページ数はLibreOfficeで確認したもの。Excelの画面と実際の印刷は未確認なので、プレビューで確かめてから使う
