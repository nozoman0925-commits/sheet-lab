「11月4日に着工して作業日数が12日。完了はいつ?」。カレンダーを指で数えると、日曜や、お盆・年末年始の休みを数え間違えがちです。日数をただ足す(`着工日+12`)と、休みの日まで作業日に数えてしまい、完了予定日が早すぎる日付になります。

この記事では、**着工日と作業日数**を入れると、**日曜と休工日(お盆・年末年始・施主の都合の休みなど)を飛ばした完了予定日**が出る式を示します。土曜は作業日として数えます。日数に0や小数を入れる、開始日が日付になっていない、といった誤入力は、結果を出す前に止めます。

出典: 筆者がLibreOfficeで計算して確認(検証スクリプト: site/verify/work_end_date.py)。外部サイトの説明は参照していません。**Excelでは未確認**です。使うのは `WORKDAY.INTL` という標準の関数ですが、本番で使う前にカレンダーと数行を見比べてください。なお、**雨で休みになる日の見込みや、工種ごとの必要日数はこの記事では決めません**(自分の現場の数字を入れてください)。

## 先に作る表

「休工日」シート: A1に見出し、A2から下に休工日を1行1日で入れます(日曜は入れなくて大丈夫です)。例: 祝日、お盆休み、年末年始、施主の立ち会い日など。

「工期」シート(2行目から。1行目は見出し)

| 列 | 内容 | 入れるもの |
|---|---|---|
| A | 工種 | 手入力 |
| B | 開始日 | 手入力(日付として入れる) |
| C | 作業日数 | 手入力(1以上の整数) |
| D | チェック | 式 |
| E | 完了予定日 | 式 |

```
I1: =IF(COUNTA(休工日!$A$2:$A$40)>COUNT(休工日!$A$2:$A$40),"休工日に日付でないものがある","")
D2: =IF(AND(B2="",C2=""),"",IF(NOT(ISNUMBER(B2)),"開始日が日付でない",IF(NOT(ISNUMBER(C2)),"作業日数が数字でない",
      IF(OR(C2<1,C2<>INT(C2)),"作業日数は1以上の整数",IF($I$1<>"","休工日リストを直す","")))))
E2: =IF(OR(D2<>"",AND(B2="",C2="")),"",WORKDAY.INTL(B2-1,C2,11,休工日!$A$2:$A$40))
```

E列は日付の表示形式(例: `yyyy/m/d`)にします。休工日は40行目まで読む形にしていますが、足りなければ範囲を広げてください。

考え方は3つです。

- `WORKDAY.INTL(開始日-1, 作業日数, 11, 休工日)` は、「開始日の前日から数えて作業日数番目の作業日」を返します。**開始日そのものを1日目として数える**ためにB2から1を引いています。
- 3つ目の `11` は「日曜だけを休みにする」という指定です(土曜は作業日)。土日を休みにするなら `1` にします。
- 4つ目の範囲に、日曜以外の休工日を並べます。範囲に空欄があっても計算できますが、**文字(「お盆」など)が混ざるとエラーになる**ので、I1で見つけて止めます。

## 実際に計算した結果

休工日は 2026/11/3、11/23、12/29〜1/2、2027/8/13〜15 としたときの結果です。

| ケース | 開始日・作業日数 | 結果 |
|---|---|---|
| 基礎(週の頭から) | 2026/11/2(月)・5日 | 11/7(土) |
| 日曜をまたぐ | 11/4(水)・6日 | 11/10(火) |
| 日曜から開始 | 11/8(日)・1日 | 11/9(月) |
| 1日だけ | 11/10・1日 | 11/10 |
| 祝日をまたぐ | 11/20(金)・5日 | 11/26(木)(11/22日曜と11/23休工日を飛ばす) |
| お盆をまたぐ | 2027/8/10・6日 | 8/18 |
| 年末年始をまたぐ | 2026/12/26・6日 | 2027/1/7 |
| 土曜は作業日 | 11/6(金)・2日 | 11/7(土) |
| 30日 | 11/2・30日 | 12/8 |
| 開始日が文字(「11月2日」) | 文字・5日 | チェック「開始日が日付でない」 |
| 開始日が空欄 | (空欄)・5日 | チェック「開始日が日付でない」 |
| 作業日数が空欄・「5日」 | 11/2・空欄/文字 | チェック「作業日数が数字でない」 |
| 作業日数が0・負・2.5 | 11/2・0/-3/2.5 | チェック「作業日数は1以上の整数」 |
| 空行 | (なし) | すべて空欄 |

休工日の欄に「お盆」という文字を混ぜたときは、すべての行に「休工日リストを直す」と出ます。休工日を1つも入れない場合は、日曜だけを飛ばして計算されます。

上の17ケースに加え、開始日・作業日数・休工日を乱数で組み合わせた500行でも、チェック表示と完了予定日が**全件一致**しました(Pythonで日を1日ずつ数えた結果と比較。検証はLibreOfficeのみ。Excelでは未確認)。

## 使うときの注意

- **開始日は日付として入れます**。「11月2日」と文字で入れるとチェックで止まります。セルの書式が文字列になっていると、日付を入れても文字扱いになるので、書式を日付にしてください。
- **開始日が日曜や休工日のときは、次の作業日が1日目**になります(11/8日曜・1日なら11/9)。
- **作業日数は「その工種に作業する日の数」**です。半日や、乾燥・養生のように待つだけの日は、日数に含めるかどうかを自分で決めて入れてください。この式は半日を扱えません。
- **雨天の予備日は自動では入りません**。見込む場合は休工日として日付を入れるか、作業日数に足してください。
- 工程が前の工程の完了を待つ場合は、**前の工程の完了予定日の翌作業日を次の開始日に**入れる運用になります。自動でつなぐ式は、この記事には入っていません。

## この記事ができないこと

- 工期の日数や、工種の順番の決定はしません。
- 祝日の自動判定はしません(休工日に自分で入れます)。
- 遅れの判定は別記事の[工程表で遅れている工程を自動で表示する式](/schedule-delay/)で扱っています。

## 工程や台帳とあわせて管理したいとき

遅れている工程の表示は[工程表で遅れている工程を自動で表示する式](/schedule-delay/)に、見積から工事台帳への転記は[見積から工事台帳への転記](/quote-to-ledger/)にまとめています。見積の計算(数量×単価、諸経費、値引き、消費税)から作りたい場合は、運営者が作った[工事・リフォーム用 見積書テンプレート(Excel・980円)](/go/estimate-construction/?from=work-end-date)があります。数量×単価(四捨五入)、諸経費率、値引き、消費税10%(切り捨て)、税込合計を自動計算し、明細は20行、A4縦1枚で印刷できます。**この記事の完了予定日の式は、この商品には入っていません**。軽減税率の混在や、インボイス要件の保証もできません。Excelの確認はWindowsデスクトップ版16のみです。(これは運営者の商品の案内です。)

## まとめ

- 完了予定日は `WORKDAY.INTL(開始日-1, 作業日数, 11, 休工日)` で出す。開始日を1日目に数えるため1を引く
- 日曜だけを休みにする指定が `11`。土曜も休みにするなら `1`
- 日数0・小数・文字、日付になっていない開始日、休工日リストの文字は、チェックで止めて結果を出さない
- 17ケースと乱数500行の照合はLibreOfficeで一致、Excelでは未確認のため、本番ではカレンダーで数行を見比べる
