「請求は出したはずなのに、まだ入っていない工事がいくつあって、合計いくらなのか」——小さな工務店・リフォーム店では、これが頭の中や請求書の束にしかないことがよくあります。**未入金の請求を、入金期日からの超過日数で「30日以内／31〜60日／61日以上」に分けて金額を出す**と、どこから催促するかが一目でわかります。

この記事では、請求番号・請求額・入金期日・入金額を1行ずつ入れ、**基準日を1つ決めるだけで、区分・未入金額・超過日数、区分ごとの合計金額**を出す式を示します。

出典: 筆者がLibreOfficeで計算して確認(検証スクリプト: site/verify/receivable_aging.py)。外部サイトの説明は参照していません。**Excelでは未確認**です。使うのはIF・OR・NOT・ISNUMBER・INT・N・COUNTIF・SUMIF・SUMという一般的な関数ですが、本番で使う前に、数行を手計算と見比べてください。この記事は表の作り方の説明です。**売掛金の会計処理や貸倒れの判断は、会社の経理のルール(必要なら税理士)に従ってください**。

## 先に結論: 「基準日 − 入金期日」の日数で4つに分ける

- 請求額 − 入金額 が0 → **入金済み**
- 入金期日が基準日と同じか、まだ先 → **期日内**
- 期日を過ぎて30日以内 → **超過30日以内**
- 31〜60日 → **超過31〜60日**
- 61日以上 → **超過61日以上**

基準日はセルに入れる日付です。今日の日付で見たいときは、基準日のセルに `=TODAY()` を入れます(この記事の確認は、結果が毎回同じになるよう固定した日付で行いました)。

## Excelの式

シート名は「未入金」。2行目から使います。

| 列 | 内容 | 入れるもの |
|---|---|---|
| A | 請求番号 | 手入力(例: S-001) |
| B | 取引先 | 手入力 |
| C | 請求額 | 手入力(1以上の整数) |
| D | 入金期日 | 手入力(日付) |
| E | 入金額 | 手入力(0以上の整数。一部入金は累計。空欄は0として扱う) |
| F | 区分 | 式 |
| G | チェック | 式 |
| H | 未入金額 | 式 |
| I | 超過日数 | 式(期日を過ぎた分だけ) |
| N2 | 基準日 | 日付(例: 2026/10/31) |

```
F2: =IF(OR(G2<>"",A2&B2&C2&D2&E2=""),"",IF(C2-N(E2)=0,"入金済み",
      IF(D2>=$N$2,"期日内",IF($N$2-D2<=30,"超過30日以内",
      IF($N$2-D2<=60,"超過31〜60日","超過61日以上")))))
G2: =IF(A2&B2&C2&D2&E2="","",IF(NOT(ISNUMBER($N$2)),"基準日が日付でない",
      IF(OR($N$2<1,$N$2<>INT($N$2)),"基準日が日付でない",
      IF(A2="","請求番号が空欄",IF(COUNTIF($A$2:$A$1000,A2)>1,"請求番号が重複",
      IF(C2="","請求額が空欄",IF(NOT(ISNUMBER(C2)),"請求額が数字でない",
      IF(OR(C2<1,C2<>INT(C2)),"請求額は1以上の整数",
      IF(D2="","入金期日が空欄",IF(NOT(ISNUMBER(D2)),"入金期日が日付でない",
      IF(OR(D2<1,D2<>INT(D2)),"入金期日が日付でない",
      IF(E2="","",IF(NOT(ISNUMBER(E2)),"入金額が数字でない",
      IF(OR(E2<0,E2<>INT(E2)),"入金額は0以上の整数",
      IF(E2>C2,"入金額が請求額を超えている","")))))))))))))))
H2: =IF(OR(F2="",F2="入金済み"),"",C2-N(E2))
I2: =IF(OR(F2="",F2="入金済み",F2="期日内"),"",$N$2-D2)
```

D列とN2は「日付」の表示形式にしてください。C・E・H列は「数値(桁区切り)」にします。集計は右側のセルに置きます(範囲は1000行まで)。

```
N5 期日内:           =SUMIF($F$2:$F$1000,"期日内",$H$2:$H$1000)
N6 超過30日以内:     =SUMIF($F$2:$F$1000,"超過30日以内",$H$2:$H$1000)
N7 超過31〜60日:     =SUMIF($F$2:$F$1000,"超過31〜60日",$H$2:$H$1000)
N8 超過61日以上:     =SUMIF($F$2:$F$1000,"超過61日以上",$H$2:$H$1000)
N9 超過の合計:       =SUM(N6:N8)
```

## 実際に計算して確認した結果

基準日を2026/10/31にして、請求額100,000円・入金なしの請求で、入金期日だけを変えた結果です。

| 入金期日 | 基準日との差 | 区分 | 超過日数 |
|---|---|---|---|
| 2026/11/01 | 期日の前日 | 期日内 | - |
| 2026/10/31 | 当日 | 期日内 | - |
| 2026/10/30 | 1日超過 | 超過30日以内 | 1 |
| 2026/10/01 | 30日超過 | 超過30日以内 | 30 |
| 2026/09/30 | 31日超過 | 超過31〜60日 | 31 |
| 2026/09/01 | 60日超過 | 超過31〜60日 | 60 |
| 2026/08/31 | 61日超過 | 超過61日以上 | 61 |

境界の日(30日・31日、60日・61日)で区分が切り替わることを確認しました。入金期日の当日は、まだ「期日内」です。

一部入金の請求(請求額100,000円・入金40,000円・90日超過)は、未入金額が60,000円で「超過61日以上」になります。全額入金済みの請求は、期日を大きく過ぎていても「入金済み」で、集計に入りません。入金額が空欄の行は、0円として扱います。

6件を入れた集計の確認では、次の結果になりました。

| 区分 | 件数と内容 | 金額 |
|---|---|---|
| 期日内 | 2件(未入金額100,000円、150,000円) | 250,000円 |
| 超過30日以内 | 1件(10日超過) | 300,000円 |
| 超過31〜60日 | 1件(45日超過・一部入金あり) | 300,000円 |
| 超過61日以上 | 1件(100日超過) | 500,000円 |
| 入金済み | 1件 | 集計に入らない |
| 超過の合計 | | 1,100,000円 |

入力ミスの行は、区分を空欄にして、G列にこう出ます。

| 入力ミス | チェック |
|---|---|
| 請求番号が空欄 | 請求番号が空欄 |
| 請求番号が重複(S-001とs-001) | 請求番号が重複 |
| 請求額が空欄 | 請求額が空欄 |
| 請求額が「10万」・全角「１００，０００」 | 請求額が数字でない |
| 請求額が0・小数 | 請求額は1以上の整数 |
| 入金期日が空欄 | 入金期日が空欄 |
| 入金期日が文字の「10/05」・全角の「２０２６/１０/０５」 | 入金期日が日付でない |
| 入金額が「4万」 | 入金額が数字でない |
| 入金額がマイナス | 入金額は0以上の整数 |
| 入金額が請求額より多い(二重に入れた) | 入金額が請求額を超えている |
| 基準日が空欄・文字 | 基準日が日付でない(全行に表示) |
| すべて空欄の行 | (何も出さない) |

30ケースすべて、区分・未入金額・超過日数・チェック表示と集計が、Pythonで計算した結果と一致しました。さらに、乱数で作った**500行**(請求番号の空欄・重複、請求額・入金期日・入金額の文字・0・小数・マイナス・請求額超過を約12%混ぜました)でも、**全項目と集計5つが一致**しました。Excelでの確認はしていません。

## つまずきやすい点

- **日付が文字になっていないか**: 「10/05」のように入力しても、Excelの設定や入力の仕方によっては日付ではなく文字として入ることがあります。その行はG列に「入金期日が日付でない」と出るので、日付として入れ直してください。
- **入金額は累計で入れる**: 分割で入金があったときは、入金額に足していきます(40,000円→さらに30,000円なら70,000円)。そのたびに行を増やすと、請求番号が重複します。
- **入金期日の決め方**: 請求書に書いた期日の決め方は、[支払期限(締め日・支払月・支払日)を自動計算する記事](/payment-due/)にあります。入金の遅れや一部入金・二重入金の見つけ方は、[請求と入金を照合する記事](/payment-match/)も見てください。
- **請求漏れとの違い**: この記事は「請求したが入金されていない」分です。「工事が終わったのにまだ請求していない」分は、[請求漏れを見つける記事](/billing-missing/)で扱っています。
- **分割請求**: 着手・中間・完了で分けて請求するときは、[分割請求の残額の記事](/split-billing-balance/)の表と組み合わせ、請求ごとに1行にして入れます。
- **30日・60日の区切りは例**: 取引先ごとの習慣に合わせて、式の30と60を変えて使ってください(変えた場合は、本番前に数行を手計算で確認してください)。

## 注意点: この記事ができないこと

- 催促の仕方や、いつ法的な手続きに進むかの判断はしません。
- 売掛金の会計処理、貸倒れの処理、遅延損害金の計算は扱いません。
- 振込手数料を差し引いた入金など、請求額と入金額が少しずれるケースは、差額が未入金として残ります。入金額の入れ方は、会社のルールで決めてください。
- 金額は整数だけを前提にしています。税の取り扱いは扱いません(税抜か税込のどちらかにそろえて入れてください)。

## 見積から請求までつなげたいとき

見積の計算そのものから作りたい場合は、運営者が作った[工事・リフォーム用 見積書テンプレート(Excel・980円)](/go/estimate-construction/?from=receivable-aging)があります。数量×単価(四捨五入)、諸経費率、値引き、消費税10%(切り捨て)、税込合計を自動計算し、明細は20行、A4縦1枚で印刷できます。**この記事の「未入金の経過日数別の集計」機能は、この商品には入っていません**。請求書への変換、軽減税率の混在、インボイス要件の保証もできません。Excelの確認はWindowsデスクトップ版16のみです。(これは運営者の商品の案内です。)

見積の合計だけをすぐ確かめたいときは、無料の[見積の合計計算ツール](/tools/estimate-total/)が使えます(入力は外部に送信されません)。

## まとめ

- 請求番号・請求額・入金期日・入金額を1行ずつ入れ、基準日を1つ決める
- 入金期日の当日までは「期日内」。超過日数で30日以内／31〜60日／61日以上に分けて、未入金額を区分ごとに合計する
- 入金額は累計で入れる。全額入金済みは集計から外れ、請求額より多い入金はチェック列で止める
- 日付が文字になっている、請求額が0、請求番号が重複しているなどは、区分を出さずチェック列で止める
- 30ケースと500行の照合はLibreOfficeで一致。Excelでは未確認のため、本番では数行を手計算で見比べる
