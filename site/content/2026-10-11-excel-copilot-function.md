Excelに、AIに質問して結果をセルに返す「COPILOT関数」が加わりました。便利そうに見える一方、「どんなときに使い、何に使ってはいけないのか」は、あまり整理されていません。この記事では、Microsoftの公式の説明ページに書かれている内容を中心に、できること・できないことを整理します。

なお、この記事のCOPILOT関数の内容は、公式ページの記載にもとづくもので、**私たちが実際に動かして確かめたものではありません**(有料の契約が必要なため)。確認できた範囲と、確認できていない範囲を、分けて書きます。

## 先に結論

- COPILOT関数は、**文章の要約、分類、サンプルの文章づくり**に向いています。
- 公式は、**数値の計算と、検索(探して取り出す作業)には使わない**よう、はっきり案内しています。
- 結果は、同じ入力でも変わることがあり、**間違った答えを返すこともある**と、公式が明記しています。
- 財務報告、法務、コンプライアンスなど、**間違いの影響が大きい用途は避ける**よう、案内されています。

## 書式

公式の説明では、書式は次のとおりです。

```
=COPILOT(プロンプト1, [コンテキスト1], [プロンプト2], [コンテキスト2], ...)
```

- 「プロンプト」は、AIへの指示の文章です。
- 「コンテキスト」は、AIに見せたいセルまたは範囲です。省略もできます。
- 複数の指示とデータの組み合わせを、1つの指示にまとめて渡します。
- 結果は、複数行に広がる配列として返ることがあります。

公式が挙げている例は、次のようなものです。

```
=COPILOT("このフィードバックを要約して", A2:A20)
=COPILOT("センチメントを分類して", B2:B100)
```

## 使うための条件

公式の説明によると、次の条件があります。

- Copilotの契約が必要です。
- インターネット接続が必要です。
- 処理は、Azure上のモデルで行われます。公式の説明時点では、特定のモデル名が示されていました(モデルは、将来変わる可能性があります)。
- Microsoft 365版のExcel、Mac、Web、iPhoneで使えます。

また、2026年5月の更新を報じた窓の杜の記事では、**Web検索に対応した新しいCOPILOT関数**が、Microsoft 365 InsiderとFrontierに参加しているテスター向けに、順次提供されると伝えています。従来の関数は、AIモデルの知識の範囲でしか答えられなかったのに対し、新版では、天気や最新の企業情報など、オンラインの情報を参照できるようになる、という説明です。一般への提供の時期やライセンスの条件は、この記事には書かれていません。

## 回数などの制限

公式の説明では、次の制限があります。

- **10分あたり最大100回**のCOPILOT計算ができます。
- **「秘密」または「極秘」のラベルが付いたブックでは、計算できません**。
- COPILOT関数が見られるのは、指示の文章と、指定したコンテキストだけです。同じブックの他のデータや、他のファイルは見えません。

## 公式が示す注意点

公式のページには、次の注意が書かれています。

- COPILOTはAIを使っており、**間違った答えを返すことがある**。
- **数値の計算には使わず**、`SUM`や`AVERAGE`などの通常の関数を使う。
- **検索には使わず**、`XLOOKUP`などを使う。
- 財務報告や法務文書、コンプライアンスの用途のような、重大な場面は避ける。
- 同じ引数でも、**結果が時間とともに変わることがある**。結果を固定したいときは、値として貼り付ける。
- 公式ページは、指示とデータが、AIモデルの学習には使われないとも説明しています。

## 通常の関数と、何が違うか

通常の関数(`SUM`や`TRIM`など)は、同じ入力なら、いつでも同じ結果を返します。たとえば`=SUM(10,20,30)`は、LibreOfficeで再計算すると、何度でも`60`になりました。

一方でCOPILOT関数は、公式が「結果が変わることがある」と書いているとおり、同じ入力で同じ結果になる保証がありません。この違いが、数値の計算に向かない理由です。

## どんな場面で使う価値があるか

公式の説明が、推奨している用途は次のとおりです。

- 文章の要約
- サンプルデータや文章の生成
- 内容の分類やタグ付け(例:感想の肯定・否定の分類)
- Webの情報を調べる用途(新しい版で対応予定。出典の表示は「近日対応」と書かれています)

たとえば、顧客のアンケートの自由記述を、「要望」「不満」「称賛」に分けたい場面は、通常の関数では難しく、COPILOT関数が力を発揮しやすい場面です。ただし、分類の結果は、AIの判断にもとづくので、重要な判断に使う場合は、人が確認することが前提です。

## 使う前のチェックリスト

1. 数値の計算や、データの検索になっていないか(なっていれば、通常の関数を使う)。
2. 会社の機密や、個人情報を含むデータを、コンテキストに渡していないか。
3. 結果を固定する必要があるか(あるなら、値として貼り付ける)。
4. 結果の誤りが、大きな損害につながらない用途か。

## まとめ

- COPILOT関数は、文章の要約・分類・生成に向いた、新しい種類の関数です。
- 数値の計算と検索は、公式が、通常の関数を使うよう案内しています。
- 条件(契約、接続)と制限(回数、ラベル付きのブック)があります。
- 結果は変わることがあり、誤ることもあるので、重要な用途では人の確認が必要です。
