工事が終わったあと、次の現場に追われて請求書を出しそびれ、気づいたら1か月たっていた——小さな工務店・リフォーム店では、わりとよくある話です。請求が遅れると、入金も遅れます。入金が遅れると、外注先や材料屋さんへの支払いが先に出ていくことになります。

この記事では、**完了日・請求日・請求額**を1行ずつ入れるだけで、**「工事中／完了予定／請求待ち／請求漏れ／請求済」の表示、完了からの経過日、請求漏れの件数と金額**を出す式を示します。「完了から何日以内なら請求待ち、それを超えたら請求漏れ」の日数(猶予日数)は、自分で決められます。

出典: 筆者がLibreOfficeで計算して確認(検証スクリプト: site/verify/billing_missing.py)。外部サイトの説明は参照していません。**Excelでは未確認**です。使うのはIF・OR・AND・NOT・ISNUMBER・INT・N・COUNTIF・SUMIFという一般的な関数ですが、本番で使う前に、数行を手計算と見比べてください。この記事は表の作り方の説明です。**請求の時期や条件は、お客様との契約(請負契約書・見積書)に従ってください**。税の取り扱いも扱いません(請求額は税抜でも税込でも、そろえて入れてください)。

## 先に結論: 「完了日はあるのに請求日が空欄」で、基準日から猶予日数を超えていたら請求漏れ

- 完了日が空欄 → 工事中
- 請求日が入っている → 請求済
- 完了日が基準日より先 → 完了予定
- 完了日から基準日までの日数が猶予日数以内 → 請求待ち
- 猶予日数を超えている → **請求漏れ**
- 基準日には、毎日自動で変わる `TODAY()` を入れても、確認したい日付を手入力しても使えます

## Excelの式

シート名は「請求漏れ」。2行目から使います。

| 列 | 内容 | 入れるもの |
|---|---|---|
| A | 工事番号 | 手入力(例: K-001) |
| B | 工事名 | 手入力 |
| C | 完了日 | 手入力。完了するまで空欄 |
| D | 請求日 | 手入力。請求書を出すまで空欄 |
| E | 請求額(予定を含む) | 手入力(1以上の整数)。まだ請求していない工事は予定額 |
| F | 状態 | 式 |
| G | チェック | 式 |
| H | 経過日 | 式(請求待ち・請求漏れの行だけ) |
| K2 | 基準日 | 今日の日付(`=TODAY()` でもよい) |
| K3 | 猶予日数 | 完了から何日までを「請求待ち」とするか(空欄は0日) |

```
F2: =IF(OR(G2<>"",A2&B2&C2&D2&E2=""),"",IF(C2="","工事中",IF(D2<>"","請求済",
      IF(NOT(ISNUMBER($K$2)),"基準日を入力",IF(C2>$K$2,"完了予定",
      IF($K$2-C2>N($K$3),"請求漏れ","請求待ち"))))))
G2: =IF(A2&B2&C2&D2&E2="","",IF(A2="","工事番号が空欄",
      IF(COUNTIF($A$2:$A$1000,A2)>1,"工事番号が重複",
      IF(AND(C2<>"",NOT(ISNUMBER(C2))),"完了日が日付でない",
      IF(AND(ISNUMBER(C2),OR(C2<1,C2<>INT(C2))),"完了日が日付でない",
      IF(AND(D2<>"",NOT(ISNUMBER(D2))),"請求日が日付でない",
      IF(AND(ISNUMBER(D2),OR(D2<1,D2<>INT(D2))),"請求日が日付でない",
      IF(E2="","請求額が空欄",
      IF(NOT(ISNUMBER(E2)),"請求額が数字でない",
      IF(OR(E2<1,E2<>INT(E2)),"請求額は1以上の整数",
      IF(AND(D2<>"",C2=""),"完了日が空欄なのに請求日がある",
      IF(AND(D2<>"",C2>D2),"請求日が完了日より前","")))))))))))
H2: =IF(OR(F2="請求漏れ",F2="請求待ち"),$K$2-C2,"")
```

H列の表示形式は「標準」か「数値」にしてください(日付の差なので、日付形式のままだと変な日付に見えます)。`N($K$3)` は、猶予日数が空欄や文字のときに0日として扱うために使っています。入力ミスの行はチェック列に理由が出て、状態は空欄になり、集計に入りません。

集計は右側のセルに置きます(範囲は1000行まで)。

```
K5 請求漏れの件数:   =COUNTIF($F$2:$F$1000,"請求漏れ")
K6 請求漏れの金額:   =SUMIF($F$2:$F$1000,"請求漏れ",$E$2:$E$1000)
K7 請求待ちの金額:   =SUMIF($F$2:$F$1000,"請求待ち",$E$2:$E$1000)
K8 工事中の件数:     =COUNTIF($F$2:$F$1000,"工事中")
```

## 実際に計算して確認した結果

基準日を2026-10-27、猶予日数を7日にして、請求額800,000円の1行を入れた結果です。

| 完了日 | 請求日 | 状態 | 経過日 |
|---|---|---|---|
| 空欄 | 空欄 | 工事中 | - |
| 2026-10-30(基準日より先) | 空欄 | 完了予定 | - |
| 2026-10-27(基準日と同じ) | 空欄 | 請求待ち | 0 |
| 2026-10-20(ちょうど7日前) | 空欄 | 請求待ち | 7 |
| 2026-10-19(8日前) | 空欄 | 請求漏れ | 8 |
| 2026-08-28(60日前) | 空欄 | 請求漏れ | 60 |
| 2026-09-17 | 2026-10-17 | 請求済 | - |

ちょうど7日前は「請求待ち」、8日前から「請求漏れ」になります(境界の動きも確認済みです)。猶予日数を空欄にすると0日として扱い、完了日が基準日と同じ日なら請求待ち、1日でも過ぎれば請求漏れです。

5件を入れた集計の確認では、請求漏れ2件(完了から30日の800,000円と、9日の300,000円)、請求待ち1件(完了から2日の150,000円)、工事中1件、請求済1件で、請求漏れの件数 2件・金額 1,100,000円、請求待ちの金額 150,000円、工事中 1件と出ました。

入力ミスの行は、状態を空欄にして、G列にこう出ます。

| 入力ミス | チェック |
|---|---|
| 工事番号が空欄 | 工事番号が空欄 |
| 工事番号が重複(K-001とk-001) | 工事番号が重複 |
| 完了日が全角の文字「２０２６/１０/５」 | 完了日が日付でない |
| 完了日に時刻つき(2026-10-10 12:00) | 完了日が日付でない |
| 請求日が「済」 | 請求日が日付でない |
| 完了日が空欄なのに請求日がある | 完了日が空欄なのに請求日がある |
| 請求日が完了日より前(日付の逆転) | 請求日が完了日より前 |
| 請求額が空欄 | 請求額が空欄 |
| 請求額が「80万」・全角「８００，０００」 | 請求額が数字でない |
| 請求額が0・小数 | 請求額は1以上の整数 |
| すべて空欄の行 | (何も出さない) |

基準日が空欄や文字のときは、請求待ち・請求漏れの判定ができないので、完了日があって請求日が空欄の行に「基準日を入力」と出ます(請求済・工事中の行はそのまま判定されます)。

28ケースすべて、状態・経過日・チェック表示と集計が、Pythonで計算した結果と一致しました。さらに、乱数で作った**500行**(工事番号の空欄・重複、完了日・請求日の文字や時刻つき、請求額の空欄・文字・0・小数・マイナスを約12%混ぜました)でも、**全項目と集計4つが一致**しました。Excelでの確認はしていません。

## つまずきやすい点

- **日付は「日付」として入れる**: 全角の数字や「10月5日完了」のような文章は、日付として扱われずチェック列で止まります。半角で「2026/10/5」のように入れると、Excelが日付にしてくれます。
- **「請求日が完了日より前」は、すべてがミスとは限らない**: 着手金や中間請求のように、完了前に請求することもあります。そうした分は、この表ではなく[分割請求の残額を管理する記事](/split-billing-balance/)の表で見るほうが向いています。この表は「完了時に1回請求する工事」を主に想定しています。
- **請求額は予定額でよい**: 請求漏れの金額は、E列の金額の合計です。まだ請求書を作っていない工事は、見積の金額や契約金額を入れてください。追加工事が入って金額が変わる場合は、[追加工事・減額を反映した契約金額を出す記事](/contract-change/)の式で出した金額を入れると、実際の請求額に近づきます。
- **TODAYを使うと、開くたびに状態が変わる**: 過去の日付時点の状態を見たい場合は、K2に日付を手入力してください。
- **猶予日数は自社のルールで決める**: 「完了から7日以内」としたのは例です。月末締めで請求する会社なら、猶予を月末までの日数にするなど、自社の運用に合わせてください。

## 注意点: この記事ができないこと

- 請求書の作成、送信、督促はしません。入金の確認は[請求と入金を照合する記事](/payment-match/)、請求書の支払期限は[締め日と支払日から支払期限を出す記事](/payment-due/)にあります。
- 請求の時期や、請求できる条件(検収の有無、支払条件)の判断はしません。契約や下請法などの法令に関わることは、契約書や専門家に確認してください。
- 金額は整数だけを前提にしています。

## 見積から請求までつなげたいとき

見積の回答待ちを管理する方法は[見積提出後の回答待ちを管理する記事](/quote-followup/)に、見積から工事台帳に転記する流れは[見積から台帳への転記の記事](/quote-to-ledger/)にまとめています。見積の計算そのものから作りたい場合は、運営者が作った[工事・リフォーム用 見積書テンプレート(Excel・980円)](/go/estimate-construction/?from=billing-missing)があります。数量×単価(四捨五入)、諸経費率、値引き、消費税10%(切り捨て)、税込合計を自動計算し、明細は20行、A4縦1枚で印刷できます。**この記事の「請求漏れの確認」機能は、この商品には入っていません**。請求書への変換、軽減税率の混在、インボイス要件の保証もできません。Excelの確認はWindowsデスクトップ版16のみです。(これは運営者の商品の案内です。)

税込み・税抜の計算だけなら、無料の[見積の合計計算ツール](/tools/estimate-total/)が使えます(入力は外部に送信されません)。

## まとめ

- 「完了日あり・請求日なし」の行を、基準日と猶予日数で「請求待ち」と「請求漏れ」に分ける
- 猶予日数ちょうどまでは請求待ち、1日でも超えたら請求漏れ
- 請求漏れの件数と金額を1か所に出して、毎週見る習慣にする
- 日付が文字、請求日が完了日より前、完了日が空欄で請求日あり、請求額の空欄などは、状態を出さずチェック列で止める
- 28ケースと500行の照合はLibreOfficeで一致。Excelでは未確認のため、本番では数行を手計算で見比べる
