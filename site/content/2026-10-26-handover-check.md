「あのお宅、引渡からそろそろ1年だったかな……」。工事が終わって引渡したあとの定期点検は、請求が済むと頭から抜けやすい仕事です。点検の予定日を紙のメモやカレンダーに1件ずつ書いていると、書き忘れたものから漏れていきます。

この記事では、台帳に**引渡日**と**点検をした日**を入れるだけで、**次の点検の種類・予定日・「期限超過／30日以内／予定あり」**を自動で出す式を示します。工事台帳の末尾にこの表を足しておけば、開くたびに「連絡すべきお宅」が上に出ます。

出典: 筆者がLibreOfficeで計算して確認(検証スクリプト: site/verify/handover_check.py)。外部サイトの説明は参照していません。**Excelでは未確認**です。使うのはIF・OR・AND・NOT・ISNUMBER・COUNTIF・EDATEという一般的な関数ですが、本番で使う前に、数行を手計算と見比べてください。この記事は表の作り方の説明です。**点検を何年目に行うか、保証期間が何年か、といった内容は契約書・保証書に従ってください**(この記事では「1年点検」「2年点検」を例にしているだけで、法令や保証の内容の助言はしません)。

## 先に結論: 引渡日から「12か月後」「24か月後」をEDATEで出す

- 1年点検の予定日 = 引渡日の12か月後、2年点検の予定日 = 引渡日の24か月後
- 1年点検済日が空欄なら「次は1年点検」、入っていて2年点検済日が空欄なら「次は2年点検」、両方入っていれば「完了」
- 予定日が基準日(今日)より前なら「期限超過」、30日以内なら「30日以内」、それ以外は「予定あり」

基準日は、セルK1に `=TODAY()` と入れておくと開くたびに今日になります(検証では日付を直接入れて確認しました)。

## Excelの式

シート名は「引渡」。2行目から使います。

| 列 | 内容 | 入れるもの |
|---|---|---|
| A | 工事番号 | 手入力 |
| B | 引渡日 | 手入力(日付) |
| C | 1年点検済日 | 点検したら手入力(日付)。まだなら空欄 |
| D | 2年点検済日 | 点検したら手入力(日付)。まだなら空欄 |
| E | 次の点検 | 式 |
| F | 次の点検予定日 | 式 |
| G | 状態 | 式 |
| H | チェック | 式 |
| K1 | 基準日 | `=TODAY()` または日付 |

```
E2: =IF(OR(H2<>"",A2&B2&C2&D2=""),"",IF(C2="","1年点検",IF(D2="","2年点検","完了")))
F2: =IF(OR(H2<>"",A2&B2&C2&D2="",E2="完了"),"",IF(E2="1年点検",EDATE(B2,12),EDATE(B2,24)))
G2: =IF(OR(H2<>"",A2&B2&C2&D2=""),"",IF(E2="完了","完了",IF(F2<$K$1,"期限超過",
      IF(F2-$K$1<=30,"30日以内","予定あり"))))
H2: =IF(A2&B2&C2&D2="","",IF(A2="","工事番号が空欄",
      IF(COUNTIF($A$2:$A$1000,A2)>1,"工事番号が重複",
      IF(NOT(ISNUMBER($K$1)),"基準日が日付でない",
      IF(NOT(ISNUMBER(B2)),"引渡日が日付でない",
      IF(OR(B2<1,B2>73050),"引渡日が範囲外",
      IF(AND(C2<>"",NOT(ISNUMBER(C2))),"1年点検済日が日付でない",
      IF(AND(D2<>"",NOT(ISNUMBER(D2))),"2年点検済日が日付でない",
      IF(AND(D2<>"",C2=""),"1年点検が空欄のまま2年点検済み",
      IF(AND(C2<>"",C2<B2),"1年点検済日が引渡日より前",
      IF(AND(D2<>"",D2<B2),"2年点検済日が引渡日より前","")))))))))))
```

F列の表示形式は「日付」にしてください(そのままだと数字(シリアル値)で表示されます)。

ポイントは次の4つです。

- **EDATEは「月」を足すので、月末やうるう日でも日付が壊れません**。引渡が2024年2月29日なら、12か月後は存在しない2025年2月29日ではなく**2025年2月28日**になります。2025年10月31日の12か月後は2026年10月31日です(LibreOfficeでの結果)。「365日足す」式だと、うるう年をまたぐと1日ずれます。
- **日付の入力ミスは、黙って計算せずチェック列で止めます**。「2025/9/1」を文字として入れた、全角で「２０２６/９/５」と入れた、「済」と書いた、といった行は、予定日を出さずに「〜が日付でない」と表示します。間違った予定日を見せるより、空欄にして知らせるほうが安全だからです。
- **日付の逆転も拾います**。点検済日が引渡日より前になっているときは「点検済日が引渡日より前」、1年点検が空欄なのに2年点検だけ入っているときは「1年点検が空欄のまま2年点検済み」と出ます。
- **工事番号の重複も拾います**。同じ工事番号の行が2つあると、どちらも「工事番号が重複」です(大文字小文字は同じ扱い)。

## 実際に計算した結果

基準日は2026年10月26日で確認しました。

| ケース | 入力 | 次の点検 | 予定日 | 状態 |
|---|---|---|---|---|
| 引渡から約10か月 | 引渡2025/12/1、点検なし | 1年点検 | 2026/12/1 | 予定あり |
| 予定日まで25日 | 引渡2025/11/20 | 1年点検 | 2026/11/20 | 30日以内 |
| 予定日を過ぎた | 引渡2025/9/1 | 1年点検 | 2026/9/1 | 期限超過 |
| 1年点検済み | 引渡2025/9/1、1年済2026/9/5 | 2年点検 | 2027/9/1 | 予定あり |
| 両方済み | 引渡2024/9/1、1年済・2年済 | 完了 | 空欄 | 完了 |
| うるう日の引渡 | 引渡2024/2/29 | 1年点検 | 2025/2/28 | 期限超過 |
| 月末の引渡 | 引渡2025/10/31 | 1年点検 | 2026/10/31 | 30日以内 |
| 予定日が基準日と同じ | 引渡2025/10/26 | 1年点検 | 2026/10/26 | 30日以内 |
| 予定日が基準日の前日 | 引渡2025/10/25 | 1年点検 | 2026/10/25 | 期限超過 |
| 予定日が基準日の30日後 | 引渡2025/11/25 | 1年点検 | 2026/11/25 | 30日以内 |
| 予定日が基準日の31日後 | 引渡2025/11/26 | 1年点検 | 2026/11/26 | 予定あり |

入力ミスの行は、予定日・状態を空欄にして、H列にこう出ます。

| 入力ミス | チェック |
|---|---|
| 引渡日が文字「2025/9/1」、または空欄 | 引渡日が日付でない |
| 引渡日が0 | 引渡日が範囲外 |
| 工事番号が空欄 | 工事番号が空欄 |
| 工事番号が重複(a-001とA-001) | 工事番号が重複 |
| 2年点検済日だけ入力 | 1年点検が空欄のまま2年点検済み |
| 1年点検済日が引渡日より前 | 1年点検済日が引渡日より前 |
| 2年点検済日が引渡日より前 | 2年点検済日が引渡日より前 |
| 点検済日が「済」または全角の日付 | 1年点検済日が日付でない |
| 基準日が空欄または文字 | 基準日が日付でない |
| すべて空欄の行 | (何も出さない) |

23ケースすべて、次の点検・予定日・状態・チェック表示が、Pythonで計算した結果と一致しました。さらに、乱数で作った**500行**(引渡日の文字・空欄・0、点検済日の文字・日付の逆転、工事番号の空欄・重複、1年点検が空欄のままの2年点検などを約12%混ぜました)でも、**全項目が一致**しました。Excelでの確認はしていません。

なお、この確認の途中で、「引渡日が0」の行を、検証用の期待値のほうで「日付でない」と書き間違え、式との不一致が出ました。式の側は意図どおり「範囲外」と出ていたので、期待値を直しました。0のような小さな数は日付としては1900年1月0日にあたるため、「文字」ではなく「範囲外」として扱われます。

## つまずきやすい点

- **点検をしたら、必ずその日に日付を入れる**: 空欄のままだと、いつまでも「期限超過」と出続けます。連絡して日程が決まっただけの段階では入れず、点検した日を入れてください。
- **日付は「2026/9/5」のように入れる**: 入力した日付がセルの中で左寄せになっていたら文字になっている合図です。チェック列に「日付でない」と出ます。
- **「30日以内」の30は変えられる**: G列の式の `<=30` を、連絡に余裕がほしければ `<=45` や `<=60` に変えてください。
- **予定日はあくまで目安**: 契約や保証書で点検の時期・回数が決まっている場合は、そちらが正です。式の12・24を、その月数に書き換えれば使えます。

## 注意点: この記事ができないこと

- 点検の時期・回数・保証期間の決め方、保証の範囲、法令上の扱いの確認はしません。
- 点検の連絡そのもの(メール・電話・通知)はしません。表示するだけです。
- 土日祝日を避けた日付の調整はしません。

## 見積から台帳・請求までを1つで見たいとき

引渡までの流れは、見積から台帳への転記を[見積の明細から台帳に渡す記事](/quote-to-ledger/)に、工程の遅れは[工程表で遅れている工程を自動で表示する記事](/schedule-delay/)に、請求と入金の照合は[請求と入金をExcelで照合する記事](/payment-match/)にまとめています。見積の計算そのものから作りたい場合は、運営者が作った[工事・リフォーム用 見積書テンプレート(Excel・980円)](/go/estimate-construction/?from=handover-check)があります。数量×単価(四捨五入)、諸経費率、値引き、消費税10%(切り捨て)、税込合計を自動計算し、明細は20行、A4縦1枚で印刷できます。**この記事の「引渡後の点検管理」機能は、この商品には入っていません**。請求書への変換、軽減税率の混在、インボイス要件の保証もできません。Excelの確認はWindowsデスクトップ版16のみです。(これは運営者の商品の案内です。)

税込み・税抜の計算だけなら、無料の[見積の合計計算ツール](/tools/estimate-total/)が使えます(入力は外部に送信されません)。

## まとめ

- 引渡日から12か月後・24か月後をEDATEで出すと、月末・うるう日でも日付が壊れない
- 点検済日の入力で「次の点検」を切り替え、予定日と基準日の差で「期限超過／30日以内／予定あり」を出す
- 日付が文字・全角・空欄、日付の逆転、番号の重複は、予定日を出さずチェック列で止める
- 23ケースと500行の照合はLibreOfficeで一致。Excelでは未確認のため、本番では数行を手計算で見比べる
- 点検の時期や保証の内容は、契約書・保証書が正
