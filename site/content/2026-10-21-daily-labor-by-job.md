現場の作業日報を、月末にまとめて「この工事に何人工かかったか」「労務費はいくらか」に直すのは手間がかかります。工事番号の書き間違い、「半日」と文字で書かれた人工、同じ人が同じ日に2つの現場へ入っているのに両方「1」——こうした入力の揺れが、そのまま原価のズレになります。

この記事では、**日報に1行ずつ入力するだけで、台帳の表に工事ごとの人工合計と労務費が自動で出る**式を示します。あわせて、入力ミスを表示させるチェック列も作ります。

出典: 筆者がLibreOfficeで計算して確認(検証スクリプト: site/verify/daily_labor.py)。外部サイトの説明は参照していません。**Excelでは未確認**です。使うのはSUMIFS・INDEX・MATCH・IFERROR・ROUND・ASC・TRIMなどの一般的な関数ですが、本番の台帳に使う前に、数行で結果を確かめてください。日当は税抜・社会保険等を含まない単純な「日当×人工」の例で、労務費として会計・税務上どう扱うかの判断はしません。

## 先に結論

3枚のシートを使います。

**「作業員」シート**(1行1人。2行目から。氏名と日当)

| 列 | 内容 |
|---|---|
| A | 氏名(例: 職人A) |
| B | 日当(円) |

**「台帳」シート**(1行1工事。2行目から。範囲は2〜3000行の例)

| 列 | 内容 | 入れるもの |
|---|---|---|
| A | 工事番号 | 手入力(例: K-001) |
| B | 人工合計 | 式 |
| C | 労務費 | 式 |

```
B2: =IF(A2="","",SUMIFS(日報!$D$2:$D$3000,日報!$E$2:$E$3000,A2,日報!$D$2:$D$3000,">0"))
C2: =IF(A2="","",SUMIFS(日報!$G$2:$G$3000,日報!$E$2:$E$3000,A2))
```

**「日報」シート**(1行1人・1現場・1日。2行目から)

| 列 | 内容 | 入れるもの |
|---|---|---|
| A | 日付 | 手入力 |
| B | 工事番号 | 手入力 |
| C | 作業員 | 手入力(作業員シートの氏名) |
| D | 人工 | 手入力(1日=1、半日=0.5) |
| E | 整えた番号 | 式(全角→半角、前後のスペース除去) |
| F | 日当 | 式(作業員シートから引く) |
| G | 労務費 | 式(人工×日当、円未満は四捨五入) |
| H | チェック | 式 |

```
E2: =ASC(TRIM(B2))
F2: =IF(TRIM(C2)="","",IFERROR(INDEX(作業員!$B$2:$B$200,MATCH(TRIM(C2),作業員!$A$2:$A$200,0)),""))
G2: =IF(AND(ISNUMBER(D2),D2>0,ISNUMBER(F2)),ROUND(D2*F2,0),0)
H2: =IF(AND(B2="",C2="",D2=""),"",
      IF(NOT(ISNUMBER(D2)),"人工が未入力か数値でない",
      IF(D2<=0,"人工が0以下",
      IF(B2="","工事番号が空欄",
      IF(ISNA(MATCH(E2,台帳!$A$2:$A$3000,0)),"工事番号なし",
      IF(F2="","作業員が未登録",
      IF(AND(A2<>"",SUMIFS($D$2:$D$3000,$A$2:$A$3000,A2,$C$2:$C$3000,C2)>2),"同日の合計が2人工超",""))))))) 
```

(H2は見やすいよう改行していますが、実際は1つの式として入力します。)

さらに、台帳の端のセルに**照合用**として次の式を置きます。

```
E1: 未紐づけの労務費
F1: =SUM(日報!G2:G3000)-SUM(C2:C3000)
```

日報の労務費の合計と、台帳の労務費の合計が一致していれば0です。**0でなければ、どこかの日報が工事に結びついていません**(工事番号の間違いなど)。日報の「チェック」列に出た行を直してください。

ポイントは4つです。

- 台帳の集計は、日報の**E列(整えた番号)**で行います。B列(手入力の番号)で集計すると、全角や前後のスペースが入った行が漏れます。
- 人工が文字(「半日」、全角の「１」)の行は、**労務費が0**で、人工合計にも入りません。その代わりチェック列に出ます。見つけたら半角の数字に直してください。
- 「同日の合計が2人工超」は、**同じ人・同じ日の人工を全行で足した値が2を超える**行に出ます。2は例で、残業をどこまで認めるかに合わせて式の数字を変えてください。2現場に0.5ずつ入った日は、合計1なので表示されません。
- 日当を変えたとき、過去の日報の労務費も新しい日当で計算し直されます。**月ごとに日当が変わる場合は、月別に作業員シートを分けるか、日報に日当を値で保存する運用が必要**です(この記事の式では扱いません)。

## 実際に計算した結果

作業員シートは「職人A=18,000円、職人B=16,000円、職人C=15,001円」(すべて架空)として、次の11ケースを計算しました。

| ケース | 入力した日報 | 人工合計 | 労務費 | 表示 |
|---|---|---|---|---|
| 通常 | K-001に 職人A 1、職人B 0.5、職人C 1 | 2.5 | 41,001 | (なし) |
| 1日2現場 | 同じ日に職人Aが K-002 に0.5、K-003 に0.5 | 各0.5 | 各9,000 | (なし) |
| 存在しない工事番号 | K-040(台帳にない)に職人A 1 | — | 台帳に入らない。F1=18,000 | 「工事番号なし」 |
| 工事番号が空欄 | 番号なしで職人A 1 | — | 台帳に入らない。F1=18,000 | 「工事番号が空欄」 |
| 全角・スペース | 「Ｋ－006」に職人A 1、「 K-006 」に職人B 1 | 2 | 34,000 | (なし。正しく集計される) |
| 人工が文字 | 全角の「１」、「半日」 | 0 | 0 | 「人工が未入力か数値でない」 |
| 空欄・0・マイナス | 空欄、0、−1 | 0 | 0 | 「未入力か数値でない」「0以下」 |
| 未登録の作業員 | 作業員表にない「職人Z」が1 | 1 | 0 | 「作業員が未登録」 |
| 同日の2人工超 | 同じ日に職人Aが K-010 に1.5、K-011 に1 | 1.5 / 1 | 27,000 / 18,000 | 両方「同日の合計が2人工超」 |
| 端数 | 職人C(15,001円)が0.5 | 0.5 | 7,501 | (なし。7,500.5を四捨五入) |
| 日報なし | なし | 0 | 0 | (なし) |

11ケースすべて、人工合計・労務費・チェック表示・F1が、Pythonでの計算結果と一致しました。

さらに、工事300件・作業員20人・日報約1,540行の乱数データで照合しました。約82%は正しい入力、約5%は存在しない番号、約3%は空欄、約4%は全角、約2%は前後にスペース(この2つは正しく集計されるべき入力)、約2%は文字・空欄・0・マイナスの人工、約2%は未登録の作業員にし、同じ人が同じ日に2現場へ入る(合計2.5人工)行を40件混ぜています。**人工合計・労務費・チェック表示・未紐づけ額のすべてが一致**しました(Excelでの確認はしていません)。

## つまずきやすい点

- **日報の行を消したとき**: 消した分だけ人工と労務費は減ります。式は消えた行を「なかったこと」にするので、消し忘れ・消しすぎの検出はできません。月末に、日報の行数や人工の合計を手元の記録と見比べてください。
- **作業員の名前の表記ゆれ**: 「職人A」と「職人 A」のように中のスペースが違うと、未登録になります。この式が整えるのは、前後のスペースだけです。
- **工事番号の付け方がそろっていないとき**: 台帳が「K-001」、日報が「K001」のようにハイフンの有無が違うと一致しません。全角→半角と前後のスペース以外は吸収しません。
- **番号が数字だけのとき**: 台帳と日報の両方を同じ形で入力してください。この記事では数字だけの工事番号の動きを、Excelでは確認していません。
- **範囲の上限**: 日報は3000行、作業員は200人までです。増えたら範囲を広げてください。
- **日付が空欄の日報**: 日付が空欄の行は「同日の合計」のチェックを飛ばします。人工と労務費は集計されます。

## 注意点: この記事ができないこと

- 外注費(人ではなく工事単位で払うもの)、材料費、機械経費は扱いません。**労務費だけ**を集計します。
- 労務費として何を含めるか(社会保険料、残業の割増など)の判断はしません。日当×人工の単純な計算です。
- 一人親方が自分自身の人工を原価に入れるかどうか、税務・会計上の扱いは判断しません。

## 見積から請求までを1つのひな形で

この記事の式は、自分で作った台帳にそのまま使えます。工事ごとの粗利を出す考え方は[工事ごとの粗利を出す方法の記事](/job-margin/)に、請求の残額の管理は[分割請求の残額の記事](/split-billing-balance/)にあります。見積の段階の計算(数量×単価、諸経費、値引き、消費税)から作りたい場合は、運営者が作った[工事・リフォーム用 見積書テンプレート(Excel・980円)](/go/estimate-construction/?from=daily-labor-by-job)があります。数量×単価(四捨五入)、諸経費率、値引き、消費税10%(切り捨て)、税込合計を自動計算し、明細は20行、A4縦1枚で印刷できます。**この記事の日報・労務費の機能は、この商品には入っていません**。軽減税率の混在や、インボイス要件の保証もできません。Excelの確認はWindowsデスクトップ版16のみです。(これは運営者の商品の案内です。)

消費税だけをさっと出したいときは無料の[消費税 計算ツール](/tools/tax/)、見積の小計から税込までを一度に出すなら[見積の合計計算ツール](/tools/estimate-total/)が使えます(入力は外部に送信されません)。

## まとめ

- 日報に「日付・工事番号・作業員・人工」を1行ずつ入力し、台帳の人工合計と労務費はSUMIFSで集計する
- 集計の鍵は、全角・スペースを整えた「整えた番号」の列と、作業員シートから日当を引く列
- 存在しない番号・空欄・文字の人工・0以下・未登録の作業員・同日の2人工超は、チェック列に表示させる
- 日報の労務費合計と台帳の労務費合計の差(F1)が0でなければ、工事に結びついていない日報がある
- 11ケースと、工事300件・日報約1,540行の照合はLibreOfficeで一致。Excelでは未確認のため、本番では数件を電卓で検算する
