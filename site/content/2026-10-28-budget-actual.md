「工事が終わって精算したら、原価が予算を超えていた」——小さな工務店・リフォーム店で、工事ごとの利益が読めなくなる原因のひとつです。終わってから気づくと手遅れですが、**工事の途中で「予算に対して、いま原価をどれだけ使ったか」を進捗率と並べて見る**だけで、早めに手を打てます。

この記事では、**実行予算・原価実績・進捗率**を1行ずつ入れるだけで、**「順調／要注意／予算超過」の表示、予算の消化率、予算残、このままいった場合の完成時の見込原価**を出す式を示します。「進捗より何ポイント原価が先行したら要注意とするか」は、自分で決められます。

出典: 筆者がLibreOfficeで計算して確認(検証スクリプト: site/verify/budget_actual.py)。外部サイトの説明は参照していません。**Excelでは未確認**です。使うのはIF・OR・AND・NOT・ISNUMBER・INT・ROUND・N・COUNTIF・SUMIFという一般的な関数ですが、本番で使う前に、数行を手計算と見比べてください。この記事は表の作り方の説明です。**実行予算の組み方や原価の計上の仕方は、会社の経理のルール(必要なら税理士)に従ってください**。

## 先に結論: 「消化率 > 進捗率 + 許容ポイント」なら要注意、「実績 > 予算」なら予算超過

- 消化率 = 原価実績 ÷ 実行予算
- 原価実績が実行予算を超えている → **予算超過**
- 消化率が「進捗率 + 許容ポイント」を超えている → **要注意**(工事の進み具合より、原価が先に出ている)
- それ以外 → 順調
- 完成時の見込原価 = 原価実績 ÷ 進捗率(進捗率が0%のときは出さない)

## Excelの式

シート名は「予算実績」。2行目から使います。

| 列 | 内容 | 入れるもの |
|---|---|---|
| A | 工事番号 | 手入力(例: K-001) |
| B | 工事名 | 手入力 |
| C | 実行予算 | 手入力(1以上の整数)。その工事で使ってよい原価の上限 |
| D | 原価実績 | 手入力(0以上の整数)。現時点までに計上した原価の合計 |
| E | 進捗率 | 手入力(0%〜100%)。「50%」と入れるか、0.5と入れる |
| F | 状態 | 式 |
| G | チェック | 式 |
| H | 消化率 | 式 |
| I | 予算残 | 式(マイナスは超過額) |
| J | 完成時の見込原価 | 式 |
| K | 見込差額 | 式(見込原価 − 実行予算。プラスは超過の見込み) |
| N2 | 許容ポイント | 例: 0.1(10ポイント)。空欄は0として扱う |

```
F2: =IF(OR(G2<>"",A2&B2&C2&D2&E2=""),"",IF(D2>C2,"予算超過",
      IF(ROUND(D2/C2-E2-N($N$2),6)>0,"要注意","順調")))
G2: =IF(A2&B2&C2&D2&E2="","",IF(A2="","工事番号が空欄",
      IF(COUNTIF($A$2:$A$1000,A2)>1,"工事番号が重複",
      IF(C2="","実行予算が空欄",IF(NOT(ISNUMBER(C2)),"実行予算が数字でない",
      IF(OR(C2<1,C2<>INT(C2)),"実行予算は1以上の整数",
      IF(D2="","原価実績が空欄",IF(NOT(ISNUMBER(D2)),"原価実績が数字でない",
      IF(OR(D2<0,D2<>INT(D2)),"原価実績は0以上の整数",
      IF(E2="","進捗率が空欄",IF(NOT(ISNUMBER(E2)),"進捗率が数字でない",
      IF(OR(E2<0,E2>1),"進捗率は0〜100%",""))))))))))))
H2: =IF(F2="","",D2/C2)
I2: =IF(F2="","",C2-D2)
J2: =IF(OR(F2="",N(E2)=0),"",D2/E2)
K2: =IF(J2="","",J2-C2)
```

H列は「パーセンテージ」、I・J・K列は「数値(桁区切り)」の表示形式にしてください。J・K列は割り算の結果が小数になるため、表示形式で整数に丸めて見ます(式の中では丸めていません)。`ROUND(…,6)` は、消化率と進捗率の差がちょうど許容ポイントのときに、計算の誤差で判定がぶれないようにするために入れています。

集計は右側のセルに置きます(範囲は1000行まで)。

```
N5 予算超過の件数:   =COUNTIF($F$2:$F$1000,"予算超過")
N6 予算超過の金額:   =-SUMIF($F$2:$F$1000,"予算超過",$I$2:$I$1000)
N7 要注意の件数:     =COUNTIF($F$2:$F$1000,"要注意")
N8 順調の件数:       =COUNTIF($F$2:$F$1000,"順調")
```

## 実際に計算して確認した結果

許容ポイントを0.1(10ポイント)にして、実行予算1,000,000円・進捗50%の工事で原価実績だけを変えた結果です。

| 原価実績 | 消化率 | 状態 | 予算残 | 完成時の見込原価 |
|---|---|---|---|---|
| 400,000円 | 40% | 順調 | 600,000円 | 800,000円 |
| 600,000円(進捗+10ポイントちょうど) | 60% | 順調 | 400,000円 | 1,200,000円 |
| 610,000円(10ポイントを超えた) | 61% | 要注意 | 390,000円 | 1,220,000円 |

許容ポイントちょうどまでは順調、1円でも超えたら要注意です(境界の動きも確認済みです)。許容を0にすると、実績500,001円・進捗50%でも要注意になります。

予算を超えた場合は、進捗率に関わらず「予算超過」になります。実績が1,000,001円で予算1,000,000円なら、予算残は-1円です。

進捗率が30%なのに実績が1,300,000円(予算1,000,000円)という場合、完成時の見込原価は 1,300,000 ÷ 0.3 ≒ 4,333,333円と出ます。予算の4倍を超える見込みという意味で、「いまの使い方のまま最後まで行くとこうなる」という警告の数字です。

5件を入れた集計の確認では、予算超過2件(合計の超過額 220,000円)、要注意1件、順調2件と出ました。

入力ミスの行は、状態を空欄にして、G列にこう出ます。

| 入力ミス | チェック |
|---|---|
| 工事番号が空欄 | 工事番号が空欄 |
| 工事番号が重複(K-001とk-001) | 工事番号が重複 |
| 実行予算が空欄 | 実行予算が空欄 |
| 実行予算が「100万」・全角「１，０００，０００」 | 実行予算が数字でない |
| 実行予算が0・小数 | 実行予算は1以上の整数 |
| 原価実績が空欄・「40万」 | 原価実績が空欄／数字でない |
| 原価実績がマイナス・小数 | 原価実績は0以上の整数 |
| 進捗率が空欄・「半分」 | 進捗率が空欄／数字でない |
| 進捗率を「50」と入れた(5000%になる)・マイナス・1.2 | 進捗率は0〜100% |
| すべて空欄の行 | (何も出さない) |

「50」と入れてしまう誤操作は多いので、100%(=1)を超える値はチェック列で止めています。

33ケースすべて、状態・消化率・予算残・見込原価・見込差額・チェック表示と集計が、Pythonで計算した結果と一致しました。さらに、乱数で作った**500行**(工事番号の空欄・重複、実行予算・原価実績・進捗率の文字・0・小数・マイナス・範囲外を約12%混ぜました)でも、**全項目と集計4つが一致**しました。Excelでの確認はしていません。

## つまずきやすい点

- **完成時の見込原価は「進捗に比例して原価が出る」前提の目安**: 工事の初めに材料をまとめて仕入れる場合は、見込みが実際より大きく出ます。逆に、最後に外注費が集中する工事では小さく出ます。見込原価は判断の材料のひとつとして見て、現場の実情と合わせて判断してください。
- **進捗率は誰が決めるかを決めておく**: 進捗率を人によって違う感覚で入れると、判定がぶれます。[出来高(契約金額×進捗率)から今回の請求額を出す記事](/progress-billing/)でも進捗率を使うので、同じ数字を使うと管理が楽です。
- **原価実績の集め方**: 材料・外注・人工(労務費)・経費をどう足すかは、[工事の原価を材料・外注・経費に分けて粗利を見る記事](/job-margin/)や、[作業日報から人工と労務費を集計する記事](/daily-labor-by-job/)、[外注先への未払いと発注残を出す記事](/subcontract-balance/)の表の合計を入れる使い方ができます。
- **追加工事で予算が変わったとき**: 実行予算も更新してください。契約金額の変更の扱いは[追加工事・減額を反映した契約金額の記事](/contract-change/)にあります。
- **許容ポイントは自社で決める**: 0.1(10ポイント)は例です。小さな工事は変動が大きいので広めに、大きな工事は狭めにするなど、運用に合わせてください。

## 注意点: この記事ができないこと

- 実行予算の作り方(何をいくらで見込むか)の判断はしません。原価の計上基準(いつ・どの工事に付けるか)も扱いません。
- 工事の利益が出るかどうかの保証はしません。表示はあくまで入力した数字からの計算です。
- 金額は整数だけを前提にしています。税の取り扱いは扱いません(税抜か税込のどちらかにそろえて入れてください)。

## 見積から原価管理までつなげたいとき

見積の計算そのものから作りたい場合は、運営者が作った[工事・リフォーム用 見積書テンプレート(Excel・980円)](/go/estimate-construction/?from=budget-actual)があります。数量×単価(四捨五入)、諸経費率、値引き、消費税10%(切り捨て)、税込合計を自動計算し、明細は20行、A4縦1枚で印刷できます。**この記事の「予算と原価実績の比較」機能は、この商品には入っていません**。請求書への変換、軽減税率の混在、インボイス要件の保証もできません。Excelの確認はWindowsデスクトップ版16のみです。(これは運営者の商品の案内です。)

目標の粗利から売値を逆算するなら、無料の[粗利率と上乗せ率の変換ツール](/tools/margin-markup/)が使えます(入力は外部に送信されません)。

## まとめ

- 実行予算・原価実績・進捗率の3つを工事ごとに入れ、「消化率が進捗率より先行していないか」を見る
- 許容ポイントちょうどまでは順調、1円でも超えたら要注意。実績が予算を超えたら予算超過
- 完成時の見込原価(実績÷進捗率)は、進捗に比例して原価が出る前提の目安
- 進捗率に「50」と入れる、実行予算が0、工事番号の重複などは、状態を出さずチェック列で止める
- 33ケースと500行の照合はLibreOfficeで一致。Excelでは未確認のため、本番では数行を手計算で見比べる
