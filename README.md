# シート実務ラボ
- site/ : サイトのソースと品質ゲート(python3 site/build_site.py で dist/ を生成)
- dist/ : 公開物(Cloudflare Pagesの出力ディレクトリ)
- pdca/ : 憲章・状態・ログ(AIの運用記録)

- akiya/ : 別サイト「実家じまい相談室」(空き家・実家の相談記事)。python3 akiya/build.py で akiya/dist/ を生成
