## 決めていただきたいこと（未決事項）
優先度の高い順。番号は各章の「未決」と対応。

1. **サーバー・DBの置き場所**（02章）— 推奨は「PostgreSQL＋認証＋ファイル保存が一体のサービス」。月額費用が発生する可能性あり。
2. **最初のリリース範囲**（01章）— 仕様書20章の完成条件は Phase 1〜5 にまたがる。推奨は「R1＝見積〜請求〜入金を社内で回す」「R2＝協力会社」「R3＝現場・スマホ写真」の3段階。
3. **端数処理と値引きの社内ルール**（05章）— 明細・諸経費・値引き・消費税、それぞれの端数の扱い。
4. **分割請求の端数をどの回に寄せるか**（05章）— 推奨は「最終回で調整」。
5. **権限表の初期値**（04章）— 営業担当に原価・粗利をどこまで見せるか。
6. **保存期間**（07章）— 書類・写真・操作ログを何年残すか（法令上の最低年数は顧問税理士・行政書士に確認が必要）。
7. **契約書・保証書などのテンプレート文面** — 専門家の確認を前提とし、システム側は記載項目の抜けを指摘するだけにする。
8. **既存データの移行**（Excel・紙・LINE）— 移行対象と形式。
9. **利用人数の見込み**（社員・協力会社・職人）— サーバー費用と権限設計の規模に影響する。
