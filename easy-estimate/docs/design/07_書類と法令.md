# 07 書類と法令

> システムは法令適合を保証しない（仕様書17）。以下は「抜けを指摘するためのチェック項目」として持つもので、契約書・保証書などの文面と最終判断は専門家（弁護士・税理士・行政書士）の確認を前提とする。

## 1. 書類の共通の仕組み
| 項目 | ルール |
|---|---|
| 生成 | 案件・顧客・マスタ・元の書類から作る。手で写す項目を作らない |
| 状態 | 作成中 → （承認待ち）→ 確定（提出・発行・締結）→ 取消。確定で `locked_at` が入り、以後は書き換え不可 |
| 版 | 変更は新しい版（V1, V2…）。各版に作成日時・作成者・変更内容（必須入力）を残す。版の差分を表示できる |
| 取消・再発行 | 確定済みは削除しない。取消（理由必須）→ 再発行で、元と新の関係を記録 |
| 番号 | 書類種類ごと・期間ごとに自動採番。取消しても番号は再利用しない（欠番として記録） |
| 承認 | 組織設定で「承認が必要な書類と金額の条件」を決める（例：見積 300万円以上は経営者の承認） |
| 出力 | PDF（顧客提出用／内部用を別テンプレート）、印刷、ダウンロード、送信履歴 |
| 保存 | 確定時の PDF とデータの両方を保存し、PDF のハッシュ値を記録（改ざん検知） |

## 2. 書類の種類と作る順番
仕様書6-2の全種類を同じ仕組みで扱えるようにし、テンプレートは管理者が追加できる。作る順番は01章のリリースに合わせる。

| リリース | 書類 |
|---|---|
| R1 | 見積書（詳細・概算・追加・変更・原状回復）、複数プラン比較表、原価見積書（内部用）、工事請負契約書、注文書・注文請書、追加工事承諾書、工事変更合意書、請求書（一括・着手金・中間金・最終金・追加工事）、領収書、入金確認書、工事完了報告書（写真つき） |
| R2 | 発注書・外注発注書、支払明細書 |
| R3 | 現地調査報告書、採寸表、施工指示書、作業日報、工事写真台帳、検査チェックシート、引渡確認書、工程表、案内文類 |
| R4以降 | 物件調査・査定書、保証書、メンテナンス案内、クレーム対応報告書 など |

## 3. 適格請求書（インボイス制度）
請求書・領収書の確定前に以下の記載を自動チェックする。
1. 発行事業者の氏名または名称、登録番号（T＋13桁）
2. 取引年月日
3. 取引内容（軽減税率の対象品目である旨）
4. 税率ごとに区分して合計した対価の額、および適用税率
5. 税率ごとに区分した消費税額等（1書類につき税率ごとに1回の端数処理）
6. 書類の交付を受ける事業者の氏名または名称

## 4. 建設業法
### 第19条（請負契約の書面の記載事項）
契約書の確定前に、以下が入っているかを項目ごとに確認し、空欄を指摘する（入力欄は `contract_versions.legal_fields`）。
1. 工事内容
2. 請負代金の額
3. 工事着手の時期および工事完成の時期
4. 工事を施工しない日または時間帯の定めをするときは、その内容
5. 前金払または出来形部分に対する支払の定めをするときは、その支払の時期および方法
6. 設計変更・工事着手の延期・工事の中止の申出があった場合の工期の変更、請負代金の額の変更、損害の負担およびそれらの額の算定方法
7. 天災その他不可抗力による工期の変更または損害の負担およびその額の算定方法
8. 価格等の変動もしくは変更に基づく請負代金の額または工事内容の変更
9. 工事の施工により第三者が損害を受けた場合における賠償金の負担
10. 注文者が資材を提供し、または建設機械等を貸与するときは、その内容および方法
11. 注文者が完成を確認するための検査の時期および方法ならびに引渡しの時期
12. 工事完成後における請負代金の支払の時期および方法
13. 契約不適合責任またはその履行に関して講ずべき保証保険契約の締結その他の措置に関する定めをするときは、その内容
14. 各当事者の履行の遅滞その他債務の不履行の場合における遅延利息、違約金その他の損害金
15. 契約に関する紛争の解決方法
16. その他国土交通省令で定める事項

> 法改正で項目の文言・追加がありうるため、項目一覧はコードに埋め込まず設定データとして持ち、専門家の確認後に更新できるようにする。

### 第20条（見積）
見積書に材料費・労務費その他の経費の内訳を明示する。明細ごとに原価区分を持ち、顧客提出用の見積書にも区分ごとの金額を出す（原価ではなく**販売額の内訳**）。

## 5. 電子帳簿保存法（電子取引・スキャナ保存を想定）
| 要件 | 設計 |
|---|---|
| 真実性 | 確定済み書類は書き換え不可、訂正・削除は版と取消で履歴が残る（訂正削除の履歴が残るシステム）。あわせて事務処理規程のひな形を用意する |
| 可視性（検索） | 取引年月日・取引金額・取引先で検索でき、日付と金額は範囲指定、2つ以上の条件の組み合わせができる |
| 見読性 | PDF を画面・印刷で確認できる |
| 保存期間 | **未決6**。法人税法上は原則7年（欠損金の繰越がある年度は最長10年）が目安。建設業法の帳簿・図書の保存期間もある。顧問税理士・行政書士に確認して設定値にする |

## 6. 個人情報
- 顧客の個人情報は、04章の権限で業務上必要な人だけが見られる
- 閲覧・出力の操作も履歴に残す
- 顧客データの CSV 出力は管理者・経営者のみ（初期値）
- 退職者・契約終了者は即時アクセス停止
